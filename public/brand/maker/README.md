# 제조사 마크 (조건칸 «제조사» 축)

**출처** — [simple-icons](https://github.com/simple-icons/simple-icons) v13.21.0 · **CC0-1.0**(퍼블릭 도메인).
아이콘 «파일»은 CC0 이고, **마크 자체는 각 제조사의 상표**다. 어느 차인지 알아보게 하려고
그 이름과 함께 쓰는 것(지시적 사용)이고, 중고차 판(엔카·케이카·헤이딜러)이 공통으로 쓰는 방식이다.

⚠ **다른 회사(엔카·케이카 등) 서버의 이미지를 가져다 쓰지 않는다.**

## 두 장은 출처가 다르다 (2026-09-07)

사장님 「제조사에 **제네시스 KGM 로고심볼이 없네** 이건 찾아서 넣어주시고」 — simple-icons 에
없어서 따로 구했다.

| 파일 | 출처 | 라이선스 |
|---|---|---|
| `genesis.svg` | genesis.com 이 제 사이트에 싣는 로고 SVG(제조사가 «공개한» 자산) | 상표 — 지시적 사용 |
| `kgm.svg` | [위키미디어 공용 `KG Mobility brand logo.svg`](https://commons.wikimedia.org/wiki/File:KG_Mobility_brand_logo.svg) | **퍼블릭 도메인** |

★★**그림은 한 획도 안 건드린다.** path 좌표를 만지는 순간 그건 그들의 마크가 아니게 된다.

⚠⚠ **제네시스는 «날개»를 잘랐다가 되돌렸다 (2026-09-08).**
  18px 정사각 칸에 4.8:1 짜리 원본(126×26)을 넣으면 높이가 3.7px 이 되니까,
  `viewBox` 를 방패 자리(`49 2 28 22`)로 좁혀 **방패만** 남겼었다.
  사장님 「**필터에 제네시스 로고 저거 아닌데**」 — 맞다. 제네시스 엠블럼은 **날개 달린 방패**이고,
  날개를 잘라낸 방패는 그 회사 마크가 아니다.
  ⇒ `viewBox` 를 원본 판(`0 0 126 26`)으로 되돌리고, **칸을 그림에 맞췄다** —
    조건칸 마크 자리를 **44×18**(가로로 넓게)로(`components/shop/ShopFilters` `MARK_W`/`MARK_H`).
  ★**그림을 칸에 맞추지 않는다. 칸을 그림에 맞춘다.**

★색은 «밝은 배경용»으로 정한다 — 원본(genesis.com 머리띠)은 **어두운 배경용**이라 날개가 흰색이다.
  흰 바탕에 그대로 쓰면 날개가 사라지고 검은 방패만 남는다.
  ⇒ 날개·방패 = `#111111` · 방패 «안»의 GENESIS 글자 = `#ffffff`(원본과 같은 구성).
  ★`fill` 만 정했고 `d`(좌표)는 genesis.com 이 싣는 그대로다.

⚠ 다시 받을 일이 있으면 **원본을 받아 `fill` 만 다시 정한다.** 그림을 편집하지 마라.

## 파일 이름
`lib/domain/maker-logo.ts` 의 표가 «제조사 이름 → 파일 이름»을 정한다. 여기 파일명을 바꾸면 그 표도 같이 고친다.
