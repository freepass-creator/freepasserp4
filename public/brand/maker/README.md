# 제조사 마크 (조건칸 «제조사» 축)

**출처** — [simple-icons](https://github.com/simple-icons/simple-icons) v13.21.0 · **CC0-1.0**(퍼블릭 도메인).
아이콘 «파일»은 CC0 이고, **마크 자체는 각 제조사의 상표**다. 어느 차인지 알아보게 하려고
그 이름과 함께 쓰는 것(지시적 사용)이고, 중고차 판(엔카·케이카·헤이딜러)이 공통으로 쓰는 방식이다.

⚠ **다른 회사(엔카·케이카 등) 서버의 이미지를 가져다 쓰지 않는다.**

## 파일 이름
`lib/domain/maker-logo.ts` 의 표가 «제조사 이름 → 파일 이름»을 정한다. 여기 파일명을 바꾸면 그 표도 같이 고친다.

★없는 마크를 **지어내지 않는다.** 파일이 없으면 그 줄은 글자만 나온다(`makerLogoSrc` → `null`,
그리고 파일이 사라진 경우까지 대비해 `onError` 로 지운다).
제조사가 공개한 브랜드 자산을 구하면 같은 이름으로 넣으면 된다 — 코드는 안 고쳐도 된다.
