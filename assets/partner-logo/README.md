# 회원사 로고

정산서 오른쪽 위 「회원사」 자리에 붙는 그림.

## 넣는 법

1. 이 폴더에 **별칭.확장자** 로 둔다 — 별칭은 정산시트가 부르는 그 이름이다.

   ```
   손오공.png        오토플러스.png      우리캐피탈.svg
   하허호.png        렌트야.png          SMC.png
   ```

2. 돌린다.

   ```
   npx tsx scripts/embed-partner-logos.mts
   ```

   `lib/domain/partner-logo.ts` 가 다시 써진다. 그 파일은 손으로 고치지 않는다.

## 규격

| | |
|---|---|
| 형식 | png · jpg · svg (png 권장 — 배경 투명) |
| 크기 | 가로 400px 안팎이면 넉넉하다. 종이에선 높이 22px 로 눕는다 |
| 배경 | **흰 바탕이 아니라 투명**. 흰 사각형이 그대로 찍힌다 |
| 무게 | 한 장 100KB 넘지 않게. data URI 로 종이에 박히므로 파일이 커진다 |

## 지킬 것

- **허락받은 것만 넣는다.** 남의 상표다.
- 파일이 없으면 아무것도 안 그린다 — 상호 글자만 선다. 그게 정상이다.
- 이 폴더는 원본 보관용이다. 종이에 들어가는 건 위 스크립트가 만든 data URI 다.
