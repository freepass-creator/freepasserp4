# 로컬에만 있던 산출물 — 보관용 (2026-09-17)

사장님 「이제 GitHub 온라인 클라우드로만 작업할 거여서 커밋 안 된 거 있으면 확실하게
커밋해 주세요 오류 안 나게」 · 「니가 깃허브 온라인이랑 로컬이랑 다 확인해서 문제 없게끔」

로컬 워크트리에만 있던 **미추적 파일 19개**를 여기 모았다. 클라우드로만 작업하면
로컬은 언제든 사라지므로, 값이 있든 없든 «남기지 않는다»는 원칙으로 통째로 올렸다.

| 폴더 | 무엇 |
|---|---|
| `canonical-whitelabel/` | 빌드·서버 로그(`*.log`) · 종료코드(`*.exit`) · 확인 스크린샷 3장 |
| `mobile-hotfix/` | 폰·웹 대조 확인 스크린샷 7장(상품찾기·가게 패리티) |
| `wt-stl-atoms/` | PR 본문 임시 파일 |

⚠ **이것은 «작업»이 아니라 «산출물»이다.** 코드가 아니고, 다시 만들 수 있다
  (로그는 빌드하면 다시 나오고 스크린샷은 다시 찍으면 된다).
  그래서 소스 나무 안(`scripts/`·`docs/`)에 두지 않고 이 폴더에 격리했다.

★**지워도 되는 폴더다.** 필요 없다고 판단되면 이 폴더째 지우면 된다 —
  다른 어떤 코드도 여기를 참조하지 않는다.
