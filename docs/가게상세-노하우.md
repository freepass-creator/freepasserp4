
`?wl=` 은 **도메인 붙기 전 미리보기 전용**입니다. 운영에서 브랜드를 정하는 것은 **호스트**입니다.

## 1. ★★가장 크게 틀린 것 — 「규칙이 맞아도 결과가 틀리면 규칙이 틀린 것」

차량 정보에 넣을 칸을 **「위 사실줄과 안 겹치는 것만」**이라는 규칙으로 골랐습니다.
결과가 **최초등록 · 구동방식 · 승차정원 · 색상**이었습니다. 규칙은 지켰는데, 그건 차 설명이 아니라
**«남은 것 모음»**이었습니다. 하필 첫 칸이 그랜저에 「2륜구동」으로 떠 있었습니다.

> 사장님 「차량 정보에 연식이, 이륜구동, 이런 걸 넣는 게 아니라…」

**교훈** — 규칙을 세웠으면 **그 규칙이 뱉은 결과를 화면에서 눈으로** 보십시오.
저는 규칙을 믿고 결과를 안 봤습니다. 그리고 그 잘못된 규칙이 **검사에까지 박혀 있어서**,
나중에 고칠 때 게이트가 저를 막았습니다.

## 2. ★★두 번째로 크게 틀린 것 — 남의 구성을 우리 상품에 대보지 않았다

조사한 열두 곳이 거의 전부 「What's included」 블록을 갖고 있길래 **「대여료에 포함」 격자**를 만들었습니다.
우리 데이터로 그리니 이렇게 나왔습니다:

```
보험 → 별도      정비 → 담당자 확인      대차 → 불가
```

**「포함」이라 써 놓고 아무것도 포함 안 된 칸.** 사장님 「대여료에 포함은 의미가 없어.」

Autonomy·Vamos·Kinto 가 그 블록을 갖는 것은 그들이 **정말로 다 포함**하는 상품이기 때문입니다.
우리는 «따로 붙이는» 상품입니다. **벤치마크는 우리 데이터에 대보기 «전»까지는 가설일 뿐입니다.**

## 3. 「보조」는 «숨김»이 아니다

사장님 「최저가를 보여주고 기간별은 **약간 보조로** 보여주면」 → 저는 **접기 버튼**을 달았습니다.
사장님 「보조라고 한 게, 메인 대여료를 하고 **그 밑에 전체 기간별 대여료를 보조표로** 보여주라는 거지.」

★조사 결과도 같은 말을 하고 있었습니다 — **열두 곳 중 요금 구조를 접은 곳이 0곳**.
저는 그 숫자를 문서에 적어 놓고도 못 읽었습니다.
**말을 좁게 읽어 기능을 지우지 마십시오.** 애매하면 «덜 감추는» 쪽이 안전합니다.

## 4. 이 화면에서만 나오는 함정 — 코드

### ㉠ `.fp-wl` 이 flex 아이템이라 «찌그러진다»
구르는 칸(`.fp-main-pad`)이 **세로 flex 컨테이너**입니다. 그 안의 `.fp-wl`(손님 화면 흰 바닥)은
flex 아이템이라 기본 `flex-shrink: 1` 로 **컨테이너 높이에 눌립니다.**

```
내용 2,155px 인데 흰 바닥은 844px → 첫 화면만 흰색, 그 아래는 업무동 회색(#eaedf2)
```
`min-height: 100vh` 로는 **못 막습니다**(그건 «최소»지 «줄지 마라»가 아닙니다).
→ `flex: 0 0 auto`. 지금 `app/globals.css` 에 박아 뒀습니다. **지우지 마십시오.**

⚠ **첫 화면은 늘 멀쩡했습니다.** 위만 보고 넘어가면 영원히 안 걸립니다.

### ㉡ 검사가 «주석»에 속는다
`check-design-locked.mts` 에 「이 낱말이 있나」를 정규식으로 걸면, **그 낱말을 설명하는 주석**이
검사를 통과시켜 버립니다. 오늘 두 번 걸렸습니다.
→ **그려지는 글자**를 보십시오: `/>선택 옵션</` · `/title="대여료에 포함"/`.

### ㉢ 검사는 «깨서» 확인한다
새 검사를 넣으면 **일부러 코드를 깨서 빨간불이 뜨는지** 보십시오. 안 그러면 고무도장입니다.
(전에 heredoc 이 `\b` 를 0x08 로 먹어 **두 검사가 한 번도 안 뜬** 적이 있습니다.)

```bash
cp components/shop/ShopDetail.tsx /tmp/sd.bak
# … 일부러 깬다 …
npx tsx scripts/check-design-locked.mts     # 빨간불이 떠야 정상
cp /tmp/sd.bak components/shop/ShopDetail.tsx
```

### ㉣ JSX 주석을 삼항 값 자리에 두면 안 컴파일된다
```jsx
{cond ? (
  {/* 주석 */}      ← 여기서 깨진다. 오늘 세 번 걸렸다
  <div/>
) : null}
```
주석은 **삼항 «밖»**으로.

### ㉤ 도면 숫자는 «조건식»을 안 센다
`check-building` 의 높이 세는 정규식은 `height: 8` 은 세고 `height: mobile ? 10 : 8` 은 **안 셉니다.**
조건식을 상수로 바꾸면 «없던 치수가 는 것»처럼 빨간불이 뜹니다. **근거를 도면에 적고 올리면 됩니다**
(좋아졌으면 `npm run check:building -- --tighten`).

## 5. 화면 찍기 — 이 앱은 «문서»가 안 구른다

`html/body` 가 `overflow:hidden` 이고 **`.fp-main-pad` 가 구릅니다.**
그래서 `fullPage` 스크린샷이 **첫 화면만** 찍힙니다. 전체를 찍으려면 임시로 풀어야 합니다:

```js
const s = document.createElement('style');
s.textContent = `nextjs-portal,[data-nextjs-toast]{display:none!important}
  html,body{overflow:visible!important;height:auto!important}
  .fp-shell{height:auto!important;min-height:0!important}
  .fp-main-pad{overflow:visible!important;height:auto!important;max-height:none!important}`;
document.head.appendChild(s);
```
- `nextjs-portal` 을 숨기지 않으면 **개발용 검은 N 배지가 하단독 금액을 가립니다.**
- 캡처가 **타일로 깨지기** 시작하면(같은 조각이 반복) 그 탭은 버리고 **새 탭**에서 다시 찍으십시오.
- 폰은 `390x844`, 웹은 `1440x900`. 폰 첫 방문은 쿠키가 없어 SSR 이 데스크톱으로 잡히니 **새로고침 후** 재십시오.

## 7. 이 화면의 «값을 지어내지 않는다» 규칙

- 뜻 없는 값(「기타」·「협의」·「미정」)은 **줄째로 뺍니다**(`meaningful()`).
  색상 칸의 「기타」는 색을 안 알려 주면서 칸은 채운 꼴이라 **안 적는 것보다 나쁩니다.**
- 모르는 것은 **「없음」이 아니라 「담당자 확인」**입니다.
- **중도해지 위약금은 손님 화면에 안 냅니다** — 업무동 정본의 판단입니다(벌칙 조항이 서면
  «어떤 차를 얼마에» 보는 화면이 계약서 읽는 화면이 됩니다). 제가 가게를 새로 지으면서
  그 판단을 안 보고 다시 넣었다가 뺐습니다. **딴 데 이미 내린 판단을 먼저 찾으십시오.**
- 요금 밑에 **「심사」라는 낱말을 쓰지 않습니다** — 셀링포인트가 「무심사」인데 요금 옆에서
  그 말을 도로 꺼내면 손님이 평생 들어 온 그 단어를 다시 만납니다.
