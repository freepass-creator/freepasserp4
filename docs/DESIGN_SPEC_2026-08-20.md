## 1. 받은 것과 판단

| 시안 | 층을 만드는 법 | 모서리 | 뱃지 구분 | 판정 |
|---|---|---|---|---|
| cursor-a / codex-a | 테두리 굵기·색만 | 2px 한 단계 | 자리(a) | **✕** 지금과 달라지는 게 없다 |
| **cursor-b** | **면 대비**(페이지 회색 vs 카드 흰) | **8 / 4 두 단계** | **모양**(상태=알약, 분류=사각) | **◎ 채택 — 기준안** |
| cursor-c / codex-c | 면 대비 + 옅은 그림자 1단 | 12 / 8 / 4~6 세 단계 | 자리+모양 | △ 부분 채택(선택 강조만) |
| codex-b | 면 대비 | 8 / 4 | 모양 + 혜택을 파란 블록으로 묶음 | △ 혜택 블록은 **불채택**(카드가 무거워짐) |

**왜 cursor-b인가**
- 뱃지가 **사진 바로 밑 한 줄**로 정렬돼 6장을 훑을 때 눈이 한 줄만 따라가면 된다. codex계열은 뱃지가 사진 모서리에 흩어져 스캔 경로가 둘이 된다.
- 모서리 2단(8/4)이면 «담는 것(카드)»과 «누르는 것(컨트롤)»이 갈린다. 한 단계(2px)는 지금 문제 그대로고, 세 단계는 ERP에 과하다.
- 혜택을 **파란 면 블록**으로 묶은 codex-b는 카드 무게중심이 혜택으로 쏠린다. 우리 화면에서 제일 중요한 건 **차·상태·금액**이다.

**cursor-c에서 가져올 것 하나** — 선택된 카드의 **옅은 그림자 1단**. 격자에서 「지금 고른 것」이 테두리만으로는 약하다.

## 2. 공통 토큰 — 이 값으로 굳힌다

### 2-1. 모서리 (2단 + 알약)

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--radius-card` | **8px** | 카드·패널·모달·큰 서피스 |
| `--radius` | **4px** | 표·입력·버튼·필터칩·사각 뱃지 |
| `--radius-pill` | **999px** | **상태 뱃지 전용** |

⚠ 지금 `R = 4` 하나로 전부 쓰고 있다(`tokens.ts`). `R_CARD`를 새로 내보내고 카드류만 갈아탄다. **뱃지는 종류에 따라 갈린다** — 아래 2-4.

### 2-2. 층 — 그림자가 아니라 면으로

| 층 | 배경 | 테두리 |
|---|---|---|
| 페이지 | `#f6f7f9` | — |
| 카드·패널 | `#ffffff` | `1px #e2e5ea` |
| 표 머리·라벨 셀 | `#f7f8fa` | 아래 `1px #e2e5ea` |
| 선택된 카드 | `#ffffff` | `2px #1B2A4A` + **그림자 1단** |

그림자는 **선택 상태 하나에만**. `0 1px 2px rgba(15,27,53,.06)` 한 값만 쓴다. hover로 카드가 뜨지 않는다.

### 2-3. 색 — 늘리지 않는다

| 이름 | 값 | 뜻 |
|---|---|---|
| 브랜드 네이비 | `#1B2A4A` | 선택·주버튼·강조. **면으로 쓰고 글자색으로 남발하지 않는다** |
| 글자 | `#18181b` / `#52525b` / `#8a8f98` | 본문 / 보조 / 흐림 |
| 선 | `#e2e5ea` (기본) / `#edf0f3` (약한 선) | |
| 상태 | 초록 `#0e9f6e` · 주황 `#b45309` · 빨강 `#e02424` | 뱃지 글자·테두리에만. 큰 면으로 칠하지 않는다 |
| 틴트 면 | 네이비 `#e8f0ff` · 주황 `#fff7ed` · 초록 `#ecfdf5` | 뱃지 바탕·선택 칩 |

### 2-4. 뱃지 — 모양이 종류를 말한다

| 종류 | 모양 | 예 | 형태 |
|---|---|---|---|
| **상태** | **알약**(999) | 즉시출고·출고협의·계약중·출고불가 | 틴트 바탕 + 같은 계열 글자 + 1px 테두리 |
| **분류** | **사각**(4) | 중고렌트·신차구독·무심사 | 흰 바탕 + `#52525b` 글자 + `#e2e5ea` 테두리 |
| **혜택** | **사각**(4) | 분납·무보증·무사고·만21세 | 흰 바탕 + 네이비 글자 + 네이비 테두리 |

자리도 정한다: **사진 바로 밑 한 줄 = 상태·분류** / **본문 안 한 줄 = 혜택**. 섞지 않는다.

### 2-5. 글자·굵기 (현행 유지 — 바꾸지 말 것)

`FS` 6단(18 / 14.5 / 13 / 12 / 11 / 10) · `FW` 최대 **700**. 800·900 금지.
숫자는 전부 `tabular-nums`.

### 2-6. 컨트롤

| | 웹 | 모바일 |
|---|---|---|
| 버튼·칩·입력 높이 | 32 | 36 |
| 상단바·하단바 | 56 | 56 |

필터칩 켜짐 = **틴트 면 `#e8f0ff` + 네이비 글자 + 네이비 테두리**(네이비 채움은 너무 시끄럽다).

## 3. 화면 A — 상품 목록

```
┌─────────────────────────────────────────────┐
│ 검색  [전체 6][즉시출고][출고가능][계약중]  [최신] [격자|표] │  56 고정
├─────────────────────────────────────────────┤
│ ┌───────────┐ ┌───────────┐ ┌───────────┐   │
│ │  사진 2:1  │ │           │ │           │   │  카드 8px
│ ├───────────┤ │           │ │           │   │
│ │ ●즉시출고 중고렌트 무심사 │ ← 상태(알약)+분류(사각) 한 줄
│ │ 현대 그랜저 GN7 2.5 …    │ ← 14.5 / 650
│ │ 파노라마 빌트인캠 20인치휠 │ ← 옵션 사각칩(최대 4 + …)
│ │ 2024 · 12,400km · 가솔린 │ ← 12 / #52525b
│ │ 분납 무보증 무사고        │ ← 혜택(사각·네이비)
│ ├───────────┤
│ │ 598,000원  48개월 · 36개월 612,000원 │ ← 금액 18/700, 뒤는 12/#8a8f98
│ └───────────┘
```

- 카드 = 흰 면 + `1px #e2e5ea` + `8px`. 선택 시 `2px #1B2A4A` + 그림자 1단.
- **금액 줄은 카드 바닥에 붙인다** — 카드 높이가 달라도 금액 위치가 같아야 6장을 세로로 비교할 수 있다.
- 사진 없음 = 사선 패턴 + 「사진 준비중」(현행 유지).
- 값이 없으면 `-` 한 글자(빈칸 금지).

## 4. 화면 B — 상품 상세

- **라벨 폭 116px 고정**(전 화면 공통). 라벨 `12/#52525b`, 값 `13/#18181b`.
- 섹션 머리 = **세로 바 3~4px 네이비 + 제목 14.5/700**. 아이콘 없음.
- 영업자 전용 블록 = **좌측 네이비 4px 바 + 흰 면**(권한이 다른 정보라는 표시).
- 대여료 표 = 표 머리 반전(`#1B2A4A` 바탕 / 흰 글자), 최저가 행 강조 1줄.

## 5. 계약서 A4 — 잔여 3건

1차 반영(표지 요지 4칸 · 빈칸 3규칙 · 섹션 24/12 · 핵심표 · 문단블록)은 커밋 `3c412c3`에 들어갔다. **렌더해서 확인한 남은 문제**:

| # | 문제 | 고칠 것 |
|---|---|---|
| C1 | **표지 하단이 여전히 백지** — 요지 4칸이 위쪽에 몰려 그 아래 ~500px 공백 | 요지 4칸을 표지 **세로 가운데**로 내리거나 당사자 박스를 위로. 인쇄 1페이지에 «위–가운데–아래» 세 덩어리가 고르게 놓이게 |
| C2 | **요지 「대여기간」 칸이 3줄로 깨짐** — 「차량 인도일로부터 36개월」이 통째로 들어감 | 표지 요지는 **「36개월」만**. 기준일 설명은 본문 03에 이미 있다 |
| C3 | **03 대여 조건 표 안에서 글자 크기가 흔들림** — 「차량 인도일로부터 36개월」·「만기 반납·인수 별도 협의」·「본인+직계가족」만 작게 나옴 | pt/px 혼용 정리. **한 표 안에서는 한 크기**. 이전보다 나빠 보이는 유일한 지점이라 반드시 잡는다 |

덤: 9→10페이지가 됐다. C1을 고치면 표지가 정리되며 되돌아올 여지가 있다. **10페이지를 넘지 않는 것**을 목표로.

## 6. 손님 서명 화면 (12단계)

`DESIGN_BRIEF_ESIGN_2026-08-20.md` 4장 그대로. 요지만:

- 12단계를 **①확인 ②작성 ③동의·서명** 3묶음 스텝퍼로 얹는다.
- 모든 단계가 같은 4층: 머리띠(고정) / 안내 한 줄 / 본문 / CTA(고정).
- 「이전」은 테두리만, 「다음」은 채운 면 + 3배 폭.
- 필수는 `*` 대신 **「필수」 태그**.
- 긴 문단은 **한 줄 요지 + 접힘 상세**(원문은 접힘 안에 전문 그대로).
- 라벨–값 비율·색·모서리를 **A4와 같은 값**으로.

## 8. 수용 기준 (검증용)

**공통**
- [ ] `fontSize`·`borderRadius`·`boxShadow`에 **숫자 하드코딩이 없다**(전부 토큰)
- [ ] 굵기 700 초과가 없다
- [ ] 새 색이 2-3 표 밖에서 생기지 않았다
- [ ] `npm run check:ui` · `check:tokens` 통과
- [ ] 그림자는 **선택 상태 한 곳**에만 쓰인다

**목록·상세**
- [ ] 상태 뱃지는 알약, 분류·혜택은 사각이다
- [ ] 금액 줄이 카드 바닥에 붙어 6장이 같은 높이에서 비교된다
- [ ] 상세 라벨 폭이 전 섹션 116px로 같다
- [ ] 모바일 390px에서 가로 스크롤이 없다

**계약서**
- [ ] `data-field` **217개 이상** 유지(`grep -c`)
- [ ] 한 표 안에서 글자 크기가 하나다
- [ ] 인쇄 10페이지 이하
- [ ] `sim-esign-snapshot`·`sim-esign-field-map`·`sim-esign-compliance`·`sim-freepass-esign`·`check:template-drift` 통과
- [ ] 계약 조문·항목·값이 한 글자도 안 바뀌었다
