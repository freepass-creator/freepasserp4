## 4. 흉내 내면 «안 되는» 것 — 우리에게 데이터가 없다

케이카는 상세의 절반을, 엔카는 세 섹션을 **진단·이력·보증**에 쓴다. 우리는 실측 0%다
(`accident_history` 0 · `transmission` 0 · `location` 0 — 화이트리스트에는 있으나 값이 없다).

> 사장님 2026-09-05 「우리는 사고 관련된 거는 그렇게 중요하지 않아.」

우리는 파는 게 아니라 빌려주는 판이다. 그 자리를 대신하는 것이 **대여 조건**(보험 면책·약정주행·
연령·납부)이고, 그건 우리가 30항목을 갖고 있다. **남의 신뢰 장치를 흉내 내지 말고 우리 것을 편다.**
