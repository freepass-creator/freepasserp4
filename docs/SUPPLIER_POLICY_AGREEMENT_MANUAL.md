# 프리패스 공급사 계약정책 확인·동의 매뉴얼

문서 버전: 2026-08-10 v1  
적용 기본정책: `freepass-standard-2026-08-10-v1`

> 이 문서는 프리패스 ERP에서 공급사 상품의 견적·계약서를 작성할 때 사용하는 정책을 확인하기 위한 운영 문서다. 공급사의 개별 계약서, 보험·공제 약관 또는 별도 합의가 이 문서와 다르면 계약 발행 전에 반드시 수정한다. 실제 고객에게 사용할 계약 문안과 동의 방식은 대표자·법무 검토 후 확정한다.

## 1. 왜 확인받는가

정책은 단순 안내가 아니라 고객 견적과 계약서에 들어가는 조건이다. 특히 초과 주행요금, 중도해지 위약금, 연체 시 조치, 보험과 자기부담금은 분쟁이나 정산금액에 직접 영향을 준다.

프리패스가 공급사를 대신해 계약서를 작성하려면 다음 세 가지가 명확해야 한다.

1. 누가 계약서를 작성하는가
2. 어떤 조건을 고객 계약에 적용하는가
3. 공급사가 프리패스 기본정책을 그대로 사용할지, 일부를 변경할지

## 2. 공급사가 선택할 계약 방식

공급사는 아래 중 하나를 선택한다.

- **A. 프리패스 기본정책 전체 동의**: 별도 기재가 없는 항목에 프리패스 기본정책을 적용하고 프리패스가 계약서를 작성한다.
- **B. 일부 수정 후 동의**: 아래 변경표에 적은 항목만 공급사 정책으로 대체하고, 나머지는 프리패스 기본정책을 적용한다.
- **C. 공급사 자체 계약**: 공급사가 자체 계약서와 약관으로 계약한다. 프리패스 전자계약은 발행하지 않으며 상품·영업 정보만 연동한다.

선택하지 않았거나 담당자의 권한을 확인할 수 없으면 실제 고객 계약을 발행하지 않는다.

## 3. 프리패스 기본정책

아래 값은 공급사가 별도 값을 명시하지 않았을 때 적용되는 기준이다. 공급사가 ERP에 직접 입력한 값이 있으면 그 값을 우선한다.

## 4. 기본정책과 별도로 반드시 확정할 공급사별 항목

다음은 상품이나 보험마다 달라질 수 있어 계약 전에 실제 값을 확인한다. 프리패스 기본정책 동의만으로 사실과 다른 값을 넣어서는 안 된다.

| 구분 | 반드시 확인할 항목 |
|---|---|
| 상품 | 약정 주행거리, 계약기간, 월 대여료, 보증금, 만기 인수가격 |
| 운전자 | 기본 연령, 연령 하향 여부, 면허 경력, 개인·사업자 운전자 범위, 추가운전자 수 |
| 보험 | 보험 포함 방식, 대인·대물·자손·무보험 보상한도, 보험사, 면책금 |
| 납부 | 결제방식, 보증금 분납, 카드 결제 가능 여부 |
| 서비스 | 정비상품, 긴급출동, 대차, 탁송비, 지정 정비점 |
| 내부 영업 | 심사기준, 신용기준, 수수료 환수조건 — 고객 계약서에는 노출하지 않음 |

보험증권·공제약관과 공급사 답변이 다르면 보험증권·공제약관을 기준으로 재확인하고 계약 발행을 보류한다.

## 6. 공급사 동의서

**계약 방식 선택**

- [ ] A. 프리패스 기본정책 전체에 동의하며 프리패스가 계약서를 작성한다.
- [ ] B. 변경 요청표의 항목을 제외한 프리패스 기본정책에 동의하며 프리패스가 계약서를 작성한다.
- [ ] C. 공급사가 자체 계약서를 작성하며 프리패스 전자계약을 사용하지 않는다.

**확인사항**

- [ ] 당사는 고객에게 제공하는 상품·보험·면책·정비 조건과 위 내용을 대조했다.
- [ ] 당사는 프리패스가 확정된 정책을 견적서·계약서·전자서명 화면에 표시하는 것에 동의한다.
- [ ] 정책이 변경되면 적용 전에 변경내용과 시행일을 프리패스에 서면으로 통지한다.
- [ ] 이미 체결된 계약에는 변경 정책을 소급 적용하지 않는다는 점을 확인한다.
- [ ] 본 동의자는 공급사를 대표하거나 계약정책을 승인할 권한이 있다.

## 7. 프리패스 내부 등록 절차

1. 공급사에 이 문서와 현재 계약서·약관 사본을 함께 전달한다.
2. 공급사 코드와 대상 상품군을 명확히 적어 회신받는다.
3. 서명자 또는 승인자의 권한과 사업자 정보를 확인한다.
4. A는 기본정책을 적용하고, B는 변경 요청값만 ERP 정책에 입력한다.
5. C는 `계약서 작성=공급사가 작성`으로 등록해 프리패스 전자계약을 차단한다.
6. 보험·공제 조건은 증권 또는 공식 안내자료와 대조한다.
7. ERP 계약 미리보기에서 금액·기한·보험·해지 조건을 2인 확인한다.
8. 동의 문서 원본, 정책 버전, 적용일, 승인자를 감사기록과 함께 보관한다.
9. 실제 고객 발행 전 최종 승인 게이트를 통과한다.

## 8. 정책 변경 관리

- 기본정책 변경 시 패키지 버전을 새로 만든다. 기존 버전의 의미를 바꾸지 않는다.
- 공급사에는 변경 전후표, 시행일, 기존 계약 적용 여부를 다시 안내한다.
- 금액·요율·보험·해지 기준 변경은 새 동의를 받은 뒤 적용한다.
- 계약 체결 시점에 사용한 정책 버전과 실제 확정값을 계약에 고정해 둔다.
- 전화 동의만으로 변경하지 않는다. 이메일, 전자서명 또는 서명 문서처럼 사후 확인 가능한 기록을 남긴다.

## 9. 공급사 안내용 짧은 문구

> 프리패스 전자계약에 적용할 계약정책 확인을 요청드립니다. 첨부 문서의 기본정책을 검토하신 뒤 ① 전체 동의, ② 일부 수정 후 동의, ③ 공급사 자체 계약 중 하나를 선택해 회신해 주세요. 보험·면책·정비 조건은 실제 가입 내용과 반드시 대조해 주시고, 다른 항목은 변경 요청표에 정확한 금액·기한·범위를 적어 주세요. 회신과 내부 확인이 완료되기 전에는 해당 정책으로 고객 계약을 발행하지 않습니다.
