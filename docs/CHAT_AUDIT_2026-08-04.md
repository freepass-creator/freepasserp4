## 남은 실제 결손 — 6건, 전부 사람 문제

`agent_channel_code` 없는 방 6건. 이건 진짜다 — 채널 관리자 조회에서 빠진다.

| 방 | 메시지 | 영업자 | 회원 채널 |
|---|---:|---|---|
| `CH_RP030_125호9126_SP001` | 0 | 최사랑 | **SP001** — 유도 가능 |
| `CH_PT-0023_109호2155_…` | 0 | 박영협 | 없음 |
| `CH_PT-0023_109호2306_…` | 0 | 박영협 | 없음 |
| `CH_RP012_175부9064_usr_admin` | 3 | 박영협 | 없음 |
| `CH_RP023_145더5824_…` | 1 | 박영협 | 없음 |
| `CH_RP023_273가2149_…` | 0 | 박영협 | 없음 |

**5건이 박영협 한 사람**이고, 그 회원의 `agent_channel_code` 자체가 비어 있다.
`docs/MEMBERSHIP_AUDIT_2026-08-04.md` §1 의 「채널 없는 45명」 중 하나다.
그리고 같은 사람이 공급사 감사에서 **`company_code = RP003`(삭제된 파트너)** 로도 잡혔다.

→ **방을 고칠 게 아니라 회원을 정리해야 한다.** 회원 채널이 정해지면 방은 그 값으로 따라간다.
방에만 채널을 박아 넣으면 회원과 어긋나 다음 방이 또 비게 된다.

최사랑 1건은 회원이 `SP001` 이라 유도 가능하지만, 메시지 0건인 빈 방이라 급하지 않다.

## 메시지 0건인 방 81건

문의방을 만들고 대화를 안 한 것이다. `deal.ts:95` 의 「방 보장 — 매물×문의자 결정키」 구조상
매물 상세를 열거나 문의를 시작하면 방이 먼저 생긴다. **정상 동작**이며 결함이 아니다.
다만 목록에 빈 방이 쌓이면 영업자 화면이 지저분해지므로, 표시 정책(메시지 0건 숨김 또는 하단 정렬)은
UI 판단 사항으로 남긴다.
