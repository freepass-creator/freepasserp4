# F01 상품리스트·천이·ERP 정합 운영 매뉴얼

## 1. 기준과 순서

정본은 언제나 왼쪽이다.

```text
공급사 정제칸 → F01 판매시트 4탭 → 천이시트 → ERP(v4/products) → 상품찾기
```

F01의 발행 탭은 `상품리스트 → 손오공구독 → 픽업구독 → 오플구독` 순서다.
차량의 동일성은 **차량번호**이며, 같은 차량번호가 두 탭에 있으면 발행을 중단한다.

## 2. 매 실행 필수 대조

1. 정제칸 ↔ F01: 차량번호, 배차상태, 제조사·모델·세부모델·세부트림, 사진, 기간별 대여료.
2. F01 ↔ 천이: 발행 대상 차량번호·상태·대여료·사진. 천이의 카드 수가 맞아도 다른 차량 카드가 있으면 실패다.
3. F01 ↔ ERP: 차량번호 집합, 상태, 차종 4축, 원문 차명·옵션, 사진, 가격, 정책코드.
4. ERP ↔ 상품찾기: ERP 상태가 상품찾기 노출 규칙과 일치하는지 확인한다.

## 3. 불일치 종류와 처리

| 불일치 | 원인 위치 | 자동 처리 | 금지 |
|---|---|---|---|
| F01에만 있음 | ERP 유입 누락 | ERP 신규 등록/동기 | 원본·정제칸 수정 |
| ERP에만 있음 | F01에서 제거·계약·옛 재고 | 계약/잠금 확인 뒤 출고불가 처리 | 삭제, 출고가능으로 자동 복귀 |
| F01 값과 ERP 값 다름 | ERP 동기 지연 또는 변환 오류 | F01 값으로 ERP 갱신 | 정제칸 값 추정·치환 |
| 정제칸과 F01 값 다름 | 발행 누락 | F01 재발행 | 정제칸 덮어쓰기 |
| 천이 카드가 다름 | 카드 발행 누락/잔존 카드 | 카드시트 재발행 | 다른 공급사 카드 덮어쓰기 |
| 계약중/계약완료 | 정산원장/계약엔진 | 계약중 유지, 인도·계약완료는 출고불가 | 취소·환수만으로 자동 재판매 |

## 4. 판정 기준

- F01 차량번호 중복은 0이어야 한다. F01 합계에서 임의의 “중복 제거”를 하지 않는다.
- ERP 활성 재고 총수는 참고값이다. 정합 기준은 **F01 차량번호 집합과 ERP의 같은 차량번호 집합**이다.
- 계약 잠금, 계약중, 출고불가 차량은 삭제하지 않는다. 원본 근거가 없는 복귀는 사람이 공급사 정제칸에서 한다.
- 차량번호가 없거나 원본·정제칸을 읽지 못한 공급사가 하나라도 있으면 해당 실행은 반영 실패다.

## 5. 보고 형식

매 실행은 탭별 차량 수, F01 차량번호 중복, F01→ERP 누락, ERP→F01 초과, 핵심값 불일치,
천이 카드 불일치, 계약 잠금 예외를 남긴다. 변경이 있으면 대상·필드·원본 근거·재검증 결과를 기록한다.
