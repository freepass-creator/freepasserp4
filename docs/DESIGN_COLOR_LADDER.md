# 색·무게 설계표 — 상품 목록 / 상세 / 영업자 패널

사장님 2026-08-20 「니가 임기응변을 하잖아」 — 지시마다 한 곳씩 고치다 앞 결정을 뒤집는 일이 반복돼
**표를 먼저 박고 코드를 여기에 맞춘다.** 이 문서가 정본이고, 화면은 따라온다.

## 1. 색은 하나다 — 네이비. 다른 건 «세기»뿐

새 색상(hue)을 들이지 않는다. 초록·앰버로 섹션을 칠해 봤다가 무지개가 돼서 되돌렸다.
쓰는 색은 **네이비(`--brand` #1B2A4A)** 와 그 짝인 **스카이(`--sky` #9EC5F3)**, 그리고 무채뿐이다.

### 세기 사다리

| 단 | 표현 | 값 | 쓰는 자리 |
|---|---|---|---|
| **1 강** | 반전 — 네이비 면 + 흰 글자 | `C.brand` / `C.inverse` | 본문 **중요 섹션 머리띠**(차량스펙·대여료조건) |
| **2 중** | 연한 네이비 면 + 네이비 굵은 글자 | `--bg-selected` / `C.brand` | **선택된 줄**(대여료 표) |
| **3 점** | 네이비 글자·채움 | `C.brand` | 카드 **금액**, 「최저」 칩, 딱지 |
| **4 약** | 스카이 연한 면 | `--sky-bg` / `--sky` 55% | **영업자 패널** 머리띠 |
| **5 무** | 내려앉은 회색 면 | `--bg-sunken` / `C.line` | 본문 부가 섹션(보험·계약) |
| **6 침묵** | 흐린 무채 | `C.head` / `C.line2` / `C.faint` | 식별 섹션(기타사항) |

**한 섹션 안에 같은 단이 두 번 오지 않는다.** 머리띠가 1단이면 그 안의 선택 줄은 2단이다.
(반전 머리띠 + 반전 선택줄로 뒀다가 «한 섹션에 반전이 둘»이 되어 내렸다.)

## 2. 자리별 — 이 표에 없는 곳은 색을 쓰지 않는다

### 목록(카드·행)

| 자리 | 색 | 모양 |
|---|---|---|
| 카드 면·테두리 | `C.taupeBg` / `C.line` | 모서리 **8**(`R_CARD`) |
| 썸네일 CORE 뱃지(상태·유형·심사) | 상태 틴트, frosted | 모서리 **4**, 높이 20 |
| 혜택 뱃지(분납·무보증…) | 면 `--bdg-gray-bg` · **글자 `C.ink`** · 굵기 650 | 모서리 **4**, 높이 20 |
| 기간칩 | 꺼짐 `C.head`/`C.mute` · **켜짐 `C.brand`/흰 글자** | 모서리 **4**, 높이 20 |
| 금액 앵커 | **`C.brand`** (짚는 중 `C.brandDeep`) | 18px · 700 |
| 보증금·부가 | `C.faint` | 11px |

혜택 뱃지를 흐리게 죽이지 않는다 — 영업사원이 카드에서 가장 먼저 찾는 값이다.

### 상세(본문)

| 자리 | 색 |
|---|---|
| 섹션 카드 | 흰 면 · `C.line` · 모서리 **8** |
| 머리띠 — 차량스펙·대여료조건 | **1단 반전 남색** |
| 머리띠 — 보험조건·계약조건 | 5단 회색 면(`--bg-sunken`) |
| 머리띠 — 기타사항 | 6단 흐린 무채 |
| 대여료 선택 줄 | **2단** 연한 남색 면 + 남색 굵은 글자 |
| 「최저」 칩 | 3단 남색 채움 · 모서리 4 |
| 보험 보장한도 | 값만 14.5px (색은 안 씀) |

### 영업자 패널

| 자리 | 색 |
|---|---|
| 패널 머리 | 흰 박스 + 「**손님 비공개**」 연한 남색 딱지 |
| 대여료 카드 | 흰 카드 + 네이비 머리 한 줄 |
| 영업 정보 · 계약 조건 머리띠 | **4단 스카이 연한** |
| 몸통 | 흰 면 — 본문 섹션과 같음 |

패널은 «참고하는 곳»이다. 본문보다 세지 않는다.

## 3. 모양 — 하나로 통일

- **뱃지·칩·딱지는 전부 사각(모서리 4).** 알약(999) 금지. 한 줄에 모양이 섞이면 «뜻이 다르다»가 아니라 «규격을 안 맞췄다»로 읽힌다.
- **카드·패널만 모서리 8.** 담는 것과 담기는 것이 갈려야 층이 생긴다. 3단(12/8/4)은 B2B 밀도에 과하다.
- 뱃지 높이 20 · 좌우 7 · 글자 10.
- 컨트롤 높이 32(웹) / 36(모바일). 바 56.

## 4. 안 쓰는 것 — 시도했다가 되돌린 것들

| 무엇 | 왜 뺐나 |
|---|---|
| 알약 뱃지 | 사각과 섞이니 규격 미준수로 읽힘 |
| **좌측 4px 바** (영업자 블록·선택 줄) | 블록을 «감싸» 인용문처럼 읽힘 |
| 섹션별 다른 색상(초록=보장·앰버=의무) | 스크롤하면 무지개, 정작 중요도가 안 보임 |
| 영업자 패널 전면 반전 | 참고하는 곳이 본문보다 셌음 |
| 앰버를 영업자색으로 | 「주의·수기입력」과 뜻이 겹침 |
| CORE 뱃지를 사진 밑 별도 띠로 | 카드마다 28px 낭비. 우리는 이미 우하라 차 정면을 안 가림 |
| 섹션 머리 세로 바 | 섹션을 «구분»하지 못함. 아이콘이 그 일을 함 |

---

## 5. 바꿀 때 규칙

1. 색을 새로 들이지 않는다. 세기 사다리에서 고른다.
2. 한 자리를 고치면 **같은 단을 쓰는 다른 자리**도 같이 본다.
3. 이 문서를 먼저 고치고 코드를 맞춘다. 반대로 하지 않는다.
