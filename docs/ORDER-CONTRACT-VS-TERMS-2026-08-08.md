## 0. 왜 고치는가

사장님 지적(2026-08-08): **「계약서는 숫자 위주, 약관은 설명 위주. 약관이 앞의 계약내용을 보완 설명한다.」**

지금 `buildConsentGroups` 는 세 가지를 한 통에 담아 손님에게 보낸다.

1. **계약 확정값** — 월 대여료 1,000,000원 · 대여기간 48개월 ← 계약서가 맞다
2. **규칙 서술** — 「10일 연체 시 계약은 자동 해지되며…」 ← **약관에 이미 있다. 중복이다**
3. **상품 정책·안내** — 「심사기준: 중신용 이상」 ← **계약서 원자가 아니다. 나가면 안 된다**

실물 계약서(`public/contract-template/rental-contract.html`)는 이미 올바른 형태다.
값 + 한 줄 경고 + **`(약관 제5조)` 포인터**를 쓰고, 규칙 전문은 약관에 둔다. 그 참조가 본문에 7곳 박혀 있다.

> 「등록되지 않은 자의 운전 중 사고는 모든 담보 보험 적용이 제외되며 전액 계약자 부담입니다. **(약관 제5조)**」

---

## 1. 판정 기준 — 길이가 아니라 «값이냐 서술이냐»

> **계약서는 대부분 단답이다. 약관이 그 계약서를 보완해 서술한다.**
> 계약서를 읽으면 «이 계약이 어떤 조건인가»에 답이 나오고,
> 약관을 읽으면 «그 조건이 어떻게 적용되는가»에 답이 나온다.
> 같은 내용을 양쪽에 쓰지 않는다 — 계약서에 단답, 약관에 설명.

| | 계약서 | 약관 |
|---|---|---|
| 형태 | 숫자·금액·기간·고유명사·선택된 항목 | 주어+서술어로 규칙을 말하는 문장 |
| 예 | `48개월` `1,000,000원` `만 26세 이상` `연 5회` | 「대차서비스 지원 불가 합니다」 |
| 판정 | **이 계약에만 해당하는 값인가** | **모든 계약에 같이 적용되는 규칙인가** |

「대차서비스 지원 불가 합니다」는 16자로 짧지만 규칙이다. **길이로 가르지 말 것.**

## 2. 항목별 처분

### 2-1. 계약서에 남긴다 (값)

| 묶음 | 항목 |
|---|---|
| 본인정보 | 성명 · 연락처 · 생년월일 · 주소 |
| 차량정보 | 차량번호 · 차량 · 세부모델 · 트림 · 연식 · 연료 |
| 대여조건 | 대여기간 · 월 대여료 · 보증금 · 약정 주행거리 · 초과 주행요금\* · 현재 주행거리 · 보증금 분납\* |
| 결제 | 대여료 결제주기 · 자동이체일\* · 계산서 발행 · 중도해지 위약금 |
| 운전자 | 운전자 연령 · 면허 경력요건 · 운전자 범위\* · 추가운전자 인원 |
| 보험 | 가입 주체 · 대인/대물/자손/무보험 보상한도 · 각 면책금 · 자차 보상·자기부담률·최소/최대 면책금 · 긴급출동 |
| 사고·면책 | 면책금(고객부담금) — 연령 파생 확정값 |
| 정비 | 정비상품 · 검사 주기 · 서비스품목 |

\* 표시는 §2-2 처리가 필요하다.

### 2-2. 값인데 «미확정»으로 나가고 있다 — 확정값으로 바꾼다

> **정책에서 왔다는 이유로 빼지 않는다.** 계약 확정 전에 이미 조건 지어진 요율은
> 이 계약의 값이므로 **숫자로 계약서에 싣는다.** 빼야 할 것은 «선택지·가능성·내부기준»이다.
> 예: `초과 주행요금 : 1만km당 100,000원` — 확정 요율이므로 **그대로 둔다.**
> 약정 주행거리를 넘겼을 때 얼마를 내는지는 손님이 계약서에서 숫자로 알아야 한다.

| 항목 | 지금 | 고칠 것 |
|---|---|---|
| 보증금 분납 | `3회 분납 가능` | 「가능」은 선택지다. **확정 회차**(일시납 / 2회 / 3회)를 보낼 것 |
| 자동이체일 | `출고일 기점으로 고정 (변경불가)` | **모순**: 계약서는 「변경불가」인데 `inputRequests` 는 5·10·15·20·25일 중 **고르라고 한다.** 둘 중 하나가 틀렸다 |
| 운전자 범위 | 개인용·사업자용이 **둘 다** 나감 | 이 계약의 유형에 맞는 **하나만** |

### 2-3. 서술을 «단답»으로 환원한다 (사장님 지시 2026-08-08)

**서술문을 통째로 약관에 넘기지 않는다.** 그 안에 담긴 «답»을 뽑아 계약서에 단답으로 남기고,
설명은 약관에 둔다. 손님이 「대차 되나?」를 **계약서에서 바로** 알 수 있어야 한다.

> 「대차서비스 지원 불가 합니다」 → 계약서 `대차서비스 : 없음` + 약관 제7조

| 지금 (서술) | 계약서 단답 | 약관 |
|---|---|---|
| 대차서비스 지원 불가 합니다 | **대차서비스 : 없음** | 제7조 |
| 정비 상품 — 지정 정비점 내방 정비만 인정… | **정비서비스 : 미제공** | 제7조 |
| 차량점검 필수 가입 / 12개월 뒤 엔진오일… | **엔진오일 : 연 1회 지원** | 제7조 |
| 만기 반납이 아니면 탁송료 고객 부담 | **반납 탁송료 : 고객 부담** | 제6조 |
| 3일 연체 시 시동제어, 10일 자동 해지 | **시동제어 : 연체 3일** · **계약 해지 : 연체 10일** | 제11조 |
| 보증금 반환은 반납 후 확인 뒤 1주일 안에 | **보증금 반환 : 반납 후 7일 이내** | 제4조 |
| 지급명령 신청일부터 연 5%, 이후 연 12% | **지연손해금 : 연 5% / 12%** | 제3조 |
| 1년 이내 과실 50% 이상 사고 3회 누적 시 해지 | **사고 누적 해지 : 1년 3회** | 제9조 |
| 경찰 신고·현장 출동 없는 사고는 처리 불가 | **사고 처리 조건 : 경찰 신고 또는 현장 출동** | 제9조 |
| 중과실 자차사고 수리금액 20% 추가납부 | **중과실 자차 : 수리비 20% 추가** | 제9조 |
| 사고 수리 시 지정 협력 정비공장 입고 | **사고 수리 : 지정 정비공장** | 제9조 |
| 계약종료 30일 전까지 당사 승인 필요 | **연장 신청 : 종료 30일 전** | 제2조 |
| 정보 변경 시 먼저 연락, 두절 시 시동제어 | **연락처 변경 : 즉시 통지 의무** | 제12조 |
| 과태료·통행료 임차인 부담, 보증금에서 차감 | **과태료·통행료 : 임차인 부담** | 제18조 |
| GPS 불법 탈거 시 민·형사 고발 | **GPS : 장착** | 제10조 |

**단답으로 뽑아낼 값이 없는 문장만** 계약서에서 빼고 약관에만 둔다.
(예: 「임차인은 대여 약관에 동의하며…」 같은 총론 문장 — 값이 없다)

조항 번호는 `AGREEMENT_SECTIONS` 기준이다. 옮기기 전에 **해당 조에 그 내용이 실제로 있는지 대조**할 것 —
없으면 약관에 추가하는 것이 맞지, 계약서에 서술을 되살리는 것이 아니다.

### 2-4. 빼낸다 — 영업 단계의 것이 계약서에 실렸다

**「~ 가능」은 영업 단계의 말이다.** 「만 21세까지 하향 가능」·「3회 분납 가능」은
손님이 상품을 고를 때 듣는 말이지, 계약이 확정된 뒤 서명 화면에 있을 말이 아니다.
계약서에는 **「이 계약은 만 26세 이상」·「보증금 3회 분납」** 처럼 굳은 값만 온다.

아래는 `FIELD_MAP` 141개 원자에 **아예 없는** 항목들이다.

| 항목 | 지금 값 | 정체 | 처분 |
|---|---|---|---|
| **심사기준** | `중신용 이상` | **내부 심사 기준** | 뺀다 — 고객 노출은 사고다. **최우선** |
| 대여지역 | `전국` | 상품 안내 | 뺀다 |
| 탁송비 | `탁송비 별도` | 금액이 아니다 | 실제 금액이 확정됐으면 숫자로, 아니면 뺀다 |
| 연령 하향 | `만 21세까지 하향 가능` | **선택지** | 뺀다 |
| 연령 하향 비용 | `월 55,000원` | 조건부 옵션 요율 | **이 계약에서 하향했으면** 확정값으로 남기고, 아니면 뺀다 |
| 추가운전자 비용 | `월 50,000원` | 조건부 옵션 요율 | **추가운전자를 실제 지정했으면** 확정값으로 남기고, 아니면 뺀다 |

핵심은 **「가능·선택 가능」이 아니라 「이 계약은 이렇다」**로 적히는가다.
조건부 요율은 이 계약에서 그 조건을 **선택했을 때만** 확정값이 되어 실린다.
선택하지 않았으면 그 줄은 존재하지 않는다 — 빈칸을 「—」로 채우지 않는 것과 같은 이유다.

### 2-5. 중복 제거

`기본 운전자 연령` · `추가운전자` 가 **운전자 묶음과 보험 묶음에 두 번** 나온다. 한 곳만 남긴다.

## 3. 계약서 → 약관 포인터

계약서 값에 관련 조항을 달아 손님이 규칙을 바로 찾을 수 있게 한다. 실물 계약서가 이미 쓰는 방식이다.

```ts
{ label: '약정 주행거리', value: '연 30,000km', article: '제15조' }
{ label: '중도해지 위약금', value: '잔여 대여료의 30%', article: '제14조' }
{ label: '운전자 범위', value: '계약자와 배우자 및 직계가족', article: '제5조' }
```

착한거래 렌더러는 `article` 이 있으면 값 옆에 조항 배지를 띄운다. 없으면 그냥 값만 그린다 — 하위호환.

## 4. 역방향 의존 — 약관이 계약서 값을 참조한다

> 약관 제1조: 「대여 차량의 차종 및 대여 요금은 **본 계약서 [계약내역]의 [차종&옵션 및 월대여료총액]에 의하며**」

**계약서 값이 비면 약관이 공중에 뜬다.** `FIELD_MAP` 에서 출처가 `미정` 인 원자가 **32개** 있고,
그중 약관이 직접 참조하는 것들이 있다.

| 미정 원자 | 참조하는 약관 |
|---|---|
| 인도 일시 · 인도 장소 · 인도 담당자 · 인도 시 연료량 · 인도 시 손상 | 제6조 차량 인도·인수 |
| 연대보증인 성명·연락처·주소·관계·직업·보증한도 | 제20조 연대보증 |
| 반납 일시 · 반납 주행거리 · 반납 연료량 · 반납 손상 | 제6조 |

이번 오더 범위는 아니지만, **실계약을 태우기 전에 채울 경로를 정해야 한다.**

## 5. 완료 기준

- [ ] `심사기준`·`대여지역`·`탁송비`·`연령 하향`·`연령 하향 비용`·`추가운전자 비용` 이 payload 에서 사라진다
- [ ] `초과 주행요금`·`보증금 분납` 이 **확정값**으로 나간다(「가능」·요율표 표현 없음)
- [ ] `운전자 범위` 가 계약 유형에 맞는 **하나만** 나간다
- [ ] `자동이체일` 의 계약서 표기와 `inputRequests` 가 서로 맞는다
- [ ] §2-3 의 서술 15건이 **단답으로 환원**되어 있다(「대차서비스 : 없음」 형태). 통째로 지워서도, 그대로 둬서도 안 된다
- [ ] 계약 화면에 **주어+서술어 문장이 남아 있지 않다** — 눈으로 훑어 확인할 것
- [ ] `기본 운전자 연령`·`추가운전자` 중복이 없다
- [ ] 착한거래 `/labs/esign` 에서 계약 화면이 **숫자 위주**로 보인다
- [ ] `rows[].value` 재포맷은 여전히 하지 않는다(착한거래는 받은 그대로 출력)

## 6. 주의

- **문구를 새로 짓지 말 것.** 약관 문구는 `esign-agreement-text.ts` 가 「손대지 않는다」고 박아둔 정본이다.
  규칙을 옮길 때 약관에 해당 내용이 없으면 **문구 신설이 필요하다는 뜻이고, 그건 법률 검토 대상**이다.
- 착한거래는 렌더러다. 여기서 걸러내지 않으면 그대로 손님에게 나간다.
- 이 오더는 «무엇을 보낼지»만 다룬다. 화면을 어떻게 그릴지는 착한거래 몫이다.
