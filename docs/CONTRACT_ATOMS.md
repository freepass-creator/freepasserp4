### 면책금은 운전자 연령에서 파생된다 (JPK)

정책의 면책금 단일값과 **맞지 않는다.** 계약서는 연령대별 3단이고 「운전자 연령 선택 시 자동입력」이라고 적혀 있다.

```
만 26세 이상   대인 30만 / 대물 30만 / 자차 20%, 최소 50만~최대 100만
(그다음 단)     대인 50만 / 대물 50만 / 자차 20%, 최소 70만~최대 120만
(그다음 단)     대인 60만 / 대물 60만 / 자차 20%, 최소 80만~최대 130만
※ 면허 취득 1년 이하는 면책금 추가
※ 중과실 12대 사고는 수리비 20% 별도 추가
```

## 6. 운전자 범위 — 5종 택1 (JPK)

```
[개인기본1]   계약자와 배우자 및 계약자와 배우자의 직계가족
[개인기본2]   계약자 외 지정 1인
[개인특약]    [개인기본1] + 형제자매 외 추가 지정 1인   ← 월 55,000원 추가
[개인사업자]  계약자와 계약자 사업장의 임직원
[법인]        법인 임직원 및 법인과 계약관계 업체 소속자
```

**[개인특약]은 월 55,000원이 붙는다** — 선택이 금액을 바꾸므로 대여료 확정 전에 물어야 한다.

## 10. 약관 (뒷면)

계약서 뒷면에 별도 약관이 붙는다. **본문과 별개 문서**이고, 손님은 이걸 통독하고 동의한다.

```
JPK   제1조 차종 및 대여요금 / 제2조 계약기간 / 제3조 계약조건(보증·담보) /
      제4조 대여료 정산 및 지급 / 제5조 운전자 자격 요건 / 제6조 차량의 인도 및 반납 /
      제7조 차량 보험 및 보상 / 제8조 금지 행위 / … 제10조 해지 / 제11조 멸실·훼손 원상회복 / …
손오공 [제1조] 차종 및 구독요금 / … [제5조] 운전자의 자격 / [제8조] 금지 행위 /
      [제10조] 해지 / [제11조] 차량의 멸실 및 훼손에 따른 원상회복의무 / …
```

조문 번호·표기가 회사마다 다르다(JPK `제1조` / 손오공 `[제1조]`). **문구를 합치지 말 것** —
「그대로 쓴다」가 원칙이다(2026-08-08 결정).

## 11. 두 층으로 갈린다 — 「조건의 정의」와 「이 손님이 고른 값」

이걸 섞으면 일이 커진다. 갈라 놓으면 대부분 **이미 있다.**

```
정책관리  = 이 상품의 조건이 무엇인가   (선택지·요율·한도의 정의)
계약      = 이 손님이 무엇을 골랐는가   (선택 결과)
재고      = 이 차가 무엇인가            ← 이미 다 있다. 그대로 쓴다.
```

**정책에 이미 있어서 새로 만들 필요 없는 것** (2026-08-08 실측, `entities.ts` policy 35필드):

| 계약서 항목 | 정책 필드 |
|---|---|
| 운전자 범위 | `personal_driver_scope` · `business_driver_scope` |
| 추가운전자 허용·비용 | `additional_driver_allowance_count` · `additional_driver_cost` |
| 보증금 분납 | `deposit_installment` · `deposit_card_payment` |
| 연령·하향·상한·비용 | `basic_driver_age` · `driver_age_lowering` · `driver_age_upper_limit` · `age_lowering_cost` |
| 면허 경력요건 | `license_period` |
| 약정주행·초과요금 | `annual_mileage` · `mileage_upcharge_per_10000km` |
| 위약금 | `penalty_condition` |
| 정비 | `maintenance_service` |
| 결제방식 | `payment_method` |
| 보험 한도·면책 13종 | `injury_*` · `property_*` · `self_body_*` · `uninsured_*` · `own_damage_*` · `annual_roadside_assistance` |

### 11-A. 정책관리에 **새로 필요한** 것 — 5개

| 추가할 필드 | 왜 | 지금 상태 |
|---|---|---|
| `deductible_by_age` | 면책금이 **연령대별 3단**인데 지금은 단일값 하나뿐(§5) | 없음 |
| `late_interest_rate` | 지연손해금 — JPK 5%/12%, 손오공 8%/18% | 없음 |
| `penalty_rate_table` | 중도해지 요율이 **인수형/반납형 × 기간 구간**(손오공 4단). `penalty_condition` 은 자유 텍스트라 계산에 못 쓴다 | 문자열만 |
| `insurance_provider_side` | **보험 가입 주체** — JPK=회사 / 손오공=고객 직접(질권설정). 이게 갈리면 보험 묶음 전체가 달라진다 | 없음 |
| `contract_type` | **인수형 / 반납형** — 손오공은 이 구분이 요율·잔가를 바꾼다 | 없음 |

> ★가장 급한 건 `insurance_provider_side` 다. 지금 손오공 계약에 우리 보험 묶음을 그대로 보내면
> **회사가 안 든 보험을 든 것처럼 보여준다.** 값이 비어서 안 보이는 게 아니라, 틀린 값이 보인다.

### 11-B. 계약에 **새로 필요한** 것 — 손님이 고른 값

정책이 「고를 수 있는 것」을 정하고, 계약이 「고른 것」을 담는다. 지금 담을 칸이 없다.

| 원자 | 누가 | 비고 |
|---|---|---|
| 운전자범위 선택값 | 손님 | 정책 `personal_driver_scope` 의 5종 중 택1. **[개인특약]은 월 55,000원 추가** |
| 추가운전자 성함·주민번호·관계·면허번호·연락처 | 손님 | 위에서 지정한 경우만 |
| 가족 연락처 + 관계 | 손님 | 개인 계약 필수 |
| 실거주지 | 손님 | 주소와 다를 때 |
| 상호·사업장소재지·사업자등록번호 | 손님 | 개인사업자일 때 |
| 자동이체일 | 손님 | 5·10·15·20·25 중 택1 |
| 보증금 분납 회차(1~3) | 관리자 | 정책이 분납 허용일 때 |
| 만기 인수가격 | 관리자 | 「만기협의」도 값 |

주민등록번호·면허번호는 **착한거래 본인확인**이 받으므로 여기 없다.
우리가 받으면 PII 보관 면적이 늘고 `ESIGN_CHAKHANDEAL_INTEGRATION.md` §3 원칙과 어긋난다.

### 11-C. 순서 문제 하나

**운전자범위 [개인특약]은 월 55,000원을 더한다.** 그런데 월 대여료는 약정에서 이미 동결된다
(`freezeContractTerm`, RTDB 규칙으로 재기입 차단). 손님이 계약서 단계에서 이걸 고르면 금액이 어긋난다.

→ **약정 단계에서 미리 정하는 것**이 맞다. 계약서에서는 고르는 게 아니라 «확인»만 한다.
   손님이 바꾸고 싶으면 약정으로 되돌아가야 한다.
