# 차종명명·정제 완성 실행계획 — 2026-08-29

## 목적과 완료 기준

목적은 공급사 원문에서 출발한 차량 신원이 F03·정제칸·F01·ERP까지 근거 없이 바뀌지 않게 하는 것이다.

아래 네 가지가 동시에 충족될 때만 `완료`로 판정한다.

1. 명명 규칙 소비처가 `docs/차종명명-정제-매뉴얼.md`와 일치한다.
2. 자동후보 전건은 **공급사 원문 + 연식 + F03 생산기간** 근거가 있다.
3. 검수대기는 추정 채움 없이 원문 보존 상태다.
4. 확정 차량은 정제칸 → F01 4탭 → 천이 → ERP에서 차량번호 기준으로 동일하다.

## 확정 규칙 (SSOT)

- 기준 문서: `docs/차종명명-정제-매뉴얼.md`.
- 엔카 표기 1:1, 기아의 세대명만 개발코드로 변환한다.
- `G80 DH` 인위 특례는 폐기되어 `G80`으로 쓴다. `G80 RG3`은 엔카 표기대로 유지한다.
- FL 표기는 쓰지 않는다.
- F03 기존 행은 동결이다. F03에 없는 새 세부모델만 3-AI 검토 뒤 Cursor가 추가한다.
- F03에 없거나 연식으로 한 후보가 확정되지 않으면 빈칸·검수대기다. F01·ERP에 추정값을 직접 쓰지 않는다.

## 반드시 고칠 드리프트

이 항목들은 F03 차량 데이터 변경이 아니라, 새 규칙을 아직 반영하지 못한 문서·코드다.

- F03 `안내` 탭: 예전 `G80 DH` 설명과 `차종마스터행수=1102`를 최신 규칙·실제 행수로 갱신.
- `docs/AI_OPERATING_MANUAL.md`, `docs/차종마스터-엔카작업시트-매뉴얼.md` 등 예전 규칙 문서: 새 SSOT를 참조하거나 규칙 교체.
- `lib/domain/submodel-normalize-f03.ts`, `lib/domain/vehicle-master-lock.ts`, `scripts/audit-encar-work-sheet.mts` 등 `G80 DH`를 특례로 전제하는 검사/자체검증: 새 F03 대조 방식으로 교체.
- 새 SSOT 안의 과거 백로그 문구(`G80 DH → G80 F03 반영`)는 이미 완료된 사실과 충돌하므로 완료 이력으로 정리.

## 감사기 안전 계약

`자동후보`가 되려면 다음을 모두 충족해야 한다.

1. 공급사 원문 차명 또는 승인된 원문 별칭에서 후보 표기가 직접 나온다.
2. 후보가 F03에 존재한다.
3. 차량 연식/최초등록이 F03 생산기간과 교차한다.
4. 원문/제공 제원이 F03 제원 허용값과 충돌하지 않는다.
5. 둘 이상의 F03 후보가 남지 않는다.

한 항목이라도 충족하지 못하면 `검수대기`다. 기존 정제 `세부모델` 값은 결과이지 증거가 아니므로 1번의 입력으로 사용하면 안 된다.

## 실행 게이트

Cursor 변경 후 Codex가 아래를 실행·기록한다.

```powershell
npx tsc --noEmit
npm run check:sync
npm run audit:axes
npm run audit:passthrough
npx tsx scripts/audit-refine-vs-master.mts
```

또한 다음 수치를 적용 전·후로 비교한다.

- 전체 차량 수 = 자동후보 + 검수대기 + 오류/충돌
- 자동후보 중 원문 근거 누락 = 0
- F03에 없는 세부모델을 자동 채운 수 = 0
- F01 4탭 ↔ ERP 차량번호별 재고·상태 불일치 = 0
- 가격·사진링크·차명 4축 불일치 = 0

하나라도 0이 아니면 F01/ERP 적용 금지, 해당 차량은 검수대기로 돌리고 원인만 보고한다.

## 엔카 대조의 이중 검증 규칙

- 엔카 대조는 **Codex와 Gemini가 반드시 함께** 수행한다. Codex 단독 의견은 시트에 반영하지 않는다.
- 대조 단위는 세부모델 묶음(제조사·모델·세부모델·생산기간)이며, 같은 묶음의 트림 행에는 같은 판정을 전파한다.
- Codex는 엔카 원문 화면/URL·F03 행·생산기간을 제시하고, Gemini는 같은 비식별 근거로 독립 반례를 찾는다.
- 둘 다 `맞음` 또는 둘 다 `틀림`일 때만 해당 행을 일괄 반영한다. 하나라도 `못정함`·불일치면 `못정함`으로만 기록하고 F03 데이터는 수정하지 않는다.
- 엔카의 현재 매물 수 0, 요청 제한, 검색 노출 부재는 `틀림` 근거가 아니다.

## 운영 이력 형식

매시간 다음을 `docs/crosscheck/정제-수확량-루프-YYYY-MM-DD.md` 또는 자동 실행 로그에 남긴다.

`시각 / 원본 버전 / 대상 건수 / 자동후보 / 검수대기 / 충돌 / F01 반영 수 / ERP 반영 수 / 불일치 수 / 적용 여부 / 실패 사유`

변경·오류·보류가 있으면 대상, 변경 전후값, 검증, 미해결 사유, 실제 외부 반영 여부를 포함해 보고한다.
