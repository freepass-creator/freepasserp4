**우리 `estimate.css` 와의 차이** — 글꼴·CI색은 맞고, 아래 셋이 다르다.

| | 원본 | 우리 | 판단 |
|---|---|---|---|
| 라운드 | 4·6·8·12 **네 단계** | `--r:4` **한 단계** | 카드는 `--r-md`(8) 자리다. 바꾸면 눈에 보인다 — **사장님 확인 필요** |
| 간격 | `--sp-*` 눈금 | 없음(8/10/12/13 손으로) | 눈금부터 넣고 천천히 옮기면 된다 |

| 중립색 | 순회색 | 푸른 기운(`#1a2230`…) | **목업이 준 값**이라 안 건드린다 |

## 2. 레이아웃 — 셋 다 «좌 400 고정»

```
손오공 견적  .board  grid  400px  1fr                       2기둥
손오공 원가  .board  grid  280px  minmax(360,.9fr)  minmax(440,1.1fr)   3기둥
웰릭스 견적  body    grid  400px  minmax(0,52fr)    minmax(0,20fr)      3기둥
```

웰릭스 CSS 에 못이 박혀 있다 — 「**좌(차량) 400px 고정 — 손오공 견적기와 좌패널 폭 통일.**
중(견적):우(채팅) = 52:20 잔여배분」. 톱바는 `grid-template-rows: 48px 1fr` 로 한 줄 통째.
`height:100vh; overflow:hidden` 이고 **기둥마다 제 안에서 스크롤**한다(`.vside`/`.main`/`.wrap` 전부 `overflow-y:auto`).

접히는 지점 — 손오공 **1000px**, 웰릭스도 같은 자리에서 `grid-template-columns: 1fr`.

## 3. 무엇이 어느 기둥에 있나 — ★가장 자주 틀리는 것

### 손오공 견적 (`App.vue`)

**좌 `.vside`(400)** — 차 고르기와 그 차의 «사실»이 전부 여기 박혀 있다. **모달이 아니다.**
1. 상품 — 세그 3층(`seg-t1/t2/t3`)
2. (신차) 제조사 → 모델 → 트림 · 신용등급
3. (구독) **매물 링크 불러오기** — 엔카·케이카·오토플러스·오토핸즈·헤이딜러
4. **차종 검색**(`.srch`) — 결과가 그 자리에 목록으로 뜬다
5. **캐스케이드**(`.cascade`) — 제조사 → 모델 → 세부모델 (훑어서 고르는 길)
6. **차량 정보** — 차를 고르기 전엔 잠겨 있다(`.vinfo-lock` 「차종을 먼저 선택하면 **금액 입력**이 열립니다」)
   → 연식 · 차량가격 · 주행거리 · 배기량 · 연료 · 사고 이력

**우 `.main`** — 조건과 결과.
1. `.mhead` 차종명 + 차량가
2. **`.condbar`** — 손님 · 담당자 · 담당연락처 / **수수료 · 보증금 · 선납**
   ★조건은 좌 사이드바가 **아니라 여기** 있다
3. `.qsec` 「기본 견적」 → `.qcols`(기간 열, `repeat(4,1fr)`, 열 사이 `border-left`)
4. `.qsec.send` 「손님 발송용 견적」 — 발송할 약정만 체크

**모달로 띄우는 것** — 견적 바구니(`.cart-panel`) · 견적서 미리보기(`.qm`) · 공지(`.nt`).
즉 **결과물에만** 쓴다. **고르는 일에는 안 쓴다.**

### 손오공 원가 (`Admin.vue`)

3기둥. 좌 280 = 차종 검색·캐스케이드 / 가운데 `.main` = 설정 카드(`.sec-tag` 구역 이름 + `.cards`)
/ 우 `.rightpanel` = **「미리보기 — 지금 설정으로 계산한 값」**.
차종·상품·유형·신용을 물고 **1~5년 월납이 그 자리에서 바로 나온다** —
원가를 고치면 견적이 어떻게 변하는지 옆에서 즉시 보인다. **우리 원가 화면엔 이게 없다.**

### 웰릭스 견적 (`index.html`)

좌 `.wrap`(400, `border-right`, 자체 스크롤) = 제조사→모델→트림→**선택 옵션**→색상→… 이 **인라인**.
가운데 = 견적. 우 = 채팅. 컨트롤은 밑줄만 있는 샤프한 드롭다운(`.step-dd`, **height 32**).

## 4. 우리가 여기서 가져온 것 (2026-09-07)

- 견적 웹 = **좌 400(차량) + 우 나머지**. 조건·책정·잔가는 **우측**(원본 `.condbar` 자리).
- 기간 1~5년은 우측에서 **행=항목 · 열=기간** 표로(`.qmx`). 원본 `.qcols` 는 열마다 라벨을
  반복하는데, 원본은 기간4×항목3 이라 견딜 만했고 우리는 **기간5×항목12** 라 그대로 쓰면 못 읽는다.
- **차 고르기는 좌 기둥에 인라인**(`CarPicker inline`). 시트는 폰에서만.
- 폰은 전부 **사장님 목업 그대로**다. 웹 분기는 CSS(감싸개 `.col{display:contents}`)와
  마크업 한 곳(`useIsMobile`)뿐이다.

## 5. 아직 안 가져온 것

- **원가 3기둥 + 미리보기**(`Admin.vue` `.rightpanel`) — 값 고치면 옆에서 월납이 움직이는 것
- 좌 기둥의 **매물 링크 불러오기**(엔카·케이카·오토플러스·오토핸즈·헤이딜러)
- **공유 토큰 눈금**(라운드 4단계·`--sp-*`·`--fs-*`) — 눈에 보이는 변화라 사장님 확인 뒤
- 웰릭스의 **견적 바구니 · 손님 발송용 견적 · 견적서 미리보기 모달**
