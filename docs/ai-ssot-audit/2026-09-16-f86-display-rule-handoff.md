# F86 표시 규칙 영구 반영 요청 — 2026-09-16

## 사용자 확정 규칙

F86은 수동 시트 수정이 아니라 publisher/SSOT에서 아래 규칙을 영구 보존해야 한다.

1. **상품구분 색상은 기존 SSOT 원래색 사용**
   - 신차렌트 `#B81A8C`
   - 중고렌트 `#0D706B`
   - 중고구독 `#6B3DB3`
   - 신차구독 `#474D57`
   - 픽업구독 `#C2185B`
   - 오공구독/오플구독은 기존 정의를 찾아 SSOT에 통합하고 임의색을 만들지 않는다.
2. **배차상태와 상품구분은 별도 색상 체계**로 유지한다. 둘 다 배경색이 아니라 텍스트 색상이다.
3. **F86 탭명 규격**
   - 종합: 날짜/시간 + 대수 유지. 예: `종합 09.16 10:28:49 · 379대`
   - 공급사별 탭: 시간 제거. 예: `손오공 287대`, `이안카 154대`, `오토플러스 66대`
4. **공지사항 탭은 F86에서 생성하지 않는다.**
5. ERP5 canonical data, Atom/F01/F86 차량·가격·기간 로직은 변경하지 않는다.
6. 다음 자동 발행에서도 위 표시 규칙이 유지되어야 한다.

## 배경

현재 F86 자동 발행은 수동으로 수정한 조건부서식, 탭명, 공지사항 제거를 다음 발행에서 다시 덮어쓴다. 따라서 표시 규칙은 시트 후처리가 아니라 F86 publisher/builder 또는 그가 참조하는 SSOT 정의에서 관리해야 한다.

이 문서는 Claude single SSOT 구현 세션이 바로 반영할 수 있도록 남기는 handoff이며, 데이터 SSOT 변경 요청이 아니라 **표시/탭 생성 규칙의 영구화 요청**이다.
