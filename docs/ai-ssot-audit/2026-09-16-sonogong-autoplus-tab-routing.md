# 2026-09-16 — 손오공·오토플러스 판매탭 라우팅 결정

상태: **확정**

사용자 확정 운영 규칙을 기록한다.

## 최상위 원칙

**손오공과 오토플러스는 어떤 상품/원천 변화가 있어도 일반 상품리스트에 흡수하지 않고 각각 별도 판매탭을 유지한다.**

- 손오공 → `손오공구독` 별도 탭
- 오토플러스 → `오플구독` 별도 탭
- 두 탭은 **공통 상품리스트의 기간 구조를 강제로 따르지 않는다.**
- 각 공급사가 실제 제공하는 **자기 고유 기간/요금 구조를 그대로 유지**한다.
- 공통화하는 것은 **템플릿의 화면/열/표현 규격**뿐이다.

즉:

`공급사 고유 기간/요금 = 유지`

`판매탭 UI/열 배치/표현 양식 = 공통 템플릿 규격`

기간을 맞추기 위해 없는 기간을 만들거나, 공급사 원문 기간을 표준 기간으로 억지 변환하지 않는다.

## 판매시트 탭 원칙

1. **손오공은 별도 탭을 유지한다.**
   - 기본 `상품리스트`와 섞지 않는다.
   - 현재 코드의 `손오공구독` 갈래를 유지한다.
   - 손오공 상품은 손오공이 실제 제공하는 기간/요금 축을 사용한다.

2. **오토플러스는 별도 탭을 유지한다.**
   - 기본 `상품리스트`와 섞지 않는다.
   - 현재 코드의 `오플구독` 갈래를 유지한다.
   - 오토플러스 상품은 오토플러스가 실제 제공하는 기간/주행거리/요금 축을 사용한다.

3. **손오공 중고렌트는 새 탭을 만들지 않는다.**
   - 손오공 중고렌트 재고도 `손오공구독` 탭 안에 둔다.
   - 상품 성격상 **반납형 갈래로 취급**한다.
   - 즉 일반 `상품리스트`의 반납형으로 보내는 것이 아니라, **손오공 별도 탭 내부의 반납형 상품군**으로 라우팅한다.
   - `손오공중고렌트` 같은 신규 판매탭은 추가하지 않는다.

4. **손오공 인수형은 기존 손오공 인수형 갈래를 유지한다.**
   - 중고렌트 추가를 이유로 인수형 구조를 변경하지 않는다.

## 현재 코드와의 관계

현재 `lib/domain/sales-published-tabs.ts`는 다음 판매탭을 선언한다.

- `상품리스트`
- `손오공구독`
- `픽업구독`
- `오플구독`

그리고 `손오공구독` 안에는 이미 `N개월 반납형`과 `N개월 인수형` 요금 블록이 존재하며, `오플구독`은 오토플러스 고유 기간/주행거리 요금 블록을 가진다.

따라서 구현 방향은 **기간 구조를 하나로 합치는 것**이 아니라 다음이다.

- 손오공 원천 → 손오공 고유 기간/요금 유지 → `손오공구독` 템플릿
- 손오공 중고렌트 → 손오공 고유 기간/요금 유지 → `손오공구독` 내부 반납형
- 오토플러스 원천 → 오토플러스 고유 기간/주행거리/요금 유지 → `오플구독` 템플릿
- 일반 공급사 → 일반 `상품리스트` 규칙

## 구현 시 금지사항

- 손오공/오토플러스 상품을 일반 `상품리스트` 기간에 억지 매핑하지 않는다.
- 없는 1/6/12/24/36/60개월 값을 만들어 넣지 않는다.
- 공급사 고유 기간을 공통기간으로 보간/추정/치환하지 않는다.
- 손오공 중고렌트를 이유로 신규 탭을 만들지 않는다.
- 오토플러스 `RP023`의 원천을 옛 Google Sheet로 되돌리지 않는다. 원천은 계속 RebornCar다.
- 손오공 `RP012`의 원천은 계속 ERP API다.

## 템플릿 공통화 범위

공통 템플릿으로 맞추는 것은 다음과 같은 **표현 규격**이다.

- 탭의 기본 레이아웃
- 차량 기본정보 열의 순서/명칭 규칙
- 상태/공급사/차량번호 등 공통 원자 표시 방식
- 요금 블록의 시각적 배치와 서식
- 발행/검증/ERP 소비 인터페이스

반대로 **기간 종류, 주행거리 조건, 보증금 규칙, 공급사 고유 요금 축은 공급사별 원문 계약을 유지**한다.
