# 인계 — 상품리스트 연동 «축 레지스트리» (2026-08-22)

> **받는 사람**: 코덱스·커서·다음 세션의 AI.
> **한 줄**: 시트 → 상품리스트 → ERP 연동에서 **열 하나를 세우다 빠뜨리는 사고**를 구조로 막았다. 이제 축은 한 곳에서 선언하고, 검사가 나머지를 강제한다.

---

## 무엇이 바뀌었나

### 전 (사고가 나던 구조)
열 하나를 세우려면 **여섯 곳**을 손으로 챙겨야 했다 — 정제칸 · 판매시트 열 · 정렬 · ERP 별칭 · 재고관리 칸 · 매뉴얼 숫자.
2026-08-22 하루에만 두 번 빠뜨렸다:
- 세부모델·세부트림을 `LEFT_COLUMNS` 에 안 넣어 **조용히 가운데 정렬**로 나갔다(경고 없음).
- 차종코드는 `HEADER_ALIASES` 에 없어 시트엔 69% 차 있는데 **ERP 6,605대 중 0건**이었다.
- 더 나쁜 것 — 세부모델이 100%→33% 로 떨어진 채 **사흘**을 갔다. 그동안 기존 검사 둘 다 초록이었다
  (`check-pipeline-contracts` 는 «열이 있나», `audit-sheet-erp-parity` 는 «차가 ERP 에 있나»만 본다).

### 후 (지금)
- **`lib/domain/sales-axis-registry.ts`** — 축을 한 줄로 선언한다. 이름·ERP 필드·정렬·정제칸 여부·최소 채움률·왜 있는가.
- **`npm run check:axes`** — 선언과 여섯 곳이 같은지 대조. 다르면 **exit 1**.
- **`npm run audit:axes`** — 정제칸 ▶ 판매시트 ▶ ERP 채움률을 축마다 재고, 선언한 문턱 밑이면 실패. 매시 자동 동기(⑧″)에도 붙었다.
- **`npm run check:sync`** — 위 축 검사 + 열 계약 + 매뉴얼 일치를 한 번에.
- **`npm run sync:contract`** — 지금 코드가 하는 매핑(67열 전부)을 찍는다. 문서와 다르면 **코드가 정답**.

## 축을 더하려면 (이 순서대로)

```ts
// 1) lib/domain/sales-axis-registry.ts — 한 줄 선언
{ column: '인승', erpField: 'seats', align: 'right', fromRefined: true,
  minFillSheet: 60, minFillErp: 60, why: '원장 값을 옮기는 칸(정제해서 만드는 값이 아니다)' }
```

```bash
# 2) 검사를 돌려 «어디가 비었는지» 알려주게 한다 — 실패 메시지가 다음 할 일을 알려준다
npm run check:axes

# 3) 검사가 시키는 대로 채운다
#    · SALES_MAPPING(판매시트 열·차례) · LEFT/RIGHT_COLUMNS(정렬) · HEADER_ALIASES(ERP 필드)
#    · AI_TAIL_COLUMNS(정제칸) · entities.product(재고관리 편집 칸)

# 4) 시트에 실제 칸을 만든다(정제 축이면)
npx tsx scripts/add-supplier-ai-columns.mts --include-mirror --apply   # ⚠ 표 맨 뒤에 붙는다
npx tsx scripts/move-ai-column.mts --col=인승 --before=차종크기 --apply   # 제자리로
npx tsx scripts/fill-supplier-ai-columns.mts --include-mirror --apply  # 값 채우기

# 5) 발행 → 동기
npx tsx scripts/publish-handover-tab.mts --apply
npx tsx scripts/publish-origin-tab.mts --apply     # (+ 손오공구독·오플구독 — docs/상품리스트-연동.md §5)
npx tsx --require ./scripts/lib/server-only-shim.cjs scripts/run-sheet-daily-sync-local.mts --apply

# 6) 값이 실제로 갔는지 확인
npm run audit:axes
```

## 남은 일 (알고 있는 빈 곳)

1. **구동 정제칸 절반이 빈칸**(50%). 값은 `2WD`·`AWD` 두 값으로 이미 규격화돼 있어 **규격 결정은 필요 없고 채우기만** 하면 된다.
   (ERP 에 보이던 `xDrive`·`콰트로`·`4MATIC` 은 옛 차종마스터 스냅 잔재이지 정제칸 값이 아니다 — 2026-08-22 실측 확인.)
2. **세부트림 12% 빈칸** — 정제칸 자체가 비어 있다. 채우면 다음 동기에 그대로 올라간다.
3. **레지스트리는 «검사»지 «생성»이 아니다** — 지금은 선언과 여섯 곳이 같은지 대조만 한다.
   더 가려면 여섯 곳을 레지스트리에서 **파생**시키는 리팩터가 남아 있다(위험이 크니 별도 오더로).
