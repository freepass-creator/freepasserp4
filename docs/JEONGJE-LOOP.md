> 사장님: 「자동으로 돌면서 상호보완되게」. **결정·에스컬레이션은 사람(사장님/Claude)**, 두 AI는 수렴만 시킨다.

## 규약 (라운드 R)

```
1. 커서   ← 최신 「검증 R-1」 읽음 → 반례·구멍 고침 → 커밋 → 아래 「## 구현 R」에 «한 것·커밋해시» append
2. 코덱스 ← 최신 커밋 독립 검증(A 오매칭 · B 구멍 · C 무결) → 「## 검증 R」에 PASS/FAIL·반례 append
3. FAIL(오매칭 있음 or 구멍 늘어남) → 커서가 R+1 로 계속
4. PASS 2연속(오매칭 0 AND 구멍 안 늘어남) → 수렴 · 종료 · 코덱스가 메일로 요약
```

## 멈춤·안전 (반드시)

- **수렴**: 오매칭 0 AND 구멍 안 늘어남이 «2라운드 연속» → 종료.
- **상한**: 5라운드. 안 되면 **사장님/Claude 에스컬레이션**(무한루프 금지). 「왜 안 수렴하는지」 3줄 요약.
- **안전선 위반 감지 시 즉시 중단·롤백**(둘 중 누구든):
  - 차종코드(`pickConfirmedMasterCode`)가 medium 으로 박힘 → 「절대 안 틀린다」 위반.
  - 원문에 없는 값을 지어냄.
  - 발행 대수 급감·「공급사 매칭 실패」 발생(회귀).
- **커서는 «안전 medium»만 채운다**(세대만 애매·트림 풀검증) — 위험 medium(모델 애매)은 안 채운다.
- **코덱스는 고치지 않는다** — 반례·근거만. 코드 수정은 커서.
