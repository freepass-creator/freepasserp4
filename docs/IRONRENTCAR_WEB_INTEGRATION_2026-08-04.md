  - 웹 가격을 단일 정본으로 사용하므로 웹에 없는 과거 시트 가격기간도 후보 patch에서 제거한다.

- `GET /api/inventory/ironrentcar/preview`

  - 웹 전수 수집과 운영 v3+v4 읽기 대조 결과만 반환하며 쓰지 않는다.
