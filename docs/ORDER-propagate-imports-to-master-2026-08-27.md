# [오더] 수입 차종을 원천대장/mf-로 전파 — 프로덕션 공급사 정제 커버리지

**맥락 (2026-08-27, Claude 조사).** 공급사 원본(아이카·이안카·오토플러스·아이언)을 공용 매칭으로 재보니, 안 붙는 차의 **대부분이 수입車**였다 — 엔카 작업 시트(=차종마스터_신규, 1oMB9eo)가 국산 위주라서다. Claude가 그 수입 차종을 **엔카 작업 시트에 이미 넣어 뒀다**(세부모델=원문 모델명, 엔카 세대코드는 미정밀). 

이제 프로덕션 공급사 정제(`fill-supplier-ai-columns`)가 이 차들을 이름 붙이려면 — 프로덕션은 «차량번호 정본(상품마스터 mf-코드) → 스냅(원천대장)» 이므로 — **원천대장에도 있어야** 스냅이 잡는다.

## 규칙 (매뉴얼 그대로)
- 세부모델 = **엔카 1:1** · 괄호 없음 · **비기아 개발코드 안 붙임**(수입은 엔카 이름 그대로) · 라틴 트림 한글화 금지.
- 연식종료 2019 이전(노후)은 넣지 않는다. mf- 키는 레지스트리에 없는 것만 신규 발급.
- 넣은 뒤 `check-vehicle-master-lock` · `verify-master-pass` 통과 확인.

## 검증 (Codex/사람)
- `node C:\dev\aiops\scripts\supplier-coverage.mjs` 로 공급사 커버리지 재측정 — 수입 붙으면 91~99% → 더 오름.
- 프로덕션 `fill-supplier-ai-columns`(dry-run)에서 위 차들의 정제칸이 채워지는지 대조.

## 참고 — 하지 말 것
- fill-supplier를 공용 엔진으로 «이관»하지 않는다. 프로덕션은 차량번호 정본·mf-·규격채택·3축 검토라 더 정밀함. 엔카 작업 시트는 그 «입구»(신규 차종 → 엔카 작업 시트 → 원천대장/mf- → 상품마스터). 커버리지는 이 전파로 올린다.
