# 전자계약 문서 구성 기준

## 기본 발송본

고객에게 처음 보내는 전자계약은 아래 문서만 하나의 PDF로 봉인한다.

1. 자동차 장기대여 계약서
2. 자동차 장기대여 약관
3. 중요사항 확인 및 전자서명

부속서류는 기본 PDF에 자동으로 전부 붙이지 않는다. 작성 시점·서명자·제출 목적이 같은 문서만 해당 업무에서 별도로 생성한다.

## 부속서류 사용 기준

| 서류 | 기본 발송 | 사용하는 시점 | 처리 방식 |
|---|---:|---|---|
| 차량 인수증 | 제외 | 실제 차량 인도 시 | 인도 차량·주행거리·상태·지급품을 확인하고 별도 서명 |
| 임대차 계약 사실확인서 | 제외 | 과태료·범칙금·행정기관 제출 요청 시 | 확정 계약정보로 필요할 때 생성 |
| 운전자격 검증 확인서 | 제외 | 차량 인도 전 운전면허 확인 시 | 직원 확인 기록 또는 별도 확인서로 보관 |
| 개인정보 동의 | 계약 확인 화면에 포함 | 계약 체결·세금계산서·보험 처리 | 필요한 항목과 제공처만 표시하고 동의기록 보관 |
| 개인신용정보 동의서 | 제외 | 실제 신용조회·제공을 하는 계약만 | 조회기관·목적·항목이 확정된 경우에만 별도 동의 |
| 위치정보 동의 | GPS 차량 계약 확인 화면에 포함 | GPS 위치수집 시작 전 | 목적·이용자·보유기간을 표시하고 별도 동의기록 보관 |
| 자동이체(CMS) 출금동의 | 제외 | 결제수단을 CMS로 선택한 경우 | 계좌 등록 단계에서 전자 동의·예금주 인증 후 별도 보관 |
| 연대보증 확약서 | 제외 | 연대보증인이 실제로 있는 계약만 | 보증 최고액·기간을 특정한 별도 서면으로 체결 |

## 자동이체 확인사항

- 카드 자동결제·가상계좌·직접이체 계약에는 CMS 동의서를 붙이지 않는다.
- CMS 선택 시에만 예금주, 생년월일, 은행, 계좌번호, 출금일을 입력한다.
- 계약자와 예금주가 다르면 예금주 본인의 별도 동의와 인증을 받는다.
- CMS 동의 완료 여부와 계약서 서명 완료 여부는 별도 상태로 관리한다.
- CMS 등록 실패가 계약서 서명을 취소하지는 않지만, 차량 인도 조건이 충족되지 않은 상태로 표시한다.
- 자동이체 해지·변경 이력과 동의 철회일을 보관한다.

## 화면 버튼

계약 상세의 `부속서류` 메뉴에서 필요한 문서만 보이게 한다.

- 차량 인도 전: `운전자격 확인`, `CMS 등록`
- 차량 인도 시: `차량 인수증 작성`
- 계약 중: `임대차 사실확인서 발급`
- 조건부: `신용정보 동의`, `연대보증 서면 등록`

## 금지사항

- 사용하지 않는 부속서류를 빈 양식으로 계약 PDF에 첨부하지 않는다.
- 개인신용정보를 조회하지 않으면서 신용정보 동의를 필수로 받지 않는다.
- CMS를 사용하지 않는 계약에 CMS 출금동의를 요구하지 않는다.
- 차량 인도 전에 인수증을 미리 서명시키지 않는다.
- 연대보증인이 없는 계약에 연대보증란을 노출하지 않는다.
