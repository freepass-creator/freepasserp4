# 오공구독 원천·옵션 SSOT 매뉴얼

상태: **원천·검수 기준 문서화 / 운영 옵션 완전성 HOLD**. 설명 후보5대 복구, 번호판 불일치7대 해소, 빈 티카 목록 우선 동작 개선은 미완료다. 이 문서를 전체 옵션 정합 완료로 사용하지 않는다.

사용자 요청: 2026-09-15, 오공구독 옵션 원천을 찾아 SSOT화.
범위: RP012 / SON_NO_KONG / 오공구독(판매시트 표기 손오공구독).
사용자 재확인(2026-09-15): **손오공은 공급사이며 상품은 오공구독과 픽업구독으로 구분한다. 오공구독은 반납받아 보유 중인 물량, 픽업구독은 사오는 물량이다.** ‘손오공구독’은 기존 시트·코드를 찾기 위한 명칭일 뿐 별도 상품명이 아니다. 업무 설명과 신규 문서에는 ‘오공구독’을 쓴다. 기존 탭명 변경이나 차량 재분류가 이번 문서 수정으로 실행된 것은 아니다.
픽업구독 TCAR_EXTERNAL은 [별도 매뉴얼](픽업구독-원천-옵션-SSOT-매뉴얼.md)을 따른다.

## 원천과 저장을 구분한다

| 항목 | 실제 원천·위치 |
|---|---|
| 대상 재고 | https://sokrc.com/api/product/homepage/list?carSource=LOW_SONOKONG — 응답 carSource=SON_NO_KONG 확인 |
| 출고옵션 원문 | /product/homepage/view/{id}의 carOptionNote |
| 대조 원문 | /product/view/{id}의 carOptionNote와 현재/변경 차량번호 |
| 설명 속 옵션 후보 | homepage/view의 carDescription. 차명·트림·기본장비·옵션이 섞일 수 있으므로 별도 출처로 보존 |
| 티카 근거 | 실제 현재 동일 차량 상세를 확보한 경우에만 사용. SOKUC: 및 EXCEL_HISTORY:는 웹 URL이 아니다 |

오공구독은 손오공 상세를 먼저 확인한다. 모든 차량이 티카에 게시돼 있다고 가정하지 않는다.
carOptionNote는 공급자가 제공한 출고옵션 필드이며 제조사 출고기록을 독립 검증했다는 의미는 아니다.
EXCEL_HISTORY 표시는 원문의 유래를 기록하는 정보이며, 로컬 엑셀 사본을 현재 정본으로 삼으라는 뜻이 아니다.

저장 결과물은 freepasserp5 Firestore (default)/products다. options와 원문.옵션출처·원문.손오공출고옵션·원문.옵션근거를 함께 대조한다.
F01 손오공구독 탭은 판매 표시 결과다. 시트가 비었거나 DB와 같아도 옵션 없음·수집 완료를 뜻하지 않는다.
RTDB는 폐기됐으며 대체 원천으로 쓰지 않는다.

## 판정 절차

1. 목록의 상품ID·현재 차량번호·버킷을 고정한다.
2. homepage 상세의 ID·번호판을 대조하고 carOptionNote와 carDescription을 모두 읽는다.
3. 에이전트 상세와 번호판이 다르면 changedCarNumber 등 변경 이력을 확인한다. ID만 같다는 이유로 통과시키지 않는다. 해소 전 HOLD.
4. carOptionNote가 있으면 원문과 출처를 보존한다. 설명에 다른 옵션이 있으면 누락/충돌 후보를 별도로 기록한다.
5. note가 비고 설명에 옵션명이 있으면 DESCRIPTION_CANDIDATE로 분리한다. 줄바꿈만으로 선택옵션을 자동 확정하지 않는다. 차명·트림·기본형 표기는 수동 판정한다.
6. note·설명이 모두 비면 NO_OPTION_EVIDENCE다. ‘옵션 없음’이 아니다. 사진이나 동형 차량으로 출고 선택옵션을 추정하지 않는다.
7. 티카 목록이 빈 배열인 경우에도 손오공의 양성 근거를 지우지 않는다. 출처 간 충돌을 보존하고 검토한다.

## 구현 상태와 제한

- sonokong/lib/sonokong.mjs: list / view / viewAgent.
- sonokong/scripts/손오공.mjs: 수집·정규화, 로컬 원문 sonokong/lib/wonja/손오공차량.json.
- scripts/ingest-supplier-to-firestore.mts: Firestore 유입.
- scripts/sync-sonokong-options-only.mts: 옵션·근거만 계획/반영하는 도구.

현재 구현은 티카 paidOptList가 확인되면 이를 우선하고, 없을 때 SON_NO_KONG carOptionNote를 사용한다.
**빈 티카 목록이 존재하는 경우 note보다 우선하는 현행 동작은 완전성 근거가 아니다. 양성 원문과 충돌하면 HOLD 대상이다.**
carDescription 후보의 자동 분류·저장·시트 발행은 이번 문서화로 구현된 것이 아니다.
선택옵션 출처명 sonokongCarOptionNote는 carOptionNote 근거에만 사용한다. 설명에서 읽은 값을 같은 출처로 가장하지 않는다.
