Subject: [프리패스 ERP] 정산 청구 확인 관문 보강 검수 결과

정산관리의 접수 → 실적 → 공급사 청구 흐름을 점검하고, 미확인 영업채널의 청구 번호 발행을 서버에서 차단하도록 보강했습니다.

- 변경: 공급사 청구 발행 전 원장을 재조회하여 영업채널별 실적 확인·재확인 필요 여부를 검사합니다. 미통과면 409으로 발행 기록을 만들지 않습니다.
- 변경: 청구현황 UI, 청구서 미리보기, 서버 발행이 같은 영업채널 기준을 사용합니다. 미확인 상태에서는 번호 발행 버튼도 비활성화됩니다.
- 유지: 금액 산식, 스타·아이카 분납 청구 예외, Google Sheets 원장 저장소는 이번 변경 범위에서 건드리지 않았습니다.
- 검증: TypeScript 검사, 새 확인 관문 시뮬레이션, 기존 정산 E2E 22/22, 원장 431줄 재대조, 2026-08 청구·지급 합계 대조, production build를 통과했습니다.
- 미해결: 확인은 현재 채널별 건수만 고정합니다. 동일 건수 내 차량·금액 변경 검증과 시트→ERP 저장소 이전은 별도 결정이 필요합니다.
- 외부 반영: 미배포. 실제 운영 정산 데이터로 확인 후 사람 승인에 따라 배포해야 합니다.
