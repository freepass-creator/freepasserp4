# 합의 확정 운영매뉴얼 — 4-AI 자동 교차검증으로 «확정»한다

> 사장님(2026-08-29): 「4개 AI가 ㅇㅋ하면 확정. 원문으로 **최소 3개**가 ㅇㅋ하면 확정. **각자 자동으로 뭘 할지도 매뉴얼로 잡으면 되잖아.**」
> Codex NO-GO(자동≠사람확정·추정) 를 **«단일 계산」→ «다수 독립 합의»** 로 푼 것. 정본 설계 = `PLAN-jeongje-confirm-2026-08-29.md` v2.

## 0. 한 줄

**공급사 원문 → 4 AI가 «각자 독립」으로 차종코드를 도출 → 3개 이상 같으면 «확정». 사람은 «합의 안 된 것」만 본다.**

## 1. 확정 대상 (차량번호별)

한 차량번호의 **정체성 전부**가 대상:
```
원산지 · 제조사 · 모델 · 세부모델 · 세부트림   (= 차종코드 하나로 압축됨)
+ 제원: 배기량 · 연료 · 구동 · 인승 · 색상
```
→ 4 AI가 도출한 **차종코드가 3+ 일치**하면 그 차의 정체성 전부를 확정.

## 2. 공유 구조 — 「AI합의」 탭 (집계판)

상품마스터 문서에 **「AI합의」 탭** 하나. 각 AI는 «자기 열»에만 쓴다(남의 열 안 건드림):

| 차량번호 | 공급사 원문(차명·연료·배기량) | Claude코드 | Cursor코드 | Codex코드 | Gemini코드 | 합의수 | 확정코드 | 검증상태 | 확정시각 |
|---|---|---|---|---|---|---|---|---|---|

- 각 AI는 **자기 코드 열 + 근거(원문에서 무엇을 봤나) 각주**만 쓴다.
- 「합의수·확정코드·검증상태」는 **집계기**(6항)가 채운다 — AI가 직접 안 쓴다.

## 3. 각 AI의 «자동» 작업 (여기가 핵심)

각 AI는 «자기 방식»으로 원문→코드를 도출한다. **서로의 답을 안 보고 독립적으로.**

| AI | 도출 방식(자동) | 도구 |
|---|---|---|
| **Claude** | 원문 차명 → `snapToMaster` → 차종코드 | `scripts/confirm-lock.mts`(집계 아니라 «내 1표» 산출) |
| **Cursor** | 원문 → 차종마스터 규칙(playbook) 직접 매칭 → 코드 | `vehicle-master-playbook.ts` |
| **Codex** | 원문 → 독립 파서로 코드 도출(적대적: 다르면 왜) | Codex 전수검증 |
| **Gemini** | 원문 → 마스터 대조 → 코드 | Gemini 오더 |

- ★**원문에 근거 없으면 코드 안 낸다**(빈칸). 지어내지 마라 — 그래야 «합의 안 됨」이 자연히 드러난다.
- ★**남의 답 보고 맞추지 마라.** 독립이라야 교차검증이 의미 있다.

## 4. 합의 규칙 (집계기)

```
차량번호마다, 4 AI가 낸 코드 중 «같은 코드»가 몇 표인가:
  3+ 표 동일  →  확정   확정코드=그 코드 · 검증상태='확정' · 원천='AI합의 N/4' · 확정시각 기록
  2 이하 / 코드 갈림  →  검수대기   검증상태='검수필요' · (사람이 「AI합의」 탭에서 본다)
```

- ★**원천 = 'AI합의 N/4'** — «사람확정」이 아니다(Codex #1: 거짓 이력 금지). 사람이 실제 고른 것만 '사람확정'.
- ★**코드 하나에 정체성 전부**가 물려 있다(코드→마스터의 원산지·제조사·모델·세부모델·트림·제원). 그래서 «코드 3+ 일치»면 «정체성 전부 일치».
- 확정된 코드는 **상품마스터 「검증상태=확정·차종코드」로 이관** → fill 이 재추정 안 함(영원).

## 5. 연동 정합도 같은 방식

**대수·차번집합·핵심값 대조(운영매뉴얼 §2·§4)** 도 4 AI가 각자 독립 검수:
- 각 AI가 F01 차번집합·ERP 차번집합·대수·핵심값을 «각자 세고» 「AI합의-연동」 탭에 제출.
- 3+ 가 «같은 수·같은 집합·불일치 0»이면 그 실행을 «정합 확정».
- 한 AI라도 «읽기 실패»면 그 실행은 실패 → 다음 단계 쓰기 막음(운영매뉴얼 §4).

## 6. 자동 실행 (트리거)

- **주기**: 매시간 잡(손오공-매일) 뒤, 또는 «새 차 유입 시».
- **순서**: ① 각 AI 도출(자기 열) → ② 집계기 합의 계산 → ③ 3+ 는 상품마스터 확정 이관(쓰기=Cursor·백업·재읽기) · <3 은 검수대기 유지.
- **선행(Codex #4)**: F01 4탭·68열 매뉴얼 드리프트(`npm run check:sync`) 통과 전엔 확정 쓰기 금지.

## 7. 안전 (Codex NO-GO 반영)

- 확정 «쓰기»는 **Cursor 전용**(mf-코드) + 대상행 백업 + 실행 후 재읽기 검증.
- 근거 문자열(원문에서 무엇을 봤나) 저장 — 별칭 변환도 근거 남긴다.
- 완료 판정 = F01↔천이↔ERP 전 필드 재대조 «모두 통과»(운영매뉴얼 §5).
- 읽기 실패·후보 복수·원문 불충분 → **반드시 검수대기.** 자동 확정 안 함.

## 8. 자동 교정 — «틀린 합의»를 스스로 되돌린다 (검토만으론 부족)

★핵심 문제: 판별기 3개가 **같은 실수**를 할 수 있다(마스터 별칭 오류·공유 편향). 합의만으론 못 잡는다.
그래서 **합의와 «다른 신호(ground truth)»로 재검사 → 틀리면 자동 철회 → 재도출**.

### 8-1. 감사기(auditor) — 합의가 «안 쓴 신호»로 친다

확정된 차마다, 판별기가 «이름」으로 맞췄으니 감사기는 «숫자·역방향」으로 검사(결정적 코드, AI 의견 아님):
- **제원 모순**: 확정코드가 함의하는 제원(마스터의 배기량·연료·구동·인승) ↔ **원문의 제원**. 원문 1598cc인데 코드가 1999cc → 모순.
- **역검증(round-trip)**: 코드 → 마스터 표준차명 → 원문 차명 토큰과 겹치는가. 한 토큰도 안 겹치면 의심.
- **downstream 신호**: 계약서·사진·실물에서 어긋남 발견분도 감사기 입력(코덱스 적대적 플래그가 여기로 들어온다).

### 8-2. 비대칭 — 철회는 자동, 재확정은 게이트 (열쇠)

```
감사기 모순 발견
  → 자동 철회(격리)   검증상태=확정→'오류격리' · 원천='자동철회' · 이전값·모순필드·시각 백업   ← 안전(락 해제)
  → 재도출 큐          판별기 다시 + (반복이면) 라이브 AI/사람
  → 재확정             합의(3+)+감사 «다시 통과»해야만 확정   ← 게이트(틀린 값이 지속 못 함)
```

- **철회(락 해제)는 자유롭게 자동** — 틀릴 수도 있는 확정을 «확정에서 빼는」 건 항상 안전.
- **재확정은 반드시 게이트** — 다시 3+ 합의 + 감사 통과라야. 그래서 «틀린 합의가 지속될 수 없다».

### 8-3. 반복 철회 → 사람 에스컬레이션 (마스터 의심)

같은 차번이 **N회(예: 2회) 철회**되면 = 판별기·마스터 자체가 틀렸을 가능성. 자동 재도출 멈추고 사람/커서로:
- 사람이 원문·실물로 판정 → 필요하면 **마스터를 고친다**(마스터 수정=Cursor+사람, 정본이라 백업). 그 교정이 전 차에 퍼진다.
- 무한 철회↔재확정 루프 금지 — 에스컬레이션이 상한.

### 8-4. 누가 무엇을 (교정 역할)

| 역할 | 누구 | 자동/수동 |
|---|---|---|
| 감사기 실행(모순 탐지) | 결정적 코드 `scripts/audit-confirmed.mts` (Claude 설계·Cursor 구현) | 자동 매시간 |
| 적대적 플래그 제공 | Codex(검토만, 감사기 입력으로) | 자동 |
| 철회 쓰기(격리) | Cursor(mf-코드·백업·재읽기) | 자동(안전) |
| 재확정 쓰기 | Cursor — 단 합의+감사 게이트 통과분만 | 게이트 |
| 반복 실패·마스터 수정 | 사람 + Cursor | 수동 |

★코덱스는 여전히 «안 고친다» — 그 플래그가 감사기 입력이 되고, 실제 철회·재쓰기는 Cursor가 한다. 감사기는 «의견»이 아니라 «하드 일관성 검사」다.

## 9. 사람은 무엇을 하나

- **합의 안 된 것(검수대기) + 반복 철회 건만** 「AI합의」 탭에서 본다. 4 AI 도출·모순필드가 나란히 보이니 «왜 갈렸나/틀렸나»가 한눈에.
- 사람이 고르면 그 코드로 확정(원천='사람확정'). 명백한 것은 사람 손 안 감.
