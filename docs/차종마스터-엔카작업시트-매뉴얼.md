# 차종·제원 마스터 매뉴얼 (2026-08-27)

작업 시트: https://docs.google.com/spreadsheets/d/1oMB9eoNnQFxUyRK4CSxYh_hKrtCf7s_79xLs-GYwXCE/edit  
라이브 ERP 원장(`mf-`, `1T_RrErmGoj_…`)에는 **아직 쓰지 않는다.**

## 탭 (겹치지 않게)

| 탭 | 칸 | 역할 |
|---|---|---|
| 차종마스터 | 원산지 · 제조사 · 모델 · 세부모델 · 세부트림 | 이 차가 뭔지 |
| 제원마스터 | 구분 · 값 (연료 · 배기량(cc) · 구동방식) | 허용값 목록. 차는 여기서 고른다 |
| 전기차배터리마스터 | 제조사 · 모델 · 세부모델 · 배터리(kWh) · 비고 | 전기만. 모델별 팩 |
| 색상 | 원천대장 | 이 시트에 없음 |

인승은 제원 축이지만 이번 작업 시트에는 아직 안 실었다. 정제칸 「인승」은 원문이 하나로 모일 때만.

## 차종

- 세부모델 개수·이름은 **엔카 iNav와 1:1**. 아래 예외 두 가지 말고는 엔카 원문 그대로다.
- 세부모델·모델·세부트림에 괄호를 두지 않는다. `G80 (RG3)` → `G80 RG3`, `볼트(Volt)` → `볼트 Volt`. 괄호 제거는 예외가 아니라 표기 정리.

### 예외 — 이 둘만 (2026-08-27 확정)

| | 엔카 | 우리 시트 | 범위 |
|---|---|---|---|
| 1 | `K5 3세대` | `K5 DL3` | **기아만** `N세대` → 개발코드. 현대 `아반떼 CN7`처럼 엔카에 이미 코드가 있으면 그대로 |
| 2 | `G80` | `G80 DH` | **우리 시트만** 제네시스 1세대. RG3·GV80·다른 차에 DH를 붙이지 않음 |

예외가 **아닌 것:** 엔카가 안 나눈 FL을 우리가 쪼개기(`G80 RG3 FL`), 티볼리에 `X100` 붙이기, 기아 아닌 차에 개발코드를 새로 붙이기.

- 범위: 연식종료 2019 이후(또는 현재). NF처럼 이미 끝난 세대는 없음.
- 통상의 차명 = **세부모델 + 세부트림**. `K5 K5 DL3 시그니처`가 되면 잘못.
- 세부트림은 엔카가 배기량마다 쪼갠 것을 **합친다.** 2.5에 세 개, 3.5에도 그 세 개 + 하나면 **네 줄**. `2.5 시그니처` / `3.5 시그니처`로 두지 않음.
- 배기량만 있고 트림 이름이 없으면 **기본형**. 제네시스는 엔카가 `블랙`을 적으면 블랙, 없으면 기본형.
- `프레스티지(렌터카)` · `(택시형)` · `(장애인용)` 은 같은 트림이다. 괄호 용도는 뺀다. `노블레스(5링크)` 처럼 차가 다른 것만 풀어 쓴다 (`노블레스 5링크`).

## 제원 · 배터리

- 연료·배기량·구동은 차종 행을 쪼개지 않음. 제원마스터에서 고름.
- 전기 배터리는 제원마스터 화이트리스트가 아니라 **전기차배터리마스터**. 팩이 둘이면 행 둘(스탠다드/롱레인지).
- 공식 제원이 없으면 kWh 빈칸.

## 정제칸 (정제시트)

칸마다 따로 붙인다. 공급사 원문이 마스터 값 **하나로** 모일 때만 적는다. 추측이면 빈칸.

| 원문 | 정제칸 | 마스터 |
|---|---|---|
| 차명·세대 | 모델 · 세부모델 · 세부트림 | 차종마스터 |
| 연료·cc·구동·인승 | 연료(정제) · 배기량(정제) · 구동방식 · 인승 | 제원마스터 |
| 전기 kWh | 배터리용량(정제) | 전기차배터리마스터 |
| 색 | 외장색상 · 내장색상 | 색상마스터 |

**한 것:** 공급사 정제시트 정제칸은 엔카 작업 시트로 채움. 빈 칸은 넣고, 검수에서 다르면 바로잡음. 원문이 하나로 안 모이면 안 건드림. 상품리스트는 정제칸을 그대로 발행.

## 하지 말 것

- 후보가 여럿인데 트림·cc·kWh를 찍기
- 옵션으로 트림 맞추기
- 위 예외 둘 말고 이름을 바꾸기(FL 분할, 비기아 개발코드 추가)
