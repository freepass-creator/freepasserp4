# 정산 워크스테이션 — 구조 설계

> 사장님 2026-09-10 「구조부터 어떻게 짤 건지 보여주고 들어가자」

**직원이 이 페이지만 열어 놓으면 일이 되는 화면.** 고전 ERP 겉모습 · PC 전용 · 한 화면.

---

## 1. 한 페이지 · 탭 셋

일이 흐르는 차례 그대로다 — 정산원장(F04) 탭과 같은 말을 쓴다.

```
 차를 찾아 판다      나간 것을 센다        받을 것을 끊는다
   ┌─────┐          ┌─────┐            ┌─────┐
   │ 접수 │  ──────▶ │ 실적 │  ────────▶ │ 청구 │
   └─────┘          └─────┘            └─────┘
  인도 전            인도됨·청구월 있음    그 달 청구·계산서
```

| 탭 | 무엇을 하나 | 원장 어디 |
|---|---|---|
| **접수** | 차를 조건으로 찾아 손님 응대 → 그 자리에서 계약 접수 | 접수 |
| **실적** | 인도돼서 청구월이 박힌 줄. 청구·지급·우리 몫 | 분납실적 · 완납실적 |
| **청구** | 그 달 청구 장부 · 계산서 발행 · 넘길 것 | 청구 |

## 2. 접수 탭 — 이 화면의 주인공

```
┌ 메뉴바 ────────────────────────────────────────────────────────────┐
│ FREEPASS ERP   [접수] 실적 청구          재고 1,438 · 대기 12 · 할일 3│
├ 조건 줄 ───────────────────────────────────────────────────────────┤
│ 🔍[차번·차종·색] 연료▾ 차급▾ 상품▾ 공급사▾ 월대여료≤[700,000] ☑출고가능만│
│                                                    1,438 → 84대 찾음 │
├ ① 차량 표 — 한 줄에 조건이 다 보인다 ──────────────────────────────┤
│ ● 11가1111 기아 니로 SG2에어 23년 3.2만km 하이브리드 소형SUV 5인 흰색 │
│                        차카렌터카 중고구독   36개월 700,000 / 보증140만│
│ ▼ 줄을 누르면 «그 자리»가 펼쳐진다 ────────────────────────────┐  │
│ │ 기간별  12·770,000/154만  24·730,000/146만  36·700,000/140만  │  │
│ │ ※고객명[    ] 채널[    ] 영업자[    ] 청구월[    ] [계약 접수] │  │
│ └────────────────────────────────────────────────────────────┘  │
├ ② 접수 내역 — 넣은 것이 여기 쌓인다 ───────────────────────────────┤
│ 차번 고객 차종 공급사 채널 접수일 ☑계약서 ☑인도완료 상태             │
├ 상태바 ────────────────────────────────────────────────────────────┤
│ 재고 1,438대 · 찾은 것 84대          접수 대기 12건 · 할 일 3건      │
└────────────────────────────────────────────────────────────────────┘
```

**세 가지 원칙**

1. **조건으로 찾는다** — 손님은 「월 70 이하 SUV 있어요?」로 묻는다. 글자 검색만으로는 못 답한다.
   조건 축 여섯: `연료 · 차급 · 상품 · 공급사 · 월대여료 상한 · 출고가능만`
   ※ 대여료는 **어느 기간이든** 그 값 아래면 걸린다 — 「36개월로 하면 되나요」가 그 자리에서 풀린다.
2. **한 줄에 많이** — 「이쁘게보다는 많은 정보」(사장님). 한 줄에 열두 가지:
   `상태점 · 차번 · 차종 · 트림 · 연식 · 주행 · 연료 · 차급 · 인승 · 색 · 공급사 · 상품 · 최저요금/보증금/기간`
3. **누르면 그 자리에서 펼쳐진다** — 다른 화면으로 안 간다. 펼친 자리에 기간별 요금 + 접수 칸 + 「계약 접수」.

**접수 줄의 네 자리** — 시트의 체크 둘(계약서·인도완료)과 청구월이 말한다.

| 상태 | 조건 | 색 |
|---|---|---|
| 접수만 | 계약서 ✗ · 인도 ✗ | 회색 |
| 인도 대기 | 계약서 ✓ · 인도 ✗ | 파랑 |
| **★청구월 필요** | 인도 ✓ · 청구월 ✗ | **주황 — 이게 「일」이다** |
| 인도완료 | 인도 ✓ · 청구월 ✓ | 초록 (실적으로 넘어감) |

## 5. 데이터 — 어디서 오나

```
                    ┌──────────────────────────┐
   Firestore        │  products (재고 1,438대)   │──┐
   ★정본 하나       │  settlement_rows (원자)   │  │  GET /api/settlement/board
                    │  settlement_clawbacks     │  │  ← 한 번에 다 받는다
                    └──────────────────────────┘  │
                                                   ▼
                              ┌──────────────────────────────┐
                              │  BoardApi { load save edit car } │
                              └──────────────────────────────┘
                                 ▲                        ▲
                     진짜 문 ────┘                        └──── 미리보기 문
              /settlement/intake                    /settlement/intake/preview
              로그인 + 관리자                        로그인 없이 · 지어낸 값
```

- **조건 거르기는 화면이 한다** — 재고를 한 번 받아 두고 즉시 좁힌다.
  파이어스토어는 부분일치를 못 하고, 칠 때마다 1,438건을 읽으면 그것도 돈이다.
- **숫자는 화면이 안 센다** — 청구·지급·부가세는 서버가 엔진(`lib/domain/settlement/engine`)으로 낸다.
- **RTDB 는 안 쓴다** — `npm run check:nortdb` 가 막는다.

## 6. 파일

```
components/settlement/
  IntakeStation.tsx   ← 얼굴 하나. 탭 셋을 다 그린다. 데이터는 주입받는다
  classic.css         ← 고전 ERP 겉모습(teamjpkwork 원본 + 접수용 덧댐)
  SettlementBoard.tsx ← 폰용 정산 콕핏(따로 산다)

app/settlement/intake/page.tsx          진짜 문 — 로그인 + 관리자
app/settlement/intake/preview/page.tsx  미리보기 문 — 로그인 없이 · 샘플
app/api/settlement/board/route.ts       GET(읽기) · POST(접수·고치기)
```

⚠ **미리보기에 진짜 값을 싣지 않는다.** 로그인 없이 열리는 문이라 고객 이름 하나만 새도 사고다.

## 7. 만드는 차례

| | 무엇 | 왜 먼저 |
|---|---|---|
| ① | 조건 줄 + 차량 표(한 줄 열두 칸) | 이 화면이 하는 일의 8할 |
| ② | 줄 펼침 + 접수 칸 + 계약 접수 | 찾은 것을 바로 접수 |
| ③ | 접수 내역(하단) + 체크 둘 | 넣은 게 올라갔나 확인 |
| ④ | 실적 탭 | 인도된 것을 센다 |
| ⑤ | 청구 탭 | 그 달 청구·계산서 |

**①②③ 이 「접수 탭」이고 그것부터 끝낸다.** ④⑤는 그 뒤.

## 안 하는 것

- **폰 대응** — PC 전용이다. 표를 폰 폭에 접으면 표가 아니게 된다. 폰 접수는 `/settlement/board`.
- **수금·지급 실행 표시** — 통장을 봐야 아는 것이라 화면에서 켜면 거짓말이 된다(사장님 「수금은 별도로 관리할게」).
- **상품찾기와 겹치는 것** — 손님용 카드·사진·공유는 안 넣는다. 여기는 업무 화면이다.
