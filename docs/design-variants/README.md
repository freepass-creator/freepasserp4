## 파일 이름 규칙

`<만든이>-<안>.html` — 예: `cursor-a.html` · `codex-b.html` · `gemini-a.html`

만든이는 `cursor` · `codex` · `gemini` · `claude`. 안은 `a` · `b` · `c`(기획서 6절의 모서리 3단계).

## 지켜야 할 것

- **목업만.** 앱 코드(`app/` · `components/` · `lib/`)는 건드리지 않는다. 여기 HTML 한 장으로 끝난다.
- 한 장 안에 **목록 화면 + 상세 화면**을 위아래로 담는다.
- 맨 위에 **한 줄 설명**(무엇이 다른지), 맨 아래에 **치수 표**. 치수 표가 없으면 코드 토큰으로 옮길 수 없다.
