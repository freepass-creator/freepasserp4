## 1. GV60 F/L

### 기본가와 주요 변형

원문 `gen_gv60.txt` 4–15행: 기본 모델 세제 전 **68,280,000**, 세제 후 **64,900,000**.
42–70행: 스탠다드 2WD +0 / 스탠다드 AWD +3,800,000 / 퍼포먼스 AWD +8,400,000.
**121행: 퍼포먼스 AWD에는 환경친화적 자동차 세제혜택이 적용되지 않는다.**

| 주요 변형 | 계산 | 기본가 또는 표시가격 합산값 |
|---|---|---:|
| 스탠다드 2WD / 19인치 / 기본 내장 | 세제 후 기본 모델 표기값 | **64,900,000** |
| 스탠다드 AWD / 19인치 / 기본 내장 | 64,900,000 + 3,800,000 | **68,700,000** * |
| 스탠다드 AWD / 20인치 / 기본 내장 | 64,900,000 + 3,800,000 + 2,300,000 | **71,000,000** * |
| 퍼포먼스 AWD / 21인치 / 기본 내장 | **68,280,000 + 8,400,000** | **76,680,000** |
| 퍼포먼스 AWD / 21인치 / 셀렉션 II 스웨이드 | 76,680,000 + 2,700,000 | **79,380,000** |

\* 스탠다드 AWD의 68,700,000원과 71,000,000원은 **표시된 세제 후 base에 세제 전 옵션을 단순 가산한 값**이다. 별도 세제 후 AWD 가격으로 원문에 명시된 숫자가 아니다. 원문 182–184행은 옵션이 세제 전 금액이며 세제 후 가격은 선택품목에 따라 달라진다고 명시한다. 따라서 이 두 값은 실견적의 세제 후 확정 base로 판정할 수 없다. AWD 세제 전 기본가는 72,080,000원, 20인치 선택가는 74,380,000원이다.

퍼포먼스에 64,900,000 + 8,400,000 = 73,300,000원을 적용하면 **3,380,000원 과소계상**한다.

차량 액세서리(166–181행): 보호 필름 410,000 + 프로텍션 매트 250,000 + 플로팅 휠 캡 90,000 = **750,000**. 디퓨저 리필 키트 15,000원은 명시적으로 애프터마켓 상품이므로 제외한다.

```text
최고 PE base = 68,280,000 + 8,400,000 = 76,680,000
액세서리 제외 = 76,680,000 + 700,000 + 0 + 2,700,000 + 14,750,000
              = 94,830,000
maxPrecise    = 94,830,000 + 410,000 + 250,000 + 90,000
              = 95,580,000
```

최대성 확인: 가장 비싼 스탠다드 AWD+20인치의 세제 전 합계조차 동일한 외장·내장·옵션·액세서리를 붙이면 93,280,000원이다. 세제혜택을 적용하기 전부터 퍼포먼스 최고가보다 2,300,000원 낮으므로, 스탠다드 AWD의 세제 계산 불확실성이 모델 전체 최고가를 뒤집지 않는다.

## 2. G80-EV

원문 `gen_g80-ev.txt` 5–21행: 기본 모델 세제 전 **89,080,000**, 세제 후 **84,790,000**. 272kW 듀얼모터 AWD와 19인치 휠이 기본이다. 별도의 유료 PE·구동·휠 변형은 없다.

| 구성 | 계산 | 금액 |
|---|---|---:|
| AWD / 기본 유광 / 스탠다드 내장 | 세제 후 표기 base | **84,790,000** |
| AWD / 기본 유광 / 시그니쳐 디자인 셀렉션 | 84,790,000 + 3,000,000 | **87,790,000** |
| AWD / 유료 외장 / 스탠다드 내장 | 84,790,000 + 700,000 | **85,490,000** |
| AWD / 유료 외장 / 시그니쳐 디자인 셀렉션 | 84,790,000 + 700,000 + 3,000,000 | **88,490,000** |

43–61행: 외장은 EV 스페셜 마티라 블루 +700,000 또는 무광 마칼루 그레이 +700,000 중 **하나**다. 1,400,000원을 더하지 않는다. 내장은 기본 또는 시그니쳐 +3,000,000 중 하나다. 유효 예시는 무광 마칼루 그레이 + 옵시디언 블랙 시그니쳐 + 블랙 포지드 우드(레드 검 제외)다.

2열 컴포트의 선행조건인 컨비니언스 패키지를 포함했다. 기본 뱅앤올룹슨 오디오·ANC-R·프리뷰 서스펜션·19인치 휠을 다시 유료 옵션으로 더하지 않는다.

파퓰러 5,400,000원은 HUD+DA I+DA II+빌트인 캠의 번들이므로 제외한다. 개별 합계는 6,100,000원이며, 최고가 산식은 이 개별 선택을 사용한다.

Genesis Accessories: 후석 스마트 엔터테인먼트 3,000,000 + 보호 필름 450,000 + 플로팅 휠 캡 90,000 = **3,540,000**. 후석 엔터테인먼트는 빌트인 캠이나 2열 컴포트의 중복 구성품이 아니다. 원문의 추천 차량에도 2열 컴포트와 후석 엔터테인먼트가 함께 실려 있다. 액세서리 선택 시 영남/칠곡 출고센터 조건이 있으므로 그 조건을 충족하는 구성을 전제로 한다.

```text
액세서리 제외 = 84,790,000 + 0(PE) + 700,000 + 3,000,000 + 13,700,000
              = 102,190,000
후석 모니터만 추가 = 102,190,000 + 3,000,000 = 105,190,000
maxPrecise    = 102,190,000 + 3,000,000 + 450,000 + 90,000
              = 105,730,000
역산 확인     = 89,080,000 + 700,000 + 3,000,000 + 13,700,000 + 3,540,000
                - (89,080,000 - 84,790,000)
              = 110,020,000 - 4,290,000 = 105,730,000
```

G80의 표기 기본가에 이미 반영된 세제 차액 4,290,000원을 유지하는 산식이다. 가격표에 적힌 세제 전/후 차액 이외의 감면이나 보조금·취득세·등록비·할인·3.5% 개소세를 추가로 적용하지 않았다. 실제 계약 확정가격을 보증하는 산식은 아니다.
