# 커서 오더 — 공급사 이름 별칭 채우기 (2026-09-02)

> 설계·게이트: Claude · 구현: Cursor · 검증: 이 문서의 완료조건
> 근거: CLAUDE.md 「협업 파이프라인」 — 「커서 = 보완만. 새 구조·규격을 만들지 않는다」

## 무엇을 (한 문장)

`lib/domain/settlement-fee-table.ts` 의 `ALIAS` 에 **원장이 줄여 부르는 이름 ↔ 수수료표의 정식 상호**를 전부 채운다.

## 왜

수수료표는 정식 상호로 적혀 있고(「빌린카(LC)」·「경진렌트카」), 원장은 줄여 적는다(「엘씨렌트」·「경진카」).
이름이 안 붙으면 그 줄은 통째로 「표에 없다」가 되어 **수수료 검산이 그냥 건너뛴다.**
2026-09-02 에 엘씨렌트 = 빌린카(LC) 하나를 붙였더니 그 자리에서 2줄이 살아났다.

## 어떻게

1. **원장 쪽 이름 목록**을 뽑는다 — `v4/settlement_rows` 의 `supplier` 를 중복 없이.
   ```bash
   npx tsx scripts/check-fee-consistency.mts 2026-08
   ```
   맨 아래 「표에 없는 공급사」가 붙지 않은 이름이다. **다른 달도 같이 본다**(`2026-09`·`2027-01`).
2. **표 쪽 이름 목록**은 `FEE_RULES` 의 `supplier` 다. 시트를 읽지 않는다 — **코드가 정본**이다.
3. 둘을 눈으로 맞대 **같은 회사인 것만** `ALIAS` 에 양방향으로 넣는다.
   ```ts
   const ALIAS: Record<string, string> = { …, 엘씨렌트: '빌린카', 빌린카: '엘씨렌트' };
   ```

## 하지 않는 것 (여기가 새는 자리다)

- **규칙(`FEE_RULES`)에 줄을 새로 만들지 않는다.** 요율은 사람이 정한다.
  「빌린카에 구독 규칙이 없다」는 **없는 게 맞다** — 채우지 말고 보고한다.
- **같은 회사인지 확실하지 않으면 넣지 않는다.** 「SMC」와 「에스엠」처럼 비슷해 보여도
  근거가 없으면 «모른다»가 답이다. 넣지 말고 목록에 적어 올린다.
- 눈에 띄는 버그를 봐도 **고치지 말고 보고**한다.
- 원자가 없으면 만들지 말고 **멈추고 보고**한다.

## 보고

붙인 짝을 **표로** 적는다(원장 이름 | 표 이름 | 왜 같은 회사라고 봤나).
「같은 회사인지 모르겠는 이름」은 **따로 목록으로** 올린다 — 그게 사람이 답할 자리다.
