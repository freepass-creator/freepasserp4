검사일: 2026-09-06. 판정: **4모델 모두 max 틀림**. 검사만 수행했으며 JSON·코드·라이브 데이터는 수정하지 않았다.

기준: `data/new-car/genesis-config-fs.json` 작업 트리와 지정된 `tmp/newcar-pdf/gen_*.txt`, 동일 이름의 로컬 공식 PDF. 가격표 기준일은 2026-09-01, 개별소비세 5%, **모든 금액은 원**. GV70-EV는 JSON과 동일하게 **세제혜택 적용 전** 가격을 사용했다. 최신 웹 가격이나 세제혜택 후 실구매가를 검증한 결과가 아니다.

### 직접 계산 근거

**G70:** 일반형 3.3T·AWD·무광·스포츠·스포츠 디자인 셀렉션, 옵시디언 블랙 모노톤(알칸타라 적용 조건).

`45,000,000 + 4,950,000 + 2,470,000 + 690,000 + 2,370,000 + 1,480,000 + 6,530,000 + 1,800,000 = 65,290,000`

개별옵션 6,530,000 = 선루프 790,000 + 컨비니언스 1,290,000 + 하이테크 1,580,000 + 렉시콘 1,190,000 + 드라이빙 어시스턴스 1,680,000. 액세서리 1,800,000 = 보호필름 400,000 + 휠 캡 90,000 + 스포일러 880,000 + 알칸타라 430,000. 스포츠 휠·서스펜션은 기본 포함. 파퓰러 4,100,000 대신 그 구성품 합 4,550,000을 적용했다. 엔진×구동×기본/스포츠 8경로를 직접 합산한 최고다. Graphite Edition은 `59,700,000 + 2,470,000 + 690,000 + 790,000 = 63,650,000`으로 더 낮다.

**GV70:** 3.5T·AWD·무광·그래파이트 패키지·그래파이트 디자인·기본 21인치 + 단조 휠.

`54,730,000 + 5,500,000 + 3,000,000 + 700,000 + 3,650,000 + 0 + 2,300,000 + 12,800,000 + 4,510,000 = 87,190,000`

개별옵션 12,800,000 = 선루프 1,400,000 + HUD 1,300,000 + 컨비니언스 2,500,000 + 드라이빙Ⅰ 1,950,000 + 드라이빙Ⅱ 2,000,000 + 2열 컴포트 1,100,000 + 뱅앤올룹슨 1,700,000 + 캠 850,000. 액세서리 4,510,000 = 단조 휠 2,800,000 + 보호필름 450,000 + 휠 캡 90,000 + 사이드 스텝 470,000 + 매트 250,000 + 공기청정기 450,000.

각 경로 최고(모두 AWD·무광): 2.5T 기본 78,240,000 / 스포츠 84,490,000 / 그래파이트 84,790,000; 3.5T 기본 82,640,000 / 스포츠 86,890,000 / 그래파이트 87,190,000. 2.5T 저가 휠에 서스펜션을 따로 붙인 경로도 고가 휠 경로보다 낮다. **131,840,000은 과대가 맞지만, 차이 전체가 휠 하나 때문은 아니다.** 여러 분류·필수선택·자유옵션의 중복도 함께 제거해야 한다.

필수선택 3,800,000 = 20인치 800,000 + 무광 700,000 + 내장Ⅱ 2,300,000. 개별옵션 12,400,000 = HUD 1,300,000 + 선루프 1,400,000 + 컨비니언스 2,200,000 + 드라이빙Ⅰ 1,950,000 + 드라이빙Ⅱ 2,000,000 + 2열 컴포트 1,000,000 + 뱅앤올룹슨 1,700,000 + 캠 850,000. 액세서리 1,260,000 = 보호필름 450,000 + 휠 캡 90,000 + 사이드 스텝 470,000 + 매트 250,000. 프레스티지 11,600,000보다 개별 합이 800,000 높다.
