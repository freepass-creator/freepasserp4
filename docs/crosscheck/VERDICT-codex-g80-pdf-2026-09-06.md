## 판정

1. **필수선택 추가금: 맞음.** JSON에 인코딩된 19개 추가금 값과 기본가격을 대조했으며 원 단위 차이는 0원이다. 스포츠 휠의 단일 0원 항목은 두 엔진에 공통 적용되므로 가격은 맞다. 실제 타이어는 2.5T 피렐리 / 3.5T 미쉐린 썸머로 다르다.
2. **provisional 92,770,000원: 맞음.** 액세서리까지 포함한 유효 선택 조합의 최대는 스포츠 3.5T 경로이며 차액은 **0원**이다.
3. **G80 엔트리 설명 전체가 정확한가: 틀림.** `note`의 “블랙 에디션은 이 PDF에 없음”은 사실과 다르다. PDF 6쪽에 G80 Black 가격표가 있다. Black 최고가도 계산했지만 92,750,000원으로 위 최대를 넘지 않는다.
4. `options.conditionals`의 “2열컴포트 파노라마 상충 주의”는 패키지 선택 배타로 해석하면 틀리다. 함께 선택 가능하며 **뒷좌석 화장거울만 미적용**이다. 현재 provisional 계산은 두 옵션을 함께 더했으므로 이 부분 계산은 맞다.

## ② 조건부·중복 제거 규칙

- **프리뷰 전자제어 서스펜션 1,100,000원:** 기본 2.5T의 18·19인치에서만 유료 선택 가능(152–155줄). 기본 2.5T 20인치는 휠 3,000,000원에 포함(103–105줄), 3.5T는 엔진에 포함(46–49줄), 스포츠 2.5T는 스포츠 패키지에 포함(67–70줄). 이 네 경우를 구분했다.
- **뱅앤올룹슨 1,900,000원:** 스포츠 3.5T에서는 기본 포함이고 별도 선택 불가(73–78, 170–172줄). 해당 경로는 추가금 0원으로 처리하며 나머지 세 경로에서는 유료 선택했다.
- **파퓰러 4,300,000원:** 드라이빙 어시스턴스Ⅰ·Ⅱ·빌트인 캠을 포함(146–150줄). 개별 선택은 1,950,000 + 2,000,000 + 850,000 = **4,800,000원**(160–166, 173–175줄). 최고 가격을 찾으므로 개별 경로가 **500,000원 더 높다**. 파퓰러와 구성 개별 옵션을 중복 합산하지 않았다. 동일 장비를 저렴하게 구매하는 목적이라면 파퓰러가 유리하지만 이번 요청의 최대 가격과는 목적이 다르다.
- **파노라마 1,400,000원 + 2열 컴포트 2,700,000원:** 동시 선택 가능. 원문은 “파노라마 선루프 선택 시 뒷좌석 화장거울 미적용”(168줄)으로, 옵션 전체 선택 불가가 아니다. 가격 차감도 명시되어 있지 않다.
- **액세서리:** 후석 스마트 엔터테인먼트 3,000,000 + 차량 보호 필름 450,000 + 플로팅 휠 캡 90,000 = **3,540,000원**(130–145줄). 일반/스포츠 경로에는 모두 더할 수 있다. Black의 휠 캡은 기본 포함이므로 별도 가산하지 않는다.
- 내장 색상/가니쉬 제한(189–194줄)은 유효 색상 조합을 고르면 충족된다. 스포츠 최고가 구성의 예: 무광 마칼루 그레이 외장, 스포츠 디자인 셀렉션의 옵시디언 블랙 모노톤+그레이 스티치 및 카본 실버 와이어. 이 조합은 금지된 카본 레드 믹스를 선택하지 않는다.

## Black 누락 확인

PDF 6쪽 `GENESIS G80 Black`에는 기본 83,600,000원, 3.5T 추가 4,300,000원, 파노라마 1,400,000원이 명시돼 있다. 3쪽은 Accessories의 Black 적용 가능 및 Black 전용 플로팅 휠 캡 기본 적용을 명시한다.

```text
Black 최고 = 83,600,000 + 4,300,000 + 1,400,000
           + 3,000,000(후석 엔터) + 450,000(보호 필름)
           = 92,750,000원
스포츠 최고와 차이 = -20,000원
```

따라서 “PDF에 Black 없음”은 확정 오류이고 Black 구성 정보도 엔트리에서 누락됐지만, 이를 포함해도 전체 최고가 92,770,000원은 유지된다. JSON의 비공식 83.7M 언급을 공식 가격으로 채택하지 않았다.

## 검증 방법·한계·변경 범위

- Node의 내장 `assert`로 가격표에서 독립 전사한 필수선택 배열과 실제 JSON 배열을 원 단위 비교했다. 엔진·구동·외장·분류별 휠/내장·스포츠패키지 총 19개 인코딩 값 및 기본가격 비교 통과. 스포츠 휠 원문 두 행은 JSON 공통 0원 한 항목에 대응한다.
- 기존 앱 계산기를 호출하지 않고 독립 정수 계산으로 엔진 2종, 기본/스포츠, 구동 2종, 외장 2종, 해당 휠/내장, 12개 선택 항목의 모든 비트 조합을 순회했다. 파퓰러/개별 중복, ECS 불가 조건, 스포츠 3.5T 뱅앤올룹슨 중복을 제외한 **유효 가격 조합 110,592개**를 비교했다. 색상별 동일 가격·19인치 휠 디자인별 동일 가격은 별도 조합으로 세지 않았다.
- 네 경로의 최대와 전체 92,770,000원을 확인했고 provisional 동등성 assertion도 통과했다. Black은 별도 가격표로 계산했다.
- PDF 원본 2·3·6쪽을 PyMuPDF로 메모리 렌더링해 필수선택 분류, 개별 옵션의 가격 대응, 동시선택 주석 및 Black 존재를 육안 확인했다.
- Claude Code 독립 보조 검토를 위해 `claude --help` 실행을 시도했으나 **Access is denied**로 실행되지 않았다. 따라서 보조 AI의 원본 교차검증은 미실시이며 합의·통과로 간주하지 않는다. 본 파일은 요청받은 **Codex 독립 판정**이고 전체 다중 AI 품질 게이트 통과 선언이 아니다.
- 원문 가격/조건 및 계산 검증 범위에서 미해결 가격 불일치는 0건. JSON의 Black 설명 오류/구성 누락은 남아 있으며, 2열컴포트 조건 문구는 배타 오해 위험이 남아 있다. 요청대로 수정하지 않았다.
- 데이터·코드·운영·외부 시트 변경 없음. 이 판정 Markdown만 작성했다. 코드 변경이 없어 빌드·타입검사는 이번 문서 검사 범위에 적용하지 않았다. 외부 발송 없음.
