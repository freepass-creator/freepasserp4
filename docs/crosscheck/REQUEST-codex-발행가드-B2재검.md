## 1차 NO-GO(2건)를 어떻게 받았나
- **§3 부분소실 통과** — `.some()`(차 한 대만 겹쳐도 사면)이라 「한 대 남고 두 대 사라진」 표를 통과시켰다.
- **§4 정체불명 문자열** — 빈칸 아닌 문자열을 다 «차번»으로 봐 「미정」이 「미정」과 겹쳐 오사면.

**⇒ 사면 규칙을 「전부 살아 있을 때만」 + 「정체는 실번호/차대번호만」으로 조였다.**
- `carId(row)` = 실번호(`/^\d{2,3}[가-힣]\d{4}$/`)면 `P:번호`, 아니면 차대번호(norm 길이≥6)면 `V:차대`, 둘 다 없으면 `''`(정체불명 — 사면 근거 못 됨). 차 적재 필터(REAL_PLATE·VIN≥6)와 같은 규격.
- 코드 k 별로 직전 줄 수 `total` 과 «이번 발행 nowIds 에 확인된 수» `here` 를 센다.
- **사면 alive(k) = total>0 && here===total** — 직전 줄이 «전부» 이번에 살아 있을 때만. 한 대라도 확인 안 되면(사라짐/정체불명) 사면 안 함 → 막는다.

코드: `scripts/publish-origin-tab.mts` 가드 909~941(carId·nowIds·prevCars·alive·gone). before 는 라벨→코드 환원 카운트, now 는 라벨→코드 현재 카운트(배포 가드 그대로).

## 확실히 답해 달라
1. **§3 재검** — 「직전 3대 중 한 대만 다른 코드로 남고 두 대는 사라진」 입력을 이 코드로 다시 돌려라. here=1,total=3 → alive=false → **막히나**? (1차엔 통과했음)
2. **§4 재검** — 직전 A가 (미정,VIN_OLD)+실번호2대이고 현재 A 차가 전부 없는데 B에 (미정,VIN_NEW)만 있는 입력. 「미정」은 carId=''(정체불명)이라 겹쳐도 무의미하고, A의 실번호 2대·VIN_OLD 가 없어 alive=false → **막히나**?
3. **정상 개명 사면 유지** — 임의 개명(supplierNameKeys 못 잇음)인데 그 공급사 «차 전부»가 실번호/차대번호로 이번 발행에 그대로 있으면 → alive=true → **통과하나**? SPELL_PAIRS(에스에이→SA 등)·모호키(가온) 무소실도 배포본과 같은가?
4. **정체불명·열 없음 축퇴** — 직전/현재에 차량번호·차대번호 열이 없거나, 공급사 차가 전부 VIN도 실번호도 없으면 alive=false 로 «막힘»(배포 가드대로)인가?
