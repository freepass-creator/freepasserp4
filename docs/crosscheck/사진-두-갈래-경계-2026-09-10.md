## 1. 갈래가 둘이다 — 경계

같은 「사진이 안 보인다」를 **양쪽 끝에서** 잡고 있다. 둘 다 필요하고, 서로 덮지 않는다.

| | 무엇을 | 어디에 넣나 | 언제 |
|---|---|---|---|
| **원천→원자** | 원천 API 가 «사진 목록»을 주는 공급사(손오공·오플) | `image_urls` (+`photo_source_hash`·`photo_collected_at`) | 인제스트 |
| **링크 풀기** | 사진이 «드라이브 폴더 · 상세페이지 링크»인 공급사 | `photo_cache` | 회차 `⑦″` |

★**부딪히지 않는 이유** — `scripts/cache-photo-urls.mts` 는 `productImages(p).length` 가 있으면
그 차를 **아예 건너뛴다**(「저장된 직접 사진이 있으면 그게 정본이다 — 캐시로 덮지 않는다」).
손님 정제기(`sanitizeProductForGuest`)도 **`image_urls` 를 먼저** 쓰고 없을 때만 캐시를 쓴다.
⇒ 원자에 사진이 들어오는 차는 자동으로 원천 쪽이 이긴다. **같은 칸에 둘이 쓰지 않는다.**

## 2. ★머지 말고 «리베이스» — 안 그러면 되돌아간다

`codex/photo-projection-integrated` 는 **[#236](https://github.com/freepass-creator/freepasserp4/pull/236) 이전 main** 에서 갈라졌다.
그 판을 얹어 실제로 재 봤다 — 넷이 되돌아간다:

```
✗ 채우는 쪽이 파이어스토어에 안 씀   → 손님 화면에서 208대 사진이 다시 사라진다
✗ { merge: true } 없음               → 문서를 통째로 갈아치운다
✗ 미러 CARRY 에 photo_cache 없음     → RTDB 에 채워도 손님 원장에 안 간다(원래 사고가 이것)
✗ 사진 합치는 자가 «글자 비교»       → 같은 파일이 sz= 만 달라 두 장으로 세어진다(「1 / 91」)
```

⇒ **`origin/main` (≥ `1c16ff18`) 로 리베이스한 뒤 올린다.**
기계 검사 = **`npm run check:photo-ledger`** — 2026-09-10 부터 **CI(`verify`)에 걸려 있다.**
넷 중 하나라도 되돌아가면 그 PR 은 빨간불이다. 검사를 고쳐서 통과시키지 마라.

⚠ 겹치는 파일은 여섯이다 — `scripts/cache-photo-urls.mts` · `scripts/mirror-to-firestore.mts` ·
`scripts/hourly-sync.mts` · `components/use-product-photos.ts` · `lib/domain/product-photos.ts` ·
`lib/server/firestore-ref-shim.ts`.

`/api/extract-photos` 도 0장을 준다 — **사진이 있는데 화면에는 없다.**

**완료조건** — 이 12대가 손님 API 에서 사진을 갖고 나온다:
```bash
curl -s "https://freepasserp.com/api/catalog/feed?_=$(date +%s)" \
  | node -e "let s='';process.stdin.on('data',d=>s+=d).on('end',()=>{const a=JSON.parse(s).products||[];
     const t=['05수4035','05수4658','05수4937','11오0103','35서4634','35서5793','48나2106','48나2242','63버0542','63주0514','63주0654','63주1073'];
     for(const p of a) if(t.includes(String(p.car_number))) console.log(p.car_number,(p.image_urls||[]).length+'장');})"
```
⚠ `?_=<타임스탬프>` 를 꼭 붙인다 — 안 붙이면 CDN 이 옛 본문을 준다(그것 때문에 한 번 「안 고쳐졌다」고 봤다).

★**대안(고치지 마라)** — `NEEDS_SERVER_RE` 에 「확장자가 그림이면 직접」을 넣는 길도 있다.
그건 **손님 화면 갈래의 파일**(`lib/domain/product-photos.ts`)이라 여기서 손대면 §2 의 되돌리기가 된다.
원자로 푸는 편이 옳고, 그래도 남으면 그때 이쪽에서 잰다.
