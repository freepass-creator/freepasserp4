## 2. 판정해 주실 것 (읽기 전용)

1. **일체감** — `/shop`(목록) → `/q/[code]`(상세)로 넘어갈 때 **같은 값이 다른 모양**으로 보이는 것이
   더 남아 있는가. 특히 칩·색·글자 크기·둥글기.
2. **웹 폭 활용** — 1440px 에서 «빈 자리»가 남는 구역이 더 있는가(대여료 기간표 오른쪽, 보험 면책금 줄을
   제가 아직 안 건드렸습니다). 각 구역의 격자 채움률을 재 주시면 좋겠습니다.
3. **전수 렌더링** — 721대 중 아래 조합에서 깨지는 화면이 있는가.
   ㉠ 사진 없음(28%) ㉡ 정책 없음(265) ㉢ 옵션 없음(245) ㉣ 내장색 없음(32%)
   ㉤ 주행거리 없음(127 — 그중 76대는 원천이 색 이름) ㉥ 기간 1개만 있는 차 ㉦ 기간 7~10개인 차
   ㉧ 전기차(42 · 배터리 칸) ㉨ 차명이 아주 긴 차(차명 줄에 차번·신원 칩이 같이 선다)
4. **되돌려진 것이 없는가** — `npx tsx scripts/check-design-locked.mts` 가 통과하는데도
   문서(`docs/DESIGN_CONFIRMED_SHOP.md`)와 화면이 어긋나는 곳.
5. **주행거리 원천** — `npm run audit:axis-coverage` 가 「Km 숫자 아닌 값 76대(RP023 72 · RP004 4)」를
   잡습니다. **판매시트 「오플구독」 탭 3행은 Km 45,034 · 외장 블랙으로 바르게 적혀 있고**,
   같은 헤더를 `autoMapHeaders` 에 넣으면 `mileage→10(Km)` 로 바르게 잡힙니다.
   그런데 ERP `v4/products/RP023_05수4658` 의 `mileage` 는 「블랙」이고 `ext_color` 는 빈칸입니다
   (`sheet_source_tab: 오플구독 09.04 20:40 · 73대` · `sheet_source_row: 3` · `updatedBy: sheet_daily_sync`).
   **그 값을 쓴 유입 경로가 어디인지**만 찾아 주십시오(고치지는 마십시오).

## 3. 검사 명령

```
npx tsc --noEmit
npx tsx scripts/check-design-locked.mts
npm run check:building
npm run build
npm run audit:axis-coverage
```

⚠ `check:building` 은 다른 세션이 올린 `/connectors` 층이 도면에 없어 실패합니다 — 이번 변경과 무관합니다.
⚠ `check:fonts`/`check:tokens` 는 이번 변경 전부터 있던 전역 드리프트입니다.
