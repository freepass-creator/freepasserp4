## 무엇을

`app/login/page.tsx` 의 raw 컨트롤 17개와 페이지 안에 박힌 CSS 문자열(`LOGIN_CSS` 53줄)을 걷고,
**공용 원자로만** 세운다. 건물에서 손님·영업자가 제일 먼저 여는 문인데 지금 이 한 파일이
남은 임기응변의 **3분의 1**(raw 17 · 높이 18)을 갖고 있다.

## ★선결 — 이건 Claude 가 «먼저» 한다. 커서는 손대지 않는다

지금 로그인 칸은 **웹 44 / 모바일 48**, 원자(`md`)는 **웹 32 / 모바일 40** 이다.
그냥 갈아끼우면 **현관 입력칸이 44 → 32 로 작아진다.** 인증 한 장만 있는 화면에서 32는 좁다.

그래서 원자에 **`lg` 한 단**(웹 44 / 모바일 48 · 글자 웹 13 / 모바일 16)을 더한다 —
지금 로그인 CSS 의 값과 **정확히 같다**. 페이지에 규격을 두지 않고 원자를 고치는 것이
`CLAUDE.md` 절대원칙 1(「새 UI가 필요하면 페이지가 아니라 원자를 고친다」)이다.

- `components/ui/tokens.ts` → `CTRL` 에 `lg: { web: 44, mobile: 48, fsWeb: 13, fsMobile: 16 }`
- `Input` · `Select` · `Btn` 이 `size="lg"` 를 받게

**커서는 `components/ui/**` 를 이 오더에서 «읽기만» 한다.** 범위에 없으므로 건드리면 가드가 잡는다.

## 어떻게

1. **입력칸** — `login-field` 3종(로그인 2 · 가입 7 · 재설정 1) → `Input size="lg" full` + 라벨.
   `type` · `autoComplete` · `inputMode` · `placeholder` 는 **지금 값 그대로** 옮긴다(자동완성이 깨진다).
2. **고르는 칸** — 활동 유형 `<select>` → `Select size="lg" full`. 선택지 4개 문구·값 그대로.
3. **버튼** — `login-submit` 3개 → `Btn size="lg" full`. `disabled` 조건 그대로
   (특히 가입 버튼의 `!agree.terms || !agree.privacy`).
4. **동의 체크 3개** — `ConsentBox` 의 `<input type="checkbox">` → `Checkbox` 원자.
   **행 전체가 눌리는 동작(44px 타깃)을 유지**한다. 「전체 동의」가 둘을 같이 켜고 끄는 것도 그대로.
5. **로딩** — `.login-card.is-loading::before` 스피너(32px 원) → `Loading` 원자.
6. **알림 줄** — `login-msg` 의 `tone` 3종(muted·ok·err) → `Message` 원자.
   ⚠ 파란 안내 박스를 쌓지 말 것 — 지금처럼 **한 줄**이다.
7. **`LOGIN_CSS` 는 남기되 «치수»를 다 걷는다.** 남을 것은 아래 셋뿐이다.
   - 워드마크(`login-brand*`) — Exo 2 명함 CI. **글꼴·자간 그대로**
   - 전면 덮기(`.fp-login{position:fixed;inset:0}`) — 앱 셸 밖 인증면이라 필요하다
   - 모바일 흰 바탕(`@media` 안 `background:var(--bg-card)`) — 사장님 2026-08-23 결정.
     ★**이건 지운 적이 있어 다시 넣은 규격이다.** 지우면 회색 페이지 위에 흰 띠가 뜬다

## 건드리지 않는 것 (하나라도 바뀌면 되돌린다)

- **문구 전부** — 제목·설명·라벨·placeholder·에러 한글 메시지(`AUTH_MSG` 12줄)·안내문
- **검증·흐름** — `hasEmailShape`·비밀번호 6자·비밀번호 확인·`waitForSession`·`loginDestination`
  (오픈 리다이렉트 방어) · 가입 실패 시 `authUser.delete()` 되돌리기
- **동의 저장** — `consent: { terms, privacy, version: LEGAL_VERSION }` 를 프로필과 **같은 저장**에 넣는 구조
- **사업자번호 실시간 매칭** — 200ms 디바운스·10자리 포맷·`is-ok`/`is-miss` 문구
- 버그를 봐도 **고치지 말고 보고**한다. 원자가 모자라도 **만들지 말고 멈추고 보고**한다.
