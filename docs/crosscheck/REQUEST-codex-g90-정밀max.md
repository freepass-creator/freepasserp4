## 검증해 달라 (검사만·고치지 마라 — 어긋난 것 보고하면 클로드가 고침)
1. **tmp/mtops/G90.html 를 독립 파싱**해, 위 개별 옵션가 목록이 맞나(원단위).
2. **G90 정밀 max(풀옵션)를 «유효 완성구성»으로 직접 계산**하라:
   - 배타(하나씩): 48V·AWD·VIP4인승·매트·21인치·시그니쳐내장 최대선택.

   - 뒷좌석컴포트Ⅰ·Ⅱ 는 «개별 유료옵션»이니 max 에 포함돼야 하나(내 값 138,550,000 은 이 둘을 뺐다 → 진짜 max 는 145,050,000 아닌가?).

3. **maxPrecise 정답을 원단위로** 제시하고, 내 138,550,000 과의 차이 원인을 짚어라.
