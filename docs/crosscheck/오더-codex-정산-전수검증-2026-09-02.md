# 코덱스 오더 — 26년08월 정산 전수검증 (2026-09-02)

> 근거: CLAUDE.md 「협업 파이프라인」 — 「코덱스 = 검사만. 어긋난 것을 보고하면 내가 고친다」

## 무엇을 (한 문장)

26년08월 청구 47줄이 **원본 시트와 1:1 로 맞는지**, 그리고 **태윤 매니저 총액과의 차이가 어느 업체에서 나는지**를 독립으로 다시 세어 보고한다.

## 고치지 않는다

**파일을 하나도 바꾸지 않는다.** 어긋난 것을 찾으면 «어느 줄이 어떻게 어긋났는지»만 적는다.
고치고 싶어지면 그 자리에서 멈추고 보고한다.

## 어떻게 — 넷을 각각 «따로» 센다

### ① 시트 ↔ 화면 대조 (차번으로 맞댄다, 숫자만 비교하지 않는다)

```
원본  10gsCRpRZZVI9WGZK0b1JeGeti9mQFt4ojWXHqPCW-Ls  탭 「프리패스 26/8」
신규  1BjGBqAjRLEb9ZMKarpQsMF-q_UjdgmEqBAl1uVk8SR4  탭 「26년08월」
```

- **차번 기준**으로 「시트에만 있는 차 / 탭에만 있는 차」를 뽑는다.
- ⚠ **시트 필터에 가려진 줄을 «없는 줄»로 세지 않는다.** 2026-09-01 에 그렇게 세서
  박지원 줄을 통째로 빠뜨렸다(`basicFilter.criteria[].hiddenValues`).
- ⚠ **차번 없는 줄이 있다**(업무지원비). 차번으로 못 맞추면 고객명+금액으로 맞춘다.
- 금액은 **수식 결과가 아니라 «적힌 값»(수식X 열)**이 정본이다.

### ② 태윤 매니저 총액과의 차이가 «어느 업체»에서 나는가

```
태윤   청구 48,073,770 · 지급 40,339,156
우리   청구 43,181,120 · 지급 38,871,406
차이   청구 -4,892,650 · 지급 -1,467,750
```

업체별 합계를 양쪽에서 뽑아 **어느 업체 몇 줄에서 벌어지는지**까지 좁힌다.
총액만 맞춰 보고하지 않는다 — 그건 이미 알고 있다.

### ③ 스타스카이 「한 달 렌탈료」가 실제로 몇 갈래인가

표는 「한 달 렌탈료(VAT 포함) · 지급 80%」라 적혀 있는데 **실측은 갈린다**:

```
125호8928  렌탈료 780,000 → 청구 780,000   (1.00배)  지급 0.80
101하8578  렌탈료 700,000 → 청구 1,092,000 (1.56배)  지급 1.20
125하2544  렌탈료 1,700,000 → 청구 2,295,000 (1.35배) 지급 1.08
101호7919  렌탈료 1,800,000 → 청구 2,000,000 (1.11배) 지급 1.05
```

`v4/settlement_rows` 의 **스타 전 줄**을 배수로 갈라, 몇 갈래인지·무엇이 갈래를 가르는지
(기간? 상품구분? 메모?) 판정한다. **한 갈래로 안 떨어지면 「안 떨어진다」가 답이다** — 억지로 규칙을 만들지 않는다.

### ④ 「표에 없는」 3줄이 정말 표에 없는가

```
15다4180   엘씨렌트  구독60  청구 660,000  (렌탈료 400,000 → 1.65배)
333모5593  빌린카    구독60  청구 742,500  (렌탈료 450,000 → 1.65배)
(차번없음)  (미기재)          청구 0
```

엘씨렌트 = 빌린카(LC) 로 붙여 놨는데도 **구독 갈래가 표에 없다.**
「수수료표」 탭 159줄을 전수로 훑어 **빌린카 구독 규칙이 정말 없는지** 확인한다.
있으면 어느 줄인지, 없으면 「없다」고 적는다. **1.65 를 규칙으로 박지 않는다** — 실측 2건뿐이다.
