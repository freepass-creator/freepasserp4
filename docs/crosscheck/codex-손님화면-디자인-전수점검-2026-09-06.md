# 손님 화면 디자인·규격 전수 점검 — Codex → Claude

점검 시각: 2026-09-06 KST  
범위: 유니오토모빌 손님 여정(`/uniauto` 목록 → `/q/[code]` 상세), 웹·모바일 공통 원자, 반응형 규칙, 정적 디자인 게이트

## 결론

**확정된 정보 구조와 목록·상세의 표현 규칙은 유지되고 있다.** `npm run check:design` 및 TypeScript 검사는 통과했다.

다만, **760~약 1,140px의 웹/태블릿 구간에서 목록 3열이 물리적으로 너무 좁아지는 반응형 결함**이 있고, 손님 화면의 토큰·UI 계약 검사에 미해결 드리프트가 남아 있다. 기능 오류는 아니나, 이 상태를 "전체 규격 통일 완료"로 보기는 어렵다.

운영 배포나 화면 변경은 하지 않았다.

## 수정 우선순위

### P1 — 목록의 태블릿/좁은 웹 반응형

현재 `MOBILE_BP`는 760px이고, 목록 웹 배치는 `260px` 필터 + `32px` 간격 + 카드 `3열`이다.

760px 뷰포트에서 본문 폭은 약 712px이며, 필터와 간격을 빼면 카드 영역은 약 420px, 열 사이 간격 48px을 빼면 **카드 1장당 약 124px**이다. 1024px에서도 약 212px 수준이다. 카드 안의 사진·차명·금액은 줄어들거나 답답해질 수밖에 없다.

권고안:

1. 목록 전용 `compact desktop` 분기(권장 1,120~1,140px 이하)를 둔다.
2. 그 구간에서는 2열/자동열(`minmax(250px, 1fr)`)로 내리고, 더 좁은 폭에서는 왼쪽 필터를 시트/드로어로 전환한다.
3. 공통 `MOBILE_BP`를 무턱대고 올리지는 않는다. ERP 전체의 모바일 규격까지 함께 바뀌므로, 가게 목록의 레이아웃 분기만 따로 둔다.

### P2 — 토큰·원자 드리프트 정리

`npm run check:tokens`는 19건 실패이며, 이 중 손님 화면 관련은 15건이다. 대표적으로:

- `ShopDetail`: 17/18/20/22px, 굵기 800, 사진 위 RGBA·`#fff`.
- `shop-ui`: 웹 대수 26px·800.
- `ShopFilterSheet`: 스크림 RGBA.
- `ShopDetailView`: 오류/빈 상태 CTA의 `#fff`, `borderRadius:999`.

대부분 현재 보이는 모양을 깨뜨린다는 뜻은 아니지만, 채널 색·타이포·스크림을 전역에서 바꿀 때 이 부분만 남아 화면이 갈라질 위험이다. `C`/`FS`/`FW`/`SCRIM`/반경 토큰으로 이관하되, 손님 동의 별도 스케일(`SHOP`)은 유지한다.

### P3 — 재발 방지 게이트 보강

- `npm run check:ui`는 11건 실패. `shop-ui`·상세·필터 시트의 raw 컨트롤은 손님 동 자체가 규격 원자라는 문서와 일부 충돌해 **검사 기준이 현실과 맞지 않는다**. 무작정 예외 처리하지 말고, 허용되는 손님 원자 파일과 금지되는 페이지 손롤을 구분해야 한다.
- `/uniauto`가 `docs/건물도면.md`에 없어 `npm run check:building`이 실패한다. 현재 이 경로는 고객용 진입점인데 도면/게이트 밖이므로, 다음 구조 변경에서 회귀 탐지가 빠진다.
- `WhitelabelFrame`의 모바일 머리 높이(56)와 sticky CSS `top:56px`은 두 파일에 중복되어 있다. `--shop-header-h` 같은 한 토큰으로 묶어야 한쪽만 바뀌는 회귀를 막을 수 있다.
- JS의 모바일 판정은 `<760`, 한 CSS 글자 규칙은 `max-width:760px`다. 정확히 760px에서 글자는 모바일, 배치는 웹이 되는 1px 혼합 구간이 있다. `759px` 또는 `min-width:760px`로 경계를 통일한다.

## 시각 검증의 남은 공백

이번 세션은 브라우저 자동화 표면이 없어 실제 Chrome 스크린샷/LCP를 찍지 못했다. 코드·수치·게이트 검증만으로는 실제 렌더의 줄바꿈과 사진 비율을 완전히 대체하지 못한다.

P1 반영 후에는 최소 다음 폭을 시각 회귀 기준으로 고정해야 한다: **375, 430, 760, 1024, 1280, 1440px**. 목록의 첫 카드·필터·정렬과 상세의 사진·대여료표·하단 독을 각각 캡처해 비교한다.
