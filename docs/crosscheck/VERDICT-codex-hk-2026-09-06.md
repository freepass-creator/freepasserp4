검사 범위·미통과 항목: 38개 모델의 `min = min(trimLadder)`와 `maxCandidate = max(trimLadder) + sum(optionSuperset)` 산술은 모두 일치했다. 현대 23개 min은 `data/new-car/hyundai.json`(2026-09-05 공식 API 수집본, 연료 접미사 통합·양수 taxIncentive 차감)과 모두 일치했다. 기아 15개는 로컬 가격표를 대조했고 K5·K8의 용도/자격별 저가 구성 누락을 위 표에 기록했다. EV 가격표의 서울시 국가·지자체 보조금 적용 예시는 세제후 차량가격과 구분하여 제외했다. 아반떼 **23,980,000**은 [현대 공식 가격 페이지](https://www.hyundai.com/kr/ko/e/vehicles/the-new-avante/price)의 2026-08-05 기준 모던 가격과도 일치하여 오류 행에서 제외했다. 구형 `hy_avante.txt`의 낮은 가격으로 현재 min을 오류 처리하지 않았다.
