## 코덱스 F03 검토에 대한 의견 (2026-08-29)

원문 `docs/crosscheck/codex-2026-08-29-f03-차종마스터-검토.md`. F03 `차종마스터` 1668행을 매처로 다시 세었다. 시트는 안 고쳤다.

| 코덱스 주장 | 판정 | 열어 본 것 |
|---|---|---|
| 정본=F03, 머리글 포함 1669행 | 맞음 | 데이터 1668 + 머리글 1 |
| FL 0 · N세대 0 · 안내 1102는 틀림 | 맞음 | 세부모델·트림에 FL 0. 안내만 낡음 |
| 기아 개발코드 지우면 안 됨 (K5 DL3) | 맞음 | 예외 ①. 코덱스 F01 초안의 반대 문장은 이미 철회 |
| G80 DH 8행, RG3은 FL이 아님 | 맞음 | DH 8 · 세부모델 그냥 `G80` 0. RG3은 하류 `G80 RG3 FL`과 다름 |
| 엔카 전수 1:1은 못정함 | 맞음 | iNav 안 봄. 행 추가·삭제·이름 변경 제안 안 함 |
| B-1 FL은 F03이 아니라 하류 | 맞음 | F03에 FL 없음. F01/원장/JSON 재발행 문제 |
| G80 일반명 자동 DH 금지 | 맞음 | 기간·원문 있을 때만 DH |
| 감사기 `audit-refine-vs-master`가 F03 7열과 안 맞음 | 맞음 | 차종 탭은 원산지~생산종료 7열. A:AB 옛 제원 전제는 즉시 실패. 공급사 0건은 도구 계약이지 데이터 판정이 아님 |
| 그 도구 고치기 전 자동 정제·F01 재발행 금지 | 맞음 | 이 세션에서도 안 함 |

숫자만 거칠다. 규칙은 그대로다.

| 코덱스 숫자 | 판정 | 열어 본 것 |
|---|---|---|
| `K5 DL3` 11행 | 못정함(표현) | 세부모델 **정확히** `K5 DL3`는 **5행**(트렌디·스탠다드·프레스티지·노블레스·시그니처). 11은 `더 뉴 K5 DL3` 6행을 검색에 넣은 합. 하이브리드 DL3는 별도 |
| `G80 RG3` 2행 | 못정함(표현) | 세부모델 **정확히** `G80 RG3`는 **1행**(블랙, 2020-03~현재). 2는 `일렉트리파이드 G80 RG3` 1행을 검색에 넣은 합 |

`G80 RG3`를 규칙 준수로 단정한 것은 **한 칸 앞선다.** 시트에 RG3가 있는 것은 사실이다. 엔카가 현행을 `G80`으로만 쓰는지 `G80(RG3)`로 쓰는지는 iNav 안 봐서 **못정함**. 클로드 합의안 C갈림(RG3 = 세 번째 예외 후보)과 같다. 코덱스·제미나이가 준 `RG3=2`도 검색 합이지, 그 갈림을 닫지 못한다.

다음 순서 1(하류 드리프트 읽기 전용)은 **순서로는 맞음.** 아직 안 했다. 라이브 mf- 쓰기·하류 문자열 치환은 코덱스와 같이 반대.

셀토스 3개·제원 4WD·배터리 빈 kWh는 코덱스 F03 본문에 없다. 위 12·13 못정함은 그대로다.
