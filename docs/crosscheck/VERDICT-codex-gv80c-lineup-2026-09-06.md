**tax35까지 같은 결론을 확대하면 틀림.** 병기된 가격의 프리미엄은 아래와 같다.

## ③ 표준 48V 115,190,000의 갱신 후 유효성 — 틀림

근거: `basePrice`(15행), `freeOptions`(143~222행), `minMax`(224~252행), 표준 48V tax5 및 상한(274~281행).

현재 표준 48V 기본가는 `81,400,000 + 10,550,000 = 91,950,000`으로 lineups.tax5와 일치한다. 무광 700,000, 셀렉션Ⅱ 1,500,000, 48V 기본 22인치 0원을 적용한다.

개별옵션 합계는 아래처럼 **21,740,000**이다. 전동 스텝을 선택하고 고정식 490,000은 제외했으며 파퓰러 패키지는 별도로 가산하지 않았다.

```text
1,400,000 + 1,300,000 + 3,200,000 + 1,950,000 + 2,700,000
+ 2,200,000 + 1,900,000 + 850,000 + 3,000,000 + 2,450,000
+ 500,000 + 200,000 + 90,000 = 21,740,000
```

| 경로 | 현재 파일로 재계산한 산식 | 금액 | 115,190,000 대비 |
|---|---|---:|---:|
| `maxConfig`의 파퓰러 경로 | 91,950,000 + 700,000 + 1,500,000 + (21,740,000 − 6,800,000 + 6,200,000) | 115,290,000 | +100,000 |
| `maxPreciseConfig`의 개별 경로 | 91,950,000 + 700,000 + 1,500,000 + 21,740,000 | 115,890,000 | +700,000 |

파퓰러 포함 4개 개별가는 `1,300,000 + 1,950,000 + 2,700,000 + 850,000 = 6,800,000`으로 패키지 6,200,000보다 600,000 높다. 현재 파일은 서로 600,000 차이가 나는 두 경로를 같은 115,190,000으로 적고 있다.

이력도 확인했다. 직전 커밋 `bb26aee0`의 기본가는 81,300,000이며, 당시 `minMax.maxStatus`는 파퓰러 경로 115,190,000과 개별 경로 115,790,000을 구분했다. 현 HEAD에서 기본가가 100,000 올랐지만 115,190,000은 그대로 남았고, 개별 경로라는 설명까지 붙었다. 따라서 **이전 파퓰러 금액 잔존 + 개별 경로 설명과의 불일치**가 확인된다.

같은 엔트리 내 잔여 검증값도 갱신되지 않았다.

- `liveCrossCheck.expected` 91,850,000은 현재 기본가+48V 91,950,000과 100,000 다르다. 현재 lineups.tax35와는 같으므로 세율 기준을 명시하지 않은 과거 관측을 tax5 검증으로 사용할 수 없다.
- `recommendedCrossCheck.computed` 세 값은 현재 구성으로 각각 91,700,000 / 99,000,000 / 108,350,000이어야 하나 91,600,000 / 98,900,000 / 108,250,000이 남아 있다. 저장된 match=true를 현재가 통과 증거로 볼 수 없다.
- 같은 115,190,000을 반복한 표준 `maxPreciseShowroom`, `maxCandidate`, `maxPrecise`, 휠 note, `realWorldNote` 역시 현 tax5·기재 구성의 검증값으로 유효하지 않다.

115,890,000은 파일에 선언된 개별 경로의 계산값이다. BTO가 개별 선택을 패키지로 자동 전환하는지, 내장 추가금과 모든 옵션의 동시 선택이 유효한지는 이번 검사에서 확인하지 않았으므로 실주문 상한으로 단정하지 않는다.
