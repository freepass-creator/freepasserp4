1. **차종 매칭 무조건 F03 차종마스터 시트 기준.** 별칭맵의 «타겟(오른쪽)»은 **반드시 F03에 실재하는 모델/세부모델**. F03에 없는 형태(디 올 뉴 싼타페 MX5 등) 타겟 금지.
2. **정제칸/F01 세부모델 ∈ F03** (발행 직전 `assertSubmodelInF03` 게이트). 비-F03 출력 절대 금지.
3. **F03 기존 항목(이름 7열) 변경·삭제 금지**(동결). 맵은 «별도 데이터 파일」, F03 안 건드림.
4. **이 오더 범위 밖으로 움직이지 마라**(쓸데없는 칸·구조·문서 신설 금지).
5. **애매하면 검수대기**(추정 금지). 확정 원자만 매칭 대상.

## 만들 것 (코드 데이터)

### 1. 모델 별칭맵 `data/model-aliases.json`
원문 표기 → F03 모델. **타겟은 F03 모델에 실재해야 함(빌드 시 검증).**
- 개명: `아르카나`→`XM3` · English↔한글: `라브4`↔`RAV4` · 하이픈: `E클래스`→`E-클래스` · 표기차: `산타페`→`싼타페`.
- AI가 «미매칭 원문」을 훑어 채운다. 정확 대조 가능한 것만(추정 금지).

### 2. 세대 해석 (매뉴얼 §3-1 그대로, 코드로)

★★**함정 주의 — 기아 개발코드는 «엔카에 세대명이 있을 때만»(무조건 아님).** 나머지는 엔카 완전 동일이고 **기아만 의도적으로 세대명→개발명**(엔카 그대로 베낀 것처럼 안 보이게). 세대 하나(최초/유일)면 엔카에 세대명이 없어 코드도 없음(K8 → 「더 뉴 K8」·「K8」).
- **«허용 가능한 오류」 없음.** 엔카와 다르면 오류. F03 `K8 GL3`는 오류라 이미 「K8」·「더 뉴 K8」로 **수정 완료(2026-08-29)**.
- ★**기아 개발코드(K5 DL3 등)를 «오류」로 착각해 엔카 세대명으로 되돌리지 마라** — 의도된 차이다.
- ★**없는 코드를 «기아 무조건」 추측으로 만들지 마라**(엔카/F03에 없으면 안 붙임). 별칭맵 타겟 = F03 실재형(엔카form)만.

연식 우선 → 겹침/범위밖일 때 원문 세대표현 매핑:
- **「N세대」 → 그 모델 세부모델을 생산시작 순 정렬, N번째.** ★단 F03가 최근 세대만 가진 수입차는 «세대번호=인덱스」가 안 맞을 수 있음 → 연식으로 우선 확정하고, 세대번호로 유일 확정 안 되면 **검수대기**(억지 인덱스 금지).
- **「디 올 뉴/올 뉴/신형」 → 최신(생산시작 마지막) 세대.**
- **「더 뉴」 → 「더 뉴」 접두 세부모델.**
- 원문에 개발코드(`DN8`·`MX5`) 직접 있으면 그걸로.
- 필요시 `data/gen-hints.json`(모델별 세대표현→세부모델 예외)으로 데이터화.
