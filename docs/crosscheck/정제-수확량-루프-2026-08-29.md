# 정제 수확량 루프 — 원문에서 «발라내» 정제칸 채우기 (Claude·Cursor·Codex·Gemini)

> 사장님: 「우리는 **원문에서 정제를 해서** 채워야 해. **원문 + 공급사가 채운 칸**을 활용. 가능하면 **원문에서 배기량·구동·인승을 발라내야** 한다.」
> 「이거 **계속 수정하고 검토받고** 해야 함」 = 이 파일이 공유 루프판. 라운드마다 «자기 칸»에 append.

## 재료 (사장님 확정)

```
[원본시트 = 원문]  +  [제공시트 = 공급사가 채운 칸]   →  정제칸 채움  →  상품시트(F01)
```
- ★확정/정제 쓰기는 **정제칸(원본·제공)**에. F01은 거기서 «재발행». F01 직접 쓰면 다음 발행에 덮인다.
- 정제 = 원문 차명 파싱 + 공급사 제원칸(연료·배기량·구동·인승) 활용. 마스터-독립 근거 = **연식/최초등록** (세대) + **원문 제원** (변형).

## 루프 규약 (라운드 R)

```
1. Claude  ← 최신 dry-run으로 gap(null·medium) 유형화 → 「## 라운드 R」에 append
2. Cursor  ← gap 유형별로 원문 파서/치환사전 보강(mf-code=커서) → 커밋 → append. ★원문 안 건드림, 정제칸만. 마스터에 없으면 빈칸(추정 금지)
3. Codex   ← 재실행 dry-run 독립 검증: 오매칭 0인가(발라낸 게 틀린 세대/트림 아닌가)·null 줄었나 → append
4. 수렴: 오매칭 0 AND null 안 늘어남 2연속 → 종료. 상한 5R → 사장님/Claude
```

- ★안전: 표기 사전은 **원문→마스터 정확대조 가능한 것만**(산타페=싼타페 확실). 애매(벤츠 200)는 검수대기. English 트림은 «모델 매칭용으로 무시」하되 세부트림 확정은 마스터 풀 검증.
- 쓰기=Cursor(정제칸·백업·재읽기). 검증=Codex(안 고침). 독립표=Gemini. 게이트=Claude/사장님.
