## 사용자 최신 확정

1. 선택 옵션은 차량명 바로 아래에 실제 옵션칩으로 한 번만 표시한다.
2. 대표 월 대여료·보증금·약정기간과 전체 실제 가격 행은 `기간별 대여료` 하나의 섹션 안에 둔다.
3. 고정 36/48/60개월을 만들지 않고 공급사가 준 실제 기간을 모두 보인다.
4. 제조사·세부모델·세부트림은 차량 정보의 첫 식별줄에 둔다.
