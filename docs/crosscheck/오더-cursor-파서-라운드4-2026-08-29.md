# 커서 오더 — 세부모델 정규화 파서 (라운드 4, 읽기 전용 재측정)

> 설계·게이트: Claude · 구현: Cursor(mf-code) · 검증: Codex(오매칭). 루프판 `정제-수확량-루프-2026-08-29.md` 라운드 3 근거.
> ★이번은 **재측정(dry-run)까지.** 정제칸 쓰기·F01 재발행 없음(Codex 오매칭 검증 후 별도 게이트).

## 목표

정제 «세부모델» 정규화를 **«후보 생성 → F03 세부모델 집합 대조 → 실재 형태만 채택»**으로 바꿔, 검수대기 세부모델 미스 380 중 **약 224를 안전하게 자동후보**로 올린다. (자동후보 724 → ~948)

## 규칙 (핵심)

1. **후보 생성**: 원문/현재 세부모델에서 아래만 벗긴 조합을 만든다.
   - `FL`·`페이스리프트` 제거
   - **제조사 누출** 제거(예: `더 뉴 기아 레이 TAM` → `더 뉴 레이`)
   - **dev코드** 제거 후보(예: `쏘나타 DN8 디 엣지`의 `DN8`) — **단 F03가 그 dev코드를 쓰면 유지**(예: `싼타페 MX5`·`K5 DL3`·`G80 DH`는 F03에 있어 유지)
2. ★**「올 뉴 / 디 올 뉴 / 더 뉴 / 신형」은 엔카 실제 모델명 — 절대 벗기지 않는다**(사장님 2026-08-29). 벗기면 다른 세대 오매칭.
3. **채택 = F03 세부모델 집합에 실재하는 형태만.** 여러 후보가 F03에 있으면 **연식/생산기간으로 세대 교차검증**해 하나로. F03에 없으면 **빈칸/검수대기**(추정 금지).
4. **오매칭 방지**: 토큰 제거가 «다른 세대의 실재 형태」로 붙는지 연식·생산기간·원문 제원으로 확인. 세대가 안 갈리면 검수대기.
