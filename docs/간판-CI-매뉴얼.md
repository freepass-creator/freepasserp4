## 1. 받는다 — 무엇을 받아야 끝인가

| **로마자 철자** | ★**짐작하지 마라.** 그 회사가 도메인·명함에 쓰는 철자를 쓴다 |

## 2. 잰다 — 다섯 가지를 «자로» 잰다

```
npm run measure:brand -- <파일>     ← ①②③④ 를 한 번에 찍는다(자)
npm run check:brand                 ← ①② 를 기계가 다시 잰다(게이트)
```

### ① 투명 배경인가 (RGBA)
흰 네모를 깔고 있으면 머리띠 색이 흰색이 아닌 순간 그 네모가 드러난다.

### ② 여백이 붙어 있나 — **잉크에 딱 맞게 자른다**
> 사장님 2026-09-07 「좌측에 **CI 끝부분과 딱 정렬**되어야 하고 **CI가 너무 떨어져 있어**」

받은 원본에 빈 칸이 붙어 있으면, 줄여 넣을 때 **보이지 않는 여백**이 왼쪽에 생겨
간판 잉크가 본문 왼선과 어긋난다. 실제로 유니오토는 978×561 중 좌우 24%가 빈 칸이었다.
⇒ **여백 보정을 CSS 로 하지 마라**(음수 여백을 넣으면 제대로 된 그림이 오는 날 그만큼 파고든다).
  그림을 자른다. 허용 오차 1%.

### ③ 「이름 글자」가 그림의 몇 %인가 — `nameBand`
> 사장님 2026-09-08 「**하허호 CI는 조금 커야지**」

★★**간판 그림에는 글자만 있지 않다.** 하허호 간판(290×78)은 **악수 심볼이 세로를 다 쓰고**(94×78)
정작 「하허호」 글자는 **33px** 뿐이다. 그림끼리 높이를 맞췄더니 글자가 **10.6px** 로 앉았다
(옆 채널의 「UNI」는 16.7).
⇒ **맞추는 것은 그림이 아니라 글자다.** 잉크 열(列)을 끊어 조각을 나누고, «글자» 조각의
  세로 ÷ 전체 세로를 `logo.nameBand` 에 적는다(하허호 = 33/78 = 0.423).
⚠ **조각 고르기를 기계에 맡기지 마라.** 하허호는 「무심사」 뱃지(0.5)가 글자(0.42)보다 높아서
  「제일 높은 조각」 규칙이면 틀린다. `measure:brand` 는 조각을 «나눠서 보여 줄» 뿐 고르지 않는다.
  · 비율 1 에 가까운 조각 = 심볼(세로를 다 쓴다)   · 면이 넓고 색이 다른 조각 = 뱃지
  · 낱자마다 조각이 끊길 수 있다 — 그 무리는 비율이 서로 비슷하다.

### ④ 브랜드색 — 색만 재지 말고 **대비**를 잰다
`brandColor` 는 `--text-link` 와 칩 바탕에 그대로 들어간다. 그래서 **읽히는지**가 색보다 먼저다.

| | 하허호 원색 `#FD7015` | 우리가 쓴 `#C35610` |
|---|---|---|
| 흰 바탕 위 글자 | 2.8:1 | **4.51:1** |
| 그 색 위 흰 글자 | 2.8:1 | **4.51:1** |

⇒ **색상(hue)은 건드리지 않고 명도만 내린다.** 같은 색으로 읽히면서 글자가 읽힌다.
  **간판 그림은 원색 그대로 둔다** — 그림은 안 건드린다.
★밝은 브랜드색(오렌지·노랑·연두)을 받으면 **넣기 전에** 대비부터 잰다.
⚠ 이건 우리 판단이다. 사장님이 「그 색 그대로」 하시면 바꾼다 — 그때는 **읽힘을 포기하는 결정**이다.

### ⑤ 밑선·캡 — 글자로 그릴 때만
글꼴 지표를 **추정하지 마라.** 밑선은 높이 0 짜리 `vertical-align:baseline` 상자로 직접 재고,
캡은 canvas `actualBoundingBoxAscent`(실제 잉크)로 잰다.
⚠ 2026-09-07 에 추정으로 `CAP_NUDGE` 를 적었다가 **부호까지 틀렸다** — 심볼이 1.68px 내려앉았다.

## 3. 고른다 — 그림이 «심볼»인가 «이름»인가

| | `role: 'mark'`(기본) | `role: 'lockup'` |
|---|---|---|
| 누구 | 유니오토모빌 — 육각형 **심볼**이 따로 있다 | 하허호무심사 — **이름째로 그려진 간판** |
| 글자 | 글자는 **글자로** 그린다(`wordmark`) | 그림 안에 있다 (`wordmark` 는 비운다) |
| 자리 | 워드마크 **앞**에 선다 | 워드마크를 **대신한다** |
| 높이 | `fs · CAP · 1.5` | `fs · CAP ÷ nameBand` |
| 세로 맞춤 | 앞 글자 캡 밴드(`CAP_NUDGE`·`MARK_OPTICAL`) | **맞출 글자가 없다** — 줄 가운데 |

★심볼이 따로 있으면 **글자는 글자로** 그리는 편이 늘 선명하다(배율마다 안 뭉갠다).
★이름 자체가 그림인 회사를 본문 서체로 흉내 내면 **그건 그 회사 CI 가 아니다**
  (하허호는 「무심사」 오렌지 뱃지가 통째로 사라진다).
★`lockup` 은 `ChannelSign` 이 아니라 **`ChannelWordmark` 가 그린다** — 그림이 곧 «이름»이라,
  푸터·로그인처럼 워드마크만 부르는 자리에서도 같은 얼굴이 나와야 한다.
⚠ 그림은 색을 못 바꾼다. 푸터가 톤을 내리려 넘기는 `color` 는 안 먹으므로 **불투명도**로 내린다.

## 3-2. 글자로 그리는 CI — «짜임»을 고른다

그림이 없는 회사(우리 포함)는 **폰트로 만든다.** 사장님 2026-09-09 「이거는 이미지가 아니고
**폰트로 니가 만들게** 되어 있으니까 잘 만들고」. 그때 고르는 것이 `wordmark.kind` 다.

| | `split`(기본) | `lockup` | `lockup-ko` |
|---|---|---|---|
| 누구 | 유니오토모빌 | **우리** — `freepass`+`erp.com` | 같은 짜임의 국문 |
| 뜻 | 앞이 이름, 뒤가 **보조격** | **한 낱말**을 두 무게로 | 〃 |
| 뒤 글자 크기 | 0.59배 | **같다** | 같다 |
| 서체 | 본문 서체 | **CI 서체**(Exo 2) | 본문 서체(Exo 2 에 한글이 없다) |
| 자간 | 앞 −0.02 / 뒤 +0.16em | **−0.02em** | **−0.04em** |
| 사이 | 낱말 사이(0.36em) | **한 올**(`LOCKUP_GAP`) | 한 올 |
| 색 | 한 색(먹) | `wordmark.tone` 두 색 | 한 색 |

★★**짜임을 잘못 고르면 「연하게 그린 CI」가 아니라 «CI 가 아닌 것»이다.**

### 값은 CI 센터에서 «읽는다» — 눈으로 고르지 않는다
정본은 `C:\dev\ci_center/index.html` 이다. 브랜드마다 `parts`(영문)·`koParts`(국문)가 있고,
조각마다 **무게(`w`)와 역할(`role`)**이 붙는다. 역할이 색을 정한다(`roleColor()` — `main`/`base`).

⚠⚠ **2026-09-09 에 셋이 어긋나 있었다**(찾은 방법 = 그 파일을 열어 우리 코드와 표로 맞댄 것):

| | CI 센터 | 우리가 그리던 것 |
|---|---|---|
| 영문 자간 | `.ci-logo` **−0.02em** | −0.04em ← **국문 값(`.ci-logo.ko`)을 영문에 쓰고 있었다** |
| 조각 사이 | `margin-left:2px` @42px = **0.048em** | 없음 |
| 색 | 앞 `main` + 뒤 `base` **두 색** | 한 색 |

  그대로 주면 0.118em 이 되어 두 조각이 «낱말 사이»만큼 벌어진다. 한 낱말이 두 낱말이 된다.

로그인 현관이 **전부 이 함수**를 본다. 화면은 «크기»만 정한다.
⚠⚠ 2026-09-09 까지 같은 워드마크가 **네 군데**에 손으로 짜여 있었다(간판 · 동반 표기 ·

⚠ CSS 에 CI 를 다시 적지 마라. 특히 `.login-page *{font-family:...}` 처럼 **자식을 직접 때리는**
  규칙이 있는 화면에서는 부모의 인라인 서체가 져서 CI 가 본문 서체로 눕는다 —
  그래서 원자가 **조각마다** 서체를 다시 적는다.

### 간판은 «브랜드», 책임 표기는 «법인»
사장님 2026-09-09 「프리패스 거 **freepasserp.com 으로 브랜드로고 바꿔주라**」.

## 4. 세운다 — 표에 한 줄

채널 하나 = `lib/whitelabel.ts` `WHITELABELS` **한 줄**이다. 화면 코드는 손대지 않는다.
손대는 순간 채널마다 화면이 갈라진다.

```ts
{
  key: 'haheoho',
  sitePath: '/haheoho',                       // 도메인 붙기 전 주소. 지우지 않는다
  hosts: ['haheoho.freepasserp.com', ...],    // ⚠ 그 회사 «제» 도메인은 적지 않는다
  domainReady: false,                          // Vercel 에 붙인 «뒤» true
  name: '하허호무심사',
  wordmark: { main: '', sub: '' },             // lockup 이면 비운다
  logo: { src: '...', alt: '...', role: 'lockup', nameBand: 33 / 78 },
  brandColor: '#C35610',                       // 대비를 재서 정한 값
  tel: '1688-0987',
  bizLines: [ /* 그 회사 푸터 그대로 */ ],
}
```

⚠ **그 회사가 이미 운영 중인 도메인을 `hosts` 에 적지 않는다.** DNS 를 우리가 쥔 게 아니라
아무 일도 안 일어나지만, 다음 사람이 「저 주소가 우리 화면인가」로 읽는다.

## 6. 줄에 서는 것들 — 세로 가운데를 못 박는다

간판만의 이야기가 아니다. **한 줄에 서는 것은 높이가 저마다 다르다.**

> 사장님 2026-09-08 「**세로바도 안 맞고 위치 정렬 가로라인 잘 맞춰 주세요**」

★가름선 높이 = 이웃 칩의 **62%**(26 → 16). 같은 높이면 그건 선이 아니라 «빈 칩»으로 보인다.

| 「간격을 잘 맞춰야 함」 | 자간이 마지막 글자 «뒤»에도 붙어 적은 값과 보이는 값이 갈렸다 |
| 「**haheoho 인데?**」 | 로마자 철자를 짐작했다 |
| 「**하허호 CI는 조금 커야지**」 | 잉크 전체를 「글자」로 봤다 — 심볼이 세로를 다 쓰고 있었다 |
| 「**세로바도 안 맞고**」 | 줄에 `align-items` 를 안 걸어 높이 다른 것만 위로 붙었다 |
