# 상품 연동 화면 — 아이언을 별도 취급하지 않는다

2026-08-05 · Claude 설계 · 구현은 Codex(해당 파일 작업 중)

## 사용자 지적

> 아이언 홈페이지라고 별도 취급할 필요 없고… **연동 방식이 홈페이지인 것뿐이잖아**

맞다. 지금 화면은 이렇게 갈라져 있다.

```
┌ 홈페이지 직접 연동 ─────────────────────┐   ← 아이언렌트카만 전용 카드
│  아이언렌트카 (RP006)                    │      [데이터 검증] [검증 결과 반영]
└────────────────────────────────────────┘
┌ Google Sheet 연동 공급사 · 16곳 ─────────┐
│  공급사 | 연동 방식 | 신규 | … | 상품 연동 │   ← 표에 이미 「연동 방식」 열이 있다
│  경진렌트카 | Google Sheet | 검증 전 |    │
└────────────────────────────────────────┘
```

**표에 「연동 방식」 열이 이미 있는데** 아이언만 위로 빠져 있다. 공급사가 17곳인데 화면은
「16곳 + 특별 케이스 1」로 읽힌다. 공급사를 늘릴수록(웹연동 대상이 더 생기면) 더 나빠진다.

## 바꿀 것

**섹션 하나 · 표 하나.** 아이언은 표의 한 행이고, `연동 방식` 칸이 `홈페이지`일 뿐이다.

```
┌ 상품 연동 공급사 · 17곳 ────────────────────────────────────┐
│  공급사        | 연동 방식     | 신규 | 상태변경 | … | 상품 연동 │
│  아이언렌트카   | 홈페이지      | 검증 전 |        | [검증][반영] │
│  경진렌트카    | Google Sheet | 검증 전 |        | [검증][반영] │
│  …                                                          │
└────────────────────────────────────────────────────────────┘
```

- 섹션 제목에서 `Google Sheet` 를 뺀다 → **「상품 연동 공급사 · N곳」**
- `roster` 에 아이언을 포함해 세고 정렬한다(공급사 코드순).
- 「홈페이지 직접 연동」 전용 카드는 없앤다.

## 행 안에서 갈리는 것 — 여기만 분기하면 된다

같은 표·같은 버튼 이름이고, **누구를 부르느냐만 다르다.**

| | Google Sheet | 홈페이지 |
|---|---|---|
| 검증 | 기존 시트 검증 경로 | `refreshIronRentcarPreview()` |
| 반영 | 기존 커밋 경로 | `applyIronRentcarPreview()` |
| 결과 표시 | 신규·수정·부재차단 | 같은 칸에 같은 의미로 |

판정은 **파트너 설정**으로 한다 — 컴포넌트에 공급사 코드를 박지 말 것.
`sheet_url` 이 있으면 Google Sheet, 홈페이지 연동 플래그(현재 아이언 전용 소스가 붙은 파트너)면
홈페이지. 새 웹연동 공급사가 생겨도 코드 수정 없이 행이 늘어야 한다.

## 상세 패널

지금 아이언 미리보기 상세(49/24/25 · 수정·신규·부재차단)는 전용 카드 아래에 따로 있다.
**표에서 그 행을 펼치는 형태**로 옮긴다. 시트 공급사의 검증 결과 상세와 같은 자리·같은 모양이어야
「연동 방식만 다른 같은 절차」라는 게 화면으로도 읽힌다.
