# 디자인 요청서 — 장기렌터카 ERP 「상품 목록 + 상품 상세」

> 이 문서를 통째로 복사해서 디자인 도구(Claude/GPT/Gemini)에 넣으면 된다.
> 우리가 받고 싶은 건 **형태·색·치수 규격**이다. 기능·데이터 구조는 우리 것이 정본이다.

---

## 0. 한 줄 요청

**장기렌터카 ERP의 「상품 목록」과 「상품 상세」 두 화면을, 서로 다른 3안으로 만들어 주세요.**
한 안 = HTML 한 장(두 화면을 위아래로 담으면 됨). 아래 「데이터」에 있는 값만 쓰고 **없는 항목은 지어내지 마세요.**
빈 값이 어떻게 보일지가 이 요청의 절반입니다.

---

## 1. 쓰는 사람과 상황

- **영업사원**이 하루에 수백 대를 훑는다. 손님 앞에서 화면을 돌려 보여 준다.
- 화면은 두 축으로 갈린다.
  - **손님이 보는 것** — 차·요금·보험·계약조건
  - **영업자만 보는 것** — 심사·불가조건·분납·카드결제·위약금·승계. 손님 화면에선 그 블록이 **통째로 없다**(숨기는 게 아니라 존재하지 않는다).
- B2C 쇼핑몰이 아니라 **업무 도구**다. 한 화면에 많이 담기고 빨리 훑히는 게 예쁜 것보다 중요하다.
- 웹과 모바일을 같은 규격으로 쓴다. 모바일에서 글자를 키우지 않는다.

---

## 2. 화면 A — 상품 목록

### 뼈대

```
[상단바 56px]  검색 · 필터칩 · 정렬 · [격자|표] 전환
──────────────────────────────────────────────
격자 뷰: 카드 3열(웹) / 1열(모바일)
표   뷰: 한 줄 = 한 대
──────────────────────────────────────────────
[하단바 56px — 브라우저 바닥에 딱 붙음]
```

### 카드 한 장에 들어가는 것

| 자리 | 내용 |
|---|---|
| 사진 | 가로:세로 = 2:1 |
| 사진 위 | **CORE 뱃지 3개** — 차량상태 · 상품유형 · 심사기준 |
| 제목 | 차명 (제조사 + 모델 + 세부모델/트림) |
| 옵션 | 칩 나열 (넘치면 잘림) |
| 스펙 | 연식 · 주행 · 연료 · 색상 |
| 혜택 | **혜택 뱃지 0~5개** — 분납 · 무보증 · 만21세 · 경력무관 · 무사고 |
| 금액 | 기간별 대여료 (앵커는 **하나만** 크게) |

**뱃지 종류 (실제 값)**

- 차량상태: `즉시출고` `출고가능` `상품화중` `출고협의` `계약중` `출고불가`
- 상품유형: `신차렌트` `신차구독` `중고렌트` `중고구독`
- 심사기준: `무심사` `소득확인`
- 혜택: `분납` `무보증` `만21세` `경력무관` `무사고`

→ 성격이 다른 뱃지가 **한 카드에 최대 8개**까지 붙는다. 시끄러워지지 않게 하는 규격이 필요하다.
→ **공급사 이름은 목록에 못 쓴다** (관리자만 보는 정보다).

## 3. 화면 B — 상품 상세

### 뼈대

```
[상단바 56px 고정]
┌──────────────────────────────┬──────────────────┐
│ 좌: 손님 영역                  │ 우: 영업자 전용 패널  │
│  사진 (주사진 + 세로 썸네일 열,   │  상단바 밑부터 시작,  │
│        ∧∨ 한 칸 이동)          │  화면에 고정,        │
│  1 차량스펙                    │  안에서 스크롤       │
│  2 대여료조건 (표)              │   · 영업 정보        │
│  3 보험조건                    │   · 계약 조건        │
│  4 계약조건                    │   · [바닥 고정]      │
│  5 기타사항                    │     링크복사·텍스트복사 │
└──────────────────────────────┴──────────────────┘
[하단바 56px 고정]
```

- 좌:우 ≈ 8:4. 폭 1200px 미만이면 영업자 패널이 본문 아래로 내려간다.
- 손님 화면(`/q`)은 **좌측만** 그대로 쓴다. 우측 패널이 없는 상태가 손님이 보는 화면이다.

### 데이터에 대해 알아야 할 것

- **빈 값은 일부러 뒀다.** 목록에는 사진 없는 차·요금 없는 차·옵션 없는 차·혜택 뱃지 0개인 차가 섞여 있다. 상세에는 5칸이 비어 있다. **실제로 이렇다.**
- **없는 것 — 만들어 넣지 말 것**: 영업자 수당·마진 금액, 출력(마력), 연비, 승차인원, 잔존가치, 선납금, 재고 수량, 출고 소요일, 사은품, 절세 안내, 타사 비교, 캐피탈 지정.
- **공급사 이름·차고지는 관리자만** 본다. 목록·손님 화면에 못 쓴다.

## 5. 디자인 제약 — 우리 토큰. 이 값을 그대로 쓸 것

**색**

| 용도 | 값 |
|---|---|
| 페이지 바탕 / 카드 / 표 머리 / 줄무늬 | `#f6f7f9` / `#ffffff` / `#f7f8fa` / `#fafbfc` |
| 선택된 행 | `#e8f0ff` |
| 글자 — 주 / 보조 / 흐림 / 반전 | `#18181b` / `#52525b` / `#a1a1aa` / `#ffffff` |
| 테두리 — 기본 / 연함 / 진함 | `#e2e5ea` / `#edf0f3` / `#cbd1d9` |
| 브랜드 — 네이비 / 진한 네이비 | `#1B2A4A` / `#0F1B35` |
| 상태 틴트 (바탕/글자/포인트) | 초록 `#f0fdf4`·`#166534`·`#16a34a` · 빨강 `#fef2f2`·`#b91c1c`·`#dc2626` · 주황 `#fff7ed`·`#c2410c`·`#ea580c` · 노랑 `#fefce8`·`#a16207`·`#ca8a04` · 회색 `#f4f4f5`·`#52525b`·`#a1a1aa` |

**브랜드색은 네이비 하나다.** 인디고·에메랄드를 새로 들이지 말 것.

**글자**

- 크기는 **이 6단만**: 18(대제목) / 14.5(패널·행 제목) / 13(본문) / 12(보조) / 11(캡션) / 10(뱃지 안)
- 굵기 **최대 700**. 800·900 금지. 위계는 크기와 색 대비로 낸다.
- 서체 Pretendard.

**치수**

- 컨트롤 높이 32(웹) / 36(모바일). 상단·하단바 56.
- 아이콘 14 / 16 / 18 / 20 중에서만.
- 라벨-값 2열의 라벨 폭 116px 고정 (카드끼리 값 시작선이 맞아야 함).
- 카드 썸네일 2:1.

**모서리 — 이번 요청의 논점**

지금 우리는 **전부 4px 한 단계**라 화면이 평평하다. 3안에서 각각 다르게 제안해 볼 것.

## 6. 하지 말 것

- 900 굵기, 24px 이상 제목, 그라디언트(배경·로고·뱃지), backdrop-blur
- hover 시 카드가 뜨거나 사진이 확대되는 효과, 펄스·핑 애니메이션
- 이모지, 장식용 아이콘 남발 (섹션 머리에 1개까지 허용)
- 다크모드
- **데이터에 없는 항목을 지어내는 것** — 제일 중요하다

## 7. 풀어 줬으면 하는 문제 — 3안이 여기서 갈리면 좋겠다

**공통**

1. **평평함** — 모서리·면·테두리·그림자 중 무엇으로 층을 만들 것인가. 그림자는 최소로 하고 싶다.
2. **뱃지 규격** — 성격이 다른 뱃지가 한 카드에 최대 8개 붙는다(상태1+유형1+심사1+혜택5). 시끄럽지 않게 하는 규격은? 모양(알약 vs 사각)으로 종류를 가를 것인가, 색으로만 가를 것인가, 자리로 가를 것인가. **높이·좌우 여백·모서리·글자 크기를 숫자로 제안할 것.**
3. **빈 값** — 사진 없는 차, 요금 없는 차, 혜택 뱃지 0개인 차, 상세의 빈 5칸. 「-」로 두나 / 행을 없애나 / 흐린 「미입력」이라 쓰나. 표가 숭숭 뚫려 보이지 않게.

**목록**

4. **격자와 표, 두 뷰의 규격을 어떻게 맞추나** — 같은 카드가 한 줄이 될 때 무엇을 버리고 무엇을 남기나.
5. **금액 앵커** — 기간이 1~4개로 들쭉날쭉하다. 큰 글씨는 하나만 세우고 싶은데, 무엇을 세우고 나머지는 어떻게 보이나.

**상세**

6. **영업자 것 표시** — 면 전체 반전 / 좌측 4px 색 바 / 연한 틴트 중 무엇인가. 손님 화면에선 그 블록이 통째로 빠진다는 점을 감안할 것.
7. **대여료 표에서 「이 조건이 최저가」 표시** — 행 배경 / 좌측 바 / 우측 체크 / 머리 칩. 반납형·인수형 **두 덩어리가 한 표 안에** 있다는 게 어려운 점이다. (표 대신 「선택 카드 목록」으로 푸는 안도 환영)
8. **섹션 5개를 같은 규격으로 두되 성격은 구분** — 아이콘 / 색점 / 머리띠 색 중 무엇인가.
