1. 무엇을 만드나

「상품 목록」과 「상품 상세」 두 화면을, 서로 다른 3안으로. 한 안 = HTML 한 장(두 화면을 위아래로 담으면 됩니다). 동작은 필요 없습니다.

가장 중요한 규칙 — 아래 「데이터」에 있는 값만 씁니다. 없는 항목을 지어내면 그 안은 못 씁니다. 우리 화면에 옮길 수 없기 때문입니다.

2. 쓰는 사람과 상황

  • 영업사원이 하루에 수백 대를 훑습니다. 손님 앞에서 화면을 돌려 보여 줍니다.
  • B2C 쇼핑몰이 아니라 업무 도구입니다. 한 화면에 많이 담기고 빨리 훑히는 게 예쁜 것보다 중요합니다.
  • 웹과 모바일이 같은 규격입니다. 모바일에서 글자를 키우지 않습니다.

8. 풀어 줬으면 하는 문제

  1. 평평함 — 모서리 · 면 · 테두리 · 그림자 중 무엇으로 층을 만드나. 그림자는 최소로 하고 싶습니다.
  2. 뱃지 8개 — 한 카드에 상태1 + 유형1 + 심사1 + 혜택5가 붙습니다. 시끄럽지 않게 하는 규격은? 모양(알약 vs 사각)으로 가르나, 색으로만 가르나, 자리로 가르나. 높이 · 좌우 여백 · 모서리 · 글자 크기를 숫자로 제안해 주세요.
  3. 빈 값 — 사진 없는 차, 요금 없는 차, 혜택 0개인 차, 상세의 빈 5칸. 「-」로 두나 / 행을 없애나 / 흐린 「미입력」이라 쓰나. 카드 높이가 들쭉날쭉해지지 않게.
  4. 격자 ↔ 표 — 같은 카드가 한 줄이 될 때 무엇을 버리고 무엇을 남기나. 같은 값은 두 뷰에서 같은 모양이어야 합니다.
  5. 금액 앵커 — 기간이 0~4개로 들쭉날쭉합니다. 큰 글씨는 하나만 세우고 싶은데, 무엇을 세우고 나머지는 어떻게 보이나.
  6. 영업자 것 표시 — 면 전체 반전 / 좌측 4px 색 바 / 연한 틴트 중 무엇인가. 손님 화면에선 그 블록이 통째로 빠진다는 점을 감안할 것.
  7. 대여료 표의 최저가 표시 — 행 배경 / 좌측 바 / 우측 체크 / 머리 칩. 반납형·인수형 두 덩어리가 한 표 안에 있다는 게 어려운 점입니다. 표 대신 「선택 카드 목록」으로 푸는 안도 환영합니다.
  8. 섹션 5개 — 같은 규격으로 두되 성격은 구분하고 싶습니다. 아이콘 / 색점 / 머리띠 색 / 세로 바 중 무엇인가.

9. 시험대 — 3안 모두 이 두 카드를 넣어 주세요

시험 ① 뱃지가 8개인 카드

제네시스 G80 2.5T AWD

계약중중고구독무심사 분납무보증만21세 경력무관무사고

옵션도 5개(나파가죽·렉시콘·HUD·마사지시트·후륜조향)입니다. 이 카드가 시끄럽지 않은지가 첫 번째 시험대입니다.

시험 ② 거의 빈 카드

테슬라 모델Y 롱레인지

사진 있음 · 주행 · 색상 · 옵션 · 혜택 · 요금이 전부 없음

뱃지는 상태 · 유형 · 심사 3개뿐입니다. 이 카드가 망가져 보이지 않는지가 두 번째 시험대입니다.

10. 내놓을 것

  1. HTML 한 장 × 3안. 한 장 안에 목록 · 상세 두 화면을 위아래로. Tailwind CDN 가능, 동작 불필요.
  2. 각 안 맨 위에 한 줄 설명 — 무엇이 다른지. (예: 「A안 — 모서리 2px, 층은 테두리 굵기로만」)
  3. 치수 표를 3안 각각에 대해 채울 것. 우리가 코드 토큰으로 옮겨야 하므로 이게 없으면 못 씁니다.

이 기획서로 이미 한 벌을 받아 봤습니다. 잘 푼 것과 틀린 것을 그대로 옮깁니다.

잘 푼 것 — 이 수준이면 됩니다
  • 빈 값을 네 갈래로 나눠 처리: 값 없음 - / 사진 없음 「사진 준비중」 / 혜택 0개 「혜택 없음」 + 줄 높이 고정 / 요금 없음 「요금 산출 대기중」
  • 금액 앵커 하나 — 18px 하나 + 나머지는 우측 12px 흐리게. 「원」을 13px normal로 낮춰 숫자만 세움
  • 반납형·인수형을 rowspan으로 묶고 인수형 시작에 2px 굵은 선
  • 섹션 머리를 아이콘도 색점도 아닌 3~4px 세로 바로
  • 영업자 패널을 면 전체 반전 대신 좌측 4px 네이비 바 + 상단 머리띠로
틀린 것 — 같은 실수를 하지 마세요
  1. 혜택 뱃지를 투명 배경 + 회색 테두리로 죽여 버렸습니다. 8개 문제를 「약하게」로 풀면 안 됩니다.
  2. 뱃지 3개를 사진 좌상단에 몰았습니다. 차 정면을 가리고, 셋 다 같은 사각+틴트라 색만 다를 뿐 한 덩어리로 읽힙니다.
  3. 라벨폭 116px을 목록 카드에 썼습니다. 값이 잘립니다.
  4. 세로 썸네일을 가로 스크롤로 그렸습니다.
  5. 영업자 패널 바닥 버튼을 position:absolute로 둬서 스크롤하면 같이 밀립니다.
  6. 영업자 패널에 「고객 노출 주의」 빨강 뱃지를 달았습니다. 그 블록은 손님 화면에 아예 없으므로 경고가 불필요합니다.
  7. 상세 제목에 20px을 썼습니다. 6단에 없는 크기입니다.
  8. 격자는 상태를 뱃지로, 표는 글자로 표시해 두 뷰의 규격이 어긋났습니다.
  9. 치수 표를 내지 않았습니다. 이게 없으면 코드로 옮길 수 없습니다.
