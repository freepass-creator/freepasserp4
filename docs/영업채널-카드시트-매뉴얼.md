## 1. 절대 금지

- **채널 문서를 손으로 고치지 마라.** 발행기가 탭을 통째로 지우고 다시 찍는다 — 사람이 적은 것은 남지 않는다.
  고칠 값은 언제나 **공급사 제공시트**에서 고친다.
- **카드에 우리가 모르는 문구를 넣지 마라.** 견본 카드에 있던 「#전면썬팅 #측.후면 썬팅 #블랙박스」 줄은
  우리 데이터·정책 어디에도 근거가 없어 뺐다. 실제로 해 주는 게 확인되면 그때 정책 탭에 넣고 코드가 읽게 한다.
- **판매시트 서식을 씌우지 마라.** `lib/domain/sales-sheet-format.ts`(현재 61열 표, Roboto 9pt)는 다른 물건이다.
  이 카드의 격자·색·글자 크기는 손오공이 실제로 뿌리던 카드 이미지를 픽셀로 잰 값이다.
- **상태 필터를 좁히지 마라.** 출고불가만 뺀다 — 판매시트와 같은 기준.
  (2026-08-21 「출고가능만」으로 좁혔다가 손오공 구독이 43 → 20대로 줄었다. 사장님 지적으로 되돌림.)
- **글꼴·글자 크기를 바꾸지 마라.** 크기는 Malgun Gothic 폭으로 역산한 값이라, 폰트를 바꾸면 칸이 넘친다.

## 3. 카드 한 장의 구조 (7행 × 13열)

### 상품시트와 천이시트는 같은 셀을 쓰지 않는다

두 출력은 같은 공급사 재고를 보지만 **출력 규격이 완전히 다르다.** 셀 주소나 행 전체를 서로 복사하지 않는다.

| 구분 | 공급사 파일 「상품시트」 | 천이컴퍼니 카드시트 |
|---|---|---|
| 한 대의 크기 | 1행 | 7행 × 13열 |
| 차량번호 | 머리글이 `차량번호`인 열 | 카드 첫 행의 C:D 병합 셀(상태가 있으면 다음 줄에 함께 표시) |
| 차명 | `모델`·`세부모델`·`세부트림` 등 각 열 | 카드 둘째 행 C:D = 세부모델, 여섯째 행 C:D = 세부트림 |
| 색상·주행거리 | 머리글 이름으로 각각 한 열 | 카드 첫 행 F = 색상, H = 주행거리 |
| 옵션 | `옵션` 열 | 카드 셋째~여섯째 행 F:H 병합 셀 |
| 대여료·보증금 | 공급사 기간별 칸을 모두 한 행에 보존 | 카드 첫 행 J:L = 최저가 한 벌(보증금·기간·월대여료)만 표시 |
| 정책 | 옵션 뒤 정책 열들 | 왼쪽 조건 칸과 위쪽 머리띠 문구로 변환 |
| 생성 규칙 | 판매시트에서 공급사별 행을 그대로 복사 | 공급사 재고·운영정책을 `buildCard()`로 카드 변환 |

따라서 검수도 두 갈래로 나눈다. 공급사 「상품시트」는 판매시트와 **행 전체 값**을 비교하고,
천이시트는 공급사 재고에서 만든 **카드 표시값 14개와 차량 대수**를 비교한다.
읽기 전용 교차검사는 `scripts/audit-pipeline-destinations.mts`가 담당한다.

## 4. 조건 칸은 어디서 오나

카드 왼쪽 다섯 칸과 머리띠 문구는 그 공급사 시트 **「운영정책」 탭**에서 뽑는다. 정책이 바뀌면 다음 발행에 저절로 따라간다.

| 카드 칸 | 정책 열 | 규칙 |
|---|---|---|
| 소득 증빙 | 심사조건 | 「무심사」면 X, 아니면 O |
| 만 21세 가능 | 연령인하 | 「만 21세까지」면 O, 「불가」면 X |
| 면허 1년 미만 | 면허기간 | 「1년 이상」이면 X(1년 미만은 안 된다) |
| 카드 결제 | 결제방식 | 「카드」가 들어 있으면 O — CMS 자동이체면 X. 보증금 카드결제와 다른 칸이다 |
| 보증금 협의 | 보증금분납 | 「불가·없음」이 아니면 O |
| 머리띠 왼쪽 | 보험료 · 정비 | 「보험료 별도」면 앞에 붙는다 |
| 머리띠 오른쪽 | 보증금분납 | 「보증금 분납 <값>」 |
| 기본 : 연 N만km | 기본주행 | 연 20,000km → 「기본 : 연 2만km」 |
| 만기 문구 | — | 렌트 「종료 한달전 인수가 확인」 / 구독 반납형 「만기 반납 · 보증금 N일내 반환」(보증금 반환기한) |

**코드에 박아 두는 것은 `CHANNELS[].tabs[].blocks[].override` 뿐이다.** 지금 박혀 있는 것:

- 손오공 장기렌트 머리띠 「연1회 [ 엔진오일 ] 서비스」 — 견본 카드에 있던 문구. 정책 탭 「정비: 협의」로는 안 나온다.
- 손오공 분납문구 「보증금 분납 2~3회」 — 사장님 2026-08-21 「손오공 보증금 2~3회로 해줘」.

## 5. 돌리는 법

```bash
# 일일 반영에 붙어 있다 — 상품리스트를 찍으면 이어서 찍힌다
npx tsx scripts/run-daily.mts --apply

# 이 문서만 다시 찍기
npx tsx scripts/publish-channel-cards.mts --apply
npx tsx scripts/publish-channel-cards.mts                       # 미리보기(아무것도 안 바뀐다)
npx tsx scripts/publish-channel-cards.mts --channel=천이컴퍼니 --apply
npx tsx scripts/publish-channel-cards.mts --apply --keep-no-price   # 대여료 없는 차까지
```

발행기는 매번 이렇게 한다 — 탭 통째 갈아 끼우기 → 카드 찍기 → 숨김 탭 「이 시트는」·「AI 운영 매뉴얼」 다시 찍기
→ 문서 이름을 「MMDD <채널> 상품카드 [영업채널] [연동중]」으로 맞추기 → teamjpk.com 도메인 편집 권한 확인.

## 6. 끝나고 확인

- 화면에 찍힌 블록별 대수가 공급사 시트 재고 수 − 출고불가와 맞나.
- `npx tsx scripts/audit-pipeline-destinations.mts`에서 공급사 상품시트와 천이컴퍼니가 모두 `일치`인가.
- 「⚠ 대여료가 한 칸도 없어 뺀 차」가 나오면 그 차번을 공급사에 알려 요금을 채운다.
- 「⚠ 재고 줄에 다른 정책코드가 섞여 있다」가 나오면 `CHANNELS` 의 `정책코드`를 다시 본다.

## 7. 멈출 때

- 어느 블록이 **0대**로 나오면 발행하지 말고 공급사 시트를 먼저 본다(탭 이름이 바뀌었을 수 있다).
- 조건 칸이 전부 `-` 로 나오면 「운영정책」 탭의 그 정책코드 줄이 비었다는 뜻이다 — 채우고 다시 돌린다.

## 8. 채널을 새로 늘리려면

`lib/domain/channel-card-sheet.ts` 의 `CHANNELS` 에 한 덩어리를 더한다. 새 구글 문서를 만들고 그 id 를 `문서` 에 적는다.
탭마다 `sheetId`(숫자)는 문서 안에서 겹치지 않게 준다(지금 100·200 · 숨김 탭은 900·901 예약).
