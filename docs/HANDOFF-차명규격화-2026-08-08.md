## 무엇을 하려는 것인가

공급사는 엑셀에 편한 대로 적는다. 그건 바꿀 수 없다.
**받는 쪽이 그 한 칸을 원자로 갈라서 차종마스터로 다시 세운다.**

```
「22년식 카니발 2.2 프레스티지」
   ↓ unpack   문장 → 원자 (연식 2022 · 2200cc · 디젤 · 트림 프레스티지)
   ↓ snap     차종마스터로 세대 확정 (카니발 KA4)
   ↓ compose  고를 수 있는 것만 적기
「카니발 KA4 디젤 2.2 9인승 프레스티지」
```

차명 = **세부모델 + 파워트레인(연료·배기량 · 고를 수 있으면 인승·구동) + 세부트림.**

무엇을 적을지는 **차종마스터가 정한다.** 코드에 모델 이름이 없다 —
`variants[].drivetrain` · `variants[].seat` 의 선택지가 둘 이상이면 적고, 아니면 안 적는다.
승용에 인승을 안 적는 이유도 「5인승이라서」가 아니라 «고를 게 없어서»다.
선택지가 있는데 안 적혀 왔으면 기본값(구동 2WD · 인승 첫 선택지)으로 넣는다.

조립은 `lib/domain/vehicle-defaults.ts` 의 `composeVehicleName` 하나만 쓴다.
스크립트마다 따로 이으면 같은 차가 곳곳에서 다르게 보인다.

## 손대면 안 되는 것

- **공급사 시트에 쓰지 않는다.** 대상 시트 ID 가 파트너 `sheet_url` 과 같으면 중단한다
  (`scripts/migrate-supplier-sheet.mts`). 오플·이안카·아이카는 그들이 만드는 시트다.
- **표(Table) 순서.** 표 해제 → 값·서식 → 표 생성 → 필터 → 정렬.
  먼저 필터를 걸면 `overlapping filter` 로 변환이 거부되고, 표가 있으면 개별 데이터확인이
  `typed columns` 로 막힌다. 표에서는 숫자서식이 무시되므로 금액·주행은 «값에» 쉼표를 넣는다.
- `database.rules.json` 의 동결 금액필드 완화는 **미커밋**이다. 정산·계약서·손님 서명 금액을
  건드리므로 따로 판단해야 한다.
