# ERP4 MAIN · Surface Use Lock

최종: 2026-09-21  
상태: **CURRENT / 운영 사용면 잠금**

## 원칙

이 문서의 "사용"은 **freepasserp.com ERP4 MAIN에서 현재 사용자에게 노출·사용하는 제품면**이라는 뜻이다.
저장소에 코드가 남아 있다는 이유만으로 ERP닷컴 메인 기능으로 취급하지 않는다.

## ACTIVE_MAIN — 현재 ERP닷컴에서 쓰는 정본

| 경로/면 | 상태 | 역할 |
|---|---|---|
| `/` | ACTIVE | 운영 진입점. 주소는 유지하고 `/shop` 상품면을 보여준다 |
| `/shop` | ACTIVE | 상품 찾기·검색·필터·정렬·목록 |
| `/q/[code]` | ACTIVE | 상품 상세 확인 |
| 화이트라벨 `sitePath` / 연결 도메인 | ACTIVE | 같은 상품면을 채널 브랜드로 제공 |

ERP4 MAIN의 사용자 흐름은 **찾기 → 비교 → 상세 확인**으로 잠근다.

## ACTIVE_SUPPORT — 메인 구조를 바꾸지 않는 보조면

- 상품 공유/채널 링크 호환 경로
- 약관·개인정보 등 법적/보조 문서가 실제 링크에서 호출되는 경우
- 공개 상품 API 및 이미지/상태 조회 API

보조면은 ACTIVE_MAIN의 IA에 새 메뉴·대시보드·업무기능을 추가할 근거가 아니다.

## NOT_MAIN — ERP닷컴 메인에서는 안 쓰는 것

아래는 저장소에 존재할 수 있지만 **ERP4 MAIN 제품면이 아니다**.

- `/login`, 회원/세션/인증 UI
- `/finder` 및 과거 ERP4 업무 화면
- `/inventory`, `/members`, `/settings`, `/audit`, `/dev`, `/diag`
- `/settlement/**` 정산 업무
- `/erp5/**` 내부 데이터/운영 화면
- `/estimate/**` 별도 견적기
- `/esign/**`, `/sign/**` 전자계약 서브시스템
- 기타 내부 운영·개발·진단 페이지

이 경로들은 **삭제 대상으로 자동 판정하지 않는다.**
다만 ERP닷컴 메인 헤더·푸터·검색·목록·상세에서 진입점을 만들지 않는다. 대표 도메인에서 직접 열린 은퇴 업무 URL은 공개 상품 홈으로 정리한다.

## LEGACY / COMPAT

- 과거에 외부로 나간 링크가 있을 수 있는 경로는 즉시 삭제하지 않는다.
- 호환 경로는 새 기능 개발 대상이 아니다.
- 신규 기능은 ACTIVE_MAIN에만 추가한다.
- 레거시를 다시 메인 IA로 올리려면 사용자 명시 승인 + 정본 문서 변경 + 잠금 검사 변경이 모두 필요하다.

## 현재 UI 잠금 — 2026-09-21

- 상단바: 웹 **56px** / 모바일 **48px**
- 상단바 아래 구분선: **없음**
- 상단 제목: 웹/모바일 **18px**
- 표준 배너: 아주 옅은 쿨블루 면
- 배너 제목: **신용점수 관계 없이 누구나 가능합니다**
- 배너 본문: **고객 조건에 맞는 차량을 검색하고, 대여료·보증금·이용조건을 비교해 상담에 활용하세요.**
- 오늘 하루 안 보기: **아주 연한 문구 + X**, 별도 체크박스/버튼 면 없음
- 목록 대여료: **67만원 / 67.5만원** 형태
- 카드 우대조건(무심사·분납가능·무보증 등): 카드 바닥으로 밀지 않고 **가격 줄 바로 아래 4px**에 붙여 표시
- 상세·계약·정산 금액: 실제 원 단위 유지
