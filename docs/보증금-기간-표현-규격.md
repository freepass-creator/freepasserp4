# 보증금 · 기간 표현 규격

> 정본: **구글 판매시트의 보증 원자 → ERP 가격행(term) → 화이트라벨 화면**을 한 규칙으로 묶는다.
> 이 문서는 일반 렌트의 `단기보증/장기보증`과 구독 예외의 표시·서식·검사 기준이다.

## 1. 일반 렌트 보증금 SSOT

일반 상품의 보증금 원자는 둘뿐이다.

| 원자 | 관할 기간 | 화면에서의 이름 |
|---|---|---|
| `단기보증` | **24개월 미만** — 현재 표준 1·6·12개월, 비표준 18개월도 같은 스코프 | `보증금` |
| `장기보증` | **24개월 이상** — 현재 표준 24·36·48·60개월 | `보증금` |

- 시트의 보증 열은 **자기 가격 블록을 관할**한다. ERP 저장 시 각 `price[term].deposit`에 해당 보증 원자를 복제한다.
- 화이트라벨은 `단기보증`·`장기보증`이라는 내부 열 이름을 고객에게 노출하지 않는다. 고객은 선택한 기간의 **`보증금`**만 본다.
- 기간·월대여료·보증금 필터는 **반드시 같은 `price[term]` 행에서 동시에 성립**해야 한다. 서로 다른 기간의 조건을 섞어서 한 차량을 통과시키면 안 된다.
- 기간을 하나 이상 선택했다면 카드·정렬도 그 선택 기간 안의 가격행을 기준으로 한다. 기간을 선택하지 않은 경우에만 전체 기간 중 대표가격(최저 월대여료)을 쓴다.
- 보증금 공란은 **알 수 없음**이다. `0원`으로 바꾸지 않는다.
- `무보증`, `보증금없음`, `0`, `0원`처럼 공급사가 0원을 명시한 경우에만 `deposit=0`이다.
- 금액이 아니라 규칙으로 운영되는 공급사는 등록된 공급사 보증 정책만 계산한다. 모르는 문장을 숫자로 추정하지 않는다.
- 레거시 원천에 보증 열이 하나뿐인 경우에만 기존 파서의 단일-보증 예외를 유지한다. F01 표준 판매시트는 반드시 단기/장기 두 원자를 보존한다.

## 2. 구독 예외

일반 렌트의 단기/장기 규칙을 아래 상품에 억지로 적용하지 않는다.

| 갈래 | 보증 원자 |
|---|---|
| 오토플러스 구독 | `보증금` + 공급사 보증정책 |
| 손오공 구독 | `보증금 반납형` / `보증금 인수형` |
| 픽업 구독 | `반납형보증금` / `인수형보증금` |

ERP5 어댑터는 일반 렌트의 `shortDeposit/longDeposit`과 구독의 `depositPolicy`를 분리해서 보존한다.

## 3. 화이트라벨 표현

### 3-1. 목록 카드

- 줄 순서: **기간 · 월 대여료 · 보증금**.
- 월 대여료: `SHOP.fs.price`, `C.ink`, `FW.head`.
- 기간/보증금: `SHOP.fs.sub`.
- 보증금 금액: `C.mute`, 보통 굵기.
- 명시적 0원: **`보증금 없음`**, `C.ok`, 700.
- 카드의 보증금은 `manShort` — **만원 단위 정수, 내림**. 예: 1,785,000원 → `보증금 178만원`.
- 규칙 문장만 있는 경우 계산 가능한 규칙이면 선택 기간의 실제 금액으로 보여 주고, 계산 불가 규칙이면 원문을 보존한다.
- 금액은 잘라 말줄임하지 않는다. 규칙 문장만 별도 줄로 자연스럽게 줄바꿈한다.
- 같은 카드에서 `보증금 없음`과 `무보증` 혜택을 중복 표기하지 않는다.

### 3-2. 상세

- 선택 기간별 가격행을 그대로 보여 준다.
- 보증금은 **원 단위 정확값**(`wonKo`)을 쓴다.
- 단기/장기라는 내부 필드명보다 기간과 보증금의 관계가 먼저 보이게 한다.
- 공란을 `없음`으로 표시하지 않는다. 데이터 미확정 상태는 판매조건으로 단정하지 않는다.

### 3-3. 필터 · 정렬

- 필터 순서: `계약기간 → 월 대여료 → 보증금`.
- 보증금 밴드: 없음 / 100만 이하 / 100~200만 / 200~300만 / 300만 이상.
- **동일 가격행 원칙**: 예를 들어 12개월을 고른 상태에서 36개월 보증금이 조건에 맞는다는 이유로 차량이 통과하면 오류다.
- 선택 기간이 있으면 `월 대여료순`·`보증금 낮은순`도 그 기간의 값으로 정렬한다.
- 여러 기간을 OR로 선택한 경우에는 선택된 가격행 중 현재 필터를 모두 만족하는 행을 후보로 삼는다.

## 4. Google 판매시트 표현

### 4-1. 일반 상품 열 구조

```
… | 차종구분 | 단기보증 | 1개월 | 6개월 | 12개월 | 장기보증 | 24개월 | 36개월 | 48개월 | 60개월 | …
```

- 단기 블록과 장기 블록 사이의 경계는 **보증 열 자체**가 만든다.
- F86처럼 24~60개월 장기 상품만 투영하는 시트는 `장기보증`만 노출해도 된다. 단기 가격을 노출하기 시작하는 순간 `단기보증` 블록도 같이 추가해야 한다.

### 4-2. 판매시트 서식 SSOT

정본은 `lib/domain/sales-sheet-format.ts`.

- 글꼴: **Roboto 9pt**, italic 없음.
- 행 높이: `rowPx(9)=22px`.
- 셀 좌우 padding: **5px**.
- 첫 행 고정, 헤더 **bold**, 가운데 정렬.
- 금액(대여료·보증금·차량가격): **우측 정렬 + bold + 검정 글자**.
- 일반 텍스트는 검정. 링크만 링크색을 사용한다.
- wrap: `CLIP`.
- 열 너비: 본문 **90 percentile** 기준 자동산정, 최소 62px / 일반 최대 300px / 긴 자유텍스트 최대 240px.
- 기간 블록은 글자색이 아니라 **배경색**으로 구분한다.

단기 블록:
- `단기보증 #EAF7F8`
- `1개월 #DCF0F2`
- `6개월 #CDE9EC`
- `12개월 #BFE2E6`

장기 블록:
- `장기보증 #EDF0FE`
- `24개월 #DFE5FD`
- `36개월 #D1DAFC`
- `48개월 #C3CFFB`
- `60개월 #B5C4FA`

구독 반납형은 파랑 계열, 인수형은 보라 계열을 사용한다.

## 5. 2026-09-19 운영 실측에서 확인한 드리프트

### F01 상품리스트

- 열 구조와 단기/장기 배경 블록은 현재 정본과 일치한다.
- 실제 글꼴은 Roboto 9pt, 금액은 우측정렬+bold다.
- 과거 인수인계 문서의 `Roboto 10pt`, `보증금은 굵히지 않는다` 문구는 현재 코드와 충돌하므로 폐기한다.

### F86 전용 상품시트

현재 장기 데이터 자체는 맞지만 표현이 별도 체계다.

- Malgun Gothic 9pt
- italic
- 본문 금액 가운데 정렬
- 파란 글자
- 갈색/적갈색 헤더 배경

이 형식은 판매시트 SSOT와 불일치한다. **F86도 장기 블록을 F01과 같은 정본 서식으로 투영**해야 한다. 단, F86이 장기(24~60개월)만 제공하는 동안에는 `단기보증`을 억지로 추가하지 않는다.

## 6. 자동 검사 기준

다음은 회귀검사 대상이다.

1. 일반 렌트: `<24개월 → 단기보증`, `>=24개월 → 장기보증`.
2. 화이트라벨: 기간·대여료·보증금이 동일 가격행에서 필터되는지.
3. 선택 기간과 카드 표시 가격/보증금이 같은지.
4. 선택 기간과 월대여료/보증금 정렬 기준이 같은지.
5. F01: 글꼴·크기·italic·정렬·bold·배경색·행높이·padding.
6. F86: 장기 블록이 F01 정본 서식을 쓰는지.
7. 공란 보증금을 0원으로 추정하지 않는지.
8. 명시적 무보증만 0원으로 처리하는지.
