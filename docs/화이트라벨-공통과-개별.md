# 화이트라벨 — 무엇이 «공통»이고 무엇이 «채널마다»인가

> 사장님 2026-09-09 「**커스터마이징 하는 부분을 골라보자. 공통 영역과 커스터마이징 할 거.**
> 그중에 **필터는 되게 중요한 거 같음.** 빠른필터랑 세부필터 어떤 걸 넣을지 각자 다르게.
> **아직까지는 공통으로 갈 거긴 한데**」
> · 2026-09-09 「**화이트라벨 공통규격은 써 줘야 함. 여기서만 달리 하면 안 되고**」(#197)

## 0. 말부터 — «표준판»과 «맞춤판»

> 사장님 2026-09-09 「**화이트라벨 공통 표준 버전과 커스터마이징 버전.** 용어는 니가 알아서 하고」

| 말 | 뜻 |
|---|---|
| **표준판** | 표에 그 칸을 **안 적은** 상태. 화면이 집 기본을 그대로 쓴다 |
| **맞춤판** | 그 칸을 **적어서** 제 것을 쓰는 상태 |

★★**채널이 통째로 둘 중 하나가 아니다 — «칸마다» 갈린다.**
  이안카는 **여섯 칸이 맞춤판**이고(`domainReady`·`sitePath`·`logo`·`quick`·`providerCode`·`notice`)
  나머지는 전부 표준판이다. ⚠ 이 줄을 「빠른필터만」이라 적어 뒀다가 2026-09-10 코덱스 검토에서
  잡혔다 — **현황은 손으로 적지 말고 `npm run check:whitelabel` 이 찍는 것을 읽는다.**
  「이 채널은 맞춤판이다」라는 말은 뜻이 없다. 「이 채널은 **무엇이** 맞춤판이다」라고 말한다.

★**표준판이 기본값이다 — 적기 전까지 화면이 한 픽셀도 안 바뀐다.**
  그래서 채널을 새로 세울 때는 신원·얼굴·말만 적고 나머지는 비워 두면 된다.
  맞춤판은 «그 채널에 그럴 이유가 생겼을 때» 한 칸씩 켠다.

★지금 현황은 `npm run check:whitelabel` 이 표로 찍어 준다.

## 1. 가르는 선은 하나다

> 사장님 2026-09-09 「내가 **별도 규격**이라고 이야기하는 거 아니면 **일단 다 공통**으로
> 적용되어야 해. 화이트라벨은 **컬러만 빼고**」

★★**기본은 «공통»이다.** 맞춤판은 사장님이 「이건 채널마다 다르게」라고 «말한 것»만이다.
  ⚠ 2026-09-09 에 머리띠 오른쪽 「지금(날짜·시각·날씨)」을 `stampToday` 라는 «프리패스 전용»
    손잡이 뒤에 두었다가 걷었다 — 아무도 그러라고 한 적이 없는데 **내가 임의로 「이건 우리 것만」**
    을 만든 것이고, 그 순간 유니오토·하허호 머리띠에서는 그게 아예 안 떴다.
    **칸을 만드는 것 자체가 «갈라놓는» 일이다.** 만들기 전에 그러라고 하셨는지 본다.

```
채널이 바꿀 수 있는 것  =  표(lib/whitelabel.ts)에 «칸»이 있는 것뿐
칸이 없으면            =  공통. 화면 코드에 있고, 채널은 못 건드린다
```

**채널 하나를 위해 화면 코드를 고치는 순간 규격이 갈린다.** 그때부터는 채널이 늘 때마다
화면이 갈라지고, 한쪽을 고치면 다른 쪽에서 「또 원래대로」가 된다(CLAUDE.md 절대원칙 ①·③).
그래서 채널이 다르고 싶으면 **표에 칸을 만들고 그 칸을 읽는다.** 화면에 `if (key === …)` 를 넣지 않는다.

## 2. 채널이 정하는 것 — 표에 칸이 있다(= 맞춤판이 될 수 있는 칸)

| 묶음 | 칸 | 무엇 | 안 적으면 |
|---|---|---|---|
| **신원·주소** | `key` | 내부 이름 · 미리보기 꼬리표(`?wl=`) | (필수) |
| | `hosts` | 이 채널로 열리는 도메인 | 도메인으로는 안 열린다 |
| | `domainReady` | Vercel 에 실제로 붙었나 | 아직 안 붙음 |
| | `sitePath` | 도메인 전 임시 주소(`/haheoho`) | 없음 — **이미 나간 링크라 지우지 않는다** |
| | `providerCode` | 이 공급사 차만 싣기 | 우리 재고 전체 |
| **얼굴** | `name` | 손님에게 보이는 이름 · 탭 제목 | 노브랜드 |
| | `wordmark` | 간판 글자(짜임 `split`/`lockup`/`lockup-ko` · 두 색 `tone`) | 안 그린다 |
| | `logo` | 간판 그림(`mark` 심볼 / `lockup` 이름째 그림) | 글자만 |
| | `brandColor` | `.fp-wl` 토큰(링크·칩·포커스) | 집 기본색 |
| | `headline` | 라벨 없는 얼굴의 머리 글자 | 없음 |
| **얼굴의 «종류»** | `self` | 우리 것인가(푸터 문장이 갈린다) | 남의 채널 |
| | `plain` | 라벨을 «안 다는» 얼굴 | 라벨 단다 |
| **말** | `notice` | 검색창 위 안내 배너 | 안 띄운다 |
| | `tel` | 상담 번호(머리띠 오른쪽 · 폰 하단독) | 그 자리를 안 그린다 |
| | `homepage` | 머리띠 오른쪽 「회사 소개」 링크 | 없음 |
| | `bizLines` | 푸터 사업자 표기 | 안 그린다 |
| **고르는 길** | `quick` | **빠른필터** 칩 줄 | 집 기본 `DEFAULT_QUICK` |
| | `axes` | **세부필터** 축과 순서 | 집 기본 `SHOP_AXES` 전부 |

★**칸이 늘면 이 표에 한 줄 적는다** — `npm run check:whitelabel` 이 안 적힌 칸을 잡는다.

## 3. 필터 — 여기가 제일 중요하다

사장님이 콕 집으신 자리다. **둘 다 이미 채널이 정할 수 있게 배선돼 있다**(2026-09-09 실측).

### ㉠ 빠른필터 `quick` — 칩 줄

- 집 기본 `DEFAULT_QUICK`(`lib/shop/query.ts`) — **아홉**:
  `보증 없음 · 월 50만 이하 · 월 50~60만 · 월 60~70만 · SUV · 승합·카니발 · 승용 · 전기차 · 하이브리드`
- **적은 순서가 곧 화면 순서**다. 채널이 적으면 기본을 **통째로 대신한다**(섞이지 않는다).
- 구간 «이름»은 손으로 안 적는다 — `soloLabel(key)` 이 준다. 손으로 적으면 걸린 조건 칩과 두 말이 된다.
- ⚠ 재고에 **없는 값**을 적으면 그 칩은 눌러도 0건이다. 적기 전에 그 채널 재고를 센다.

### ㉡ 세부필터 `axes` — 왼쪽 조건 기둥 · 폰 조건 시트

- 집 기본 `SHOP_AXES` — **열둘**, 이 순서다(손님이 좁혀 가는 차례):
  `차종 · 상품구분 · 차급 · 제조사 · 계약기간 · 월 대여료 · 보증금 · 심사 · 연식 · 주행거리 · 연료 · 혜택`
- **웹 기둥과 폰 시트가 같은 목록을 본다** — 갈리면 웹에서 건 조건이 폰에서 안 보이는 «숨은 필터»가 된다.
- ⚠ **빼고 순서만 바꾼다 — 없는 축을 새로 만들 수는 없다.**
- ⚠ 값이 하나도 없는 축은 원래도 안 뜬다. 이 칸은 «값이 있어도 안 세우는» 칸이다.

### 지금 누가 다른가 (2026-09-09 실측 · 채널 여섯)

| 채널 | 빠른필터 | 세부필터 |
|---|---|---|
| freepass(노브랜드) · plain · uniplan · freepassmobility · haheoho | 표준판 | 표준판 |
| **eancar** | **맞춤판 여덟** — 기간이 맨 앞(월렌트 전문) | 표준판 |

⇒ **세부필터는 맞춤판이 하나도 없다. 그대로 둔다**(사장님 「아직까지는 공통으로 갈 거긴 한데」).

★**그래도 «된다»는 것은 확인했다** — 배선을 안 켜 보고 「됩니다」라고 적으면 그건 약속이 아니라 추측이다.
  2026-09-09 에 `plain` 에 `axes: ['term','rent','maker']` 를 **잠깐** 넣고 봤다:
  웹 기둥 = 계약기간 → 월 대여료 → 제조사 · 폰 시트 = 같은 셋 같은 순서. 확인하고 **되돌렸다.**

### 필터에서 «공통»으로 남는 것 — 채널이 못 건드린다

| | 어디 |
|---|---|
| 축이 **무엇으로 갈리나**(구간·값) | `RENT_BANDS` · `DEP_BANDS` · `MILE_BANDS` · `CREDITS` · `CATALOG_PERKS` |
| 구간 이름 | `soloLabel` |
| 정렬 목록 · 기본 인기순 | `SHOP_SORTS` — 인기순 · 낮은 대여료순 · 높은 대여료순 · 보증금 낮은순 · 연식 최신순 · 주행거리 짧은순 · 같은 차 많은순 |
| 검색이 무엇을 훑나 | `matchProductQuery` |
| 건수 세는 법 | `shopFacets` |

⇒ **「어떤 축을 보여줄까」는 채널 몫, 「그 축이 무엇으로 갈리나」는 집 몫이다.**
  구간을 채널마다 다르게 두면 같은 차가 채널마다 다른 칸에 들어가, 대수가 어디서 갈렸는지 화면이 말해주지 않는다.

## 5. 새 칸을 만들 때

1. **채널 «하나» 때문에 만들지 않는다.** 둘째 채널이 같은 것을 물으면 그때가 칸이다.
   하나짜리 예외는 칸이 아니라 그 채널의 사정이고, 칸으로 만들면 다음 사람이 규격으로 안다.
2. 만들면 **§2 표에 한 줄** 적는다.
3. **안 적으면 어떻게 되는지**를 반드시 적는다 — 그게 그 칸의 «공통값»이다.
4. `npm run check:whitelabel` — 표에 있는데 이 문서에 없는 칸을 잡는다.

## 6. 무엇이 쉽고 무엇이 어렵나 — 요청이 들어왔을 때

> 사장님 2026-09-09 「**모듈화로 해놓을 수 있는 것들이 있잖아. 큰 구조가 아니라면 니가 한번
> 고민해 봐 — 이런 건 쉽다 이런 건 어렵다.**」 · 「뭐 예를 들어서 **검색필터에 뭐 넣어달라**
> 이런 건 어렵지 않지. **순서 바꿔달라. 빠른필터에서 칩 빼달라 넣어달라.**」

렌트사가 물으면 **이 표를 보고 그 자리에서 답한다.**

### ㉠ 표 한 줄 — «몇 분» · 화면 코드를 안 건드린다

사장님이 예로 드신 것이 전부 여기다.

| 요청 | 고치는 곳 |
|---|---|
| 빠른필터 칩 **빼달라 · 넣어달라 · 순서 바꿔달라** | `quick` |
| 세부필터 **이 축은 빼달라 · 순서 바꿔달라** | `axes` |
| 배너 문구 바꿔달라 | `notice` |
| 우리 차만 보이게 해달라 | `providerCode` |
| 이름 · 색 · 전화 · 사업자 표기 · 회사 소개 링크 | `name`·`brandColor`·`tel`·`bizLines`·`homepage` |
| 주소 달라 · 도메인 붙여달라 | `sitePath`·`hosts`·`domainReady` |

★**정말로 한 줄이다.** 게이트도 그대로 통과하고, 다른 채널은 한 픽셀도 안 바뀐다.
⚠ 딱 하나만 미리 센다 — **그 채널 재고에 그 값이 «있나».** 없는 값을 세우면 눌러도 0건이다.

### ㉡ 그림 한 장 + 표 한 줄 — «반나절»

간판 로고를 받았을 때다. 그림은 붙이면 끝이 아니라 **재야 한다** —
잉크 가장자리·글자 밴드(`nameBand`)를 재고, 공유 카드(OG 1200×630)를 굽는다.
`npm run measure:brand` 로 재고 `npm run make:og` 로 굽고 `check:brand` 가 검사한다.

### ㉢ 새 «칸»을 만드는 일 — «하루 이틀»

표에 **아직 없는 것**을 채널마다 다르게 하고 싶을 때다(예: 정렬 기본값, 카드에 세울 뱃지 고르기).
칸 만들기 → 화면이 그 칸을 읽기 → §2 표에 한 줄 → 게이트. **화면에 `if (채널이름)` 을 넣지 않는다.**
⚠ **채널 «하나» 때문에는 안 만든다**(§5). 둘째가 같은 것을 물으면 그때가 칸이다.

### ㉣ 축을 «새로» 만드는 일 — «며칠» · 화면 일이 아니라 «데이터» 일

⚠⚠ **「검색필터에 뭐 넣어달라」가 늘 쉬운 건 아니다.** 갈림길은 하나다:

```
지금 있는 열두 축 중에서 «고르는» 것        → ㉠ 몇 분
지금 없는 것을 «축으로 세우는» 것            → ㉣ 며칠
```

예 — 「색상으로 찾게 해달라」 「무사고만 보게 해달라」 「옵션으로 걸러달라」.
이건 화면이 아니라 **재고 데이터**의 문제다. 그 값이 차 전부에 차 있어야 하고,
**빈칸이면 필터가 거짓말을 한다** — 「흰색 30대」라고 세워 놓고 실제로는 색을 적어 둔 차만 30대인 꼴이다.
⇒ 순서는 늘 같다: **원자를 먼저 채우고**(정제·마스터) → 축을 세운다.
  「일단 필터부터 만들고 데이터는 나중에」는 손님에게 틀린 숫자를 보여주는 길이다.

### ㉤ 안 하는 쪽 — «공통 한 벌»을 깨는 일

> 사장님 2026-09-08 「영업자 손님 렌트사 **다 동일한 내용** 보자… **어렵게 하지 말고**」

- 채널마다 **다른 카드 짜임 · 다른 상세 순서**
- 채널마다 **다른 대여료 규칙 · 다른 정책 표기**
- 채널마다 **다른 로그인 · 다른 계정**

기술이 어려워서가 아니라 **한 벌이 아니게 되기 때문**이다. 한 벌이 깨지면 채널이 늘 때마다
화면이 갈라지고, 한쪽을 고치면 다른 쪽에서 「또 원래대로」가 된다.
요청이 오면 **왜 그게 필요한지**를 묻는다 — 대개는 ㉠·㉢으로 풀린다.
