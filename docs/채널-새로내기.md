# 새 채널 내기 — 「말하면 바로」

> 사장님 2026-09-10 「이제 **여러 개를 좀 만들 거야.** 그러니까 그거를 딱 얘기하면
> **바로바로 만들 수 있게끔** 준비를 좀 해줘」

---

## ★이것만 주시면 됩니다 (다섯 가지)

| | 무엇 | 보기 |
|---|---|---|
| **이름** | 간판에 설 회사 이름 | 이안카 |
| **전화** | 손님 상담 번호 | 1899-9199 |
| **색** | 브랜드 색 | `#DE3536` |
| **사업자 줄** | 푸터에 설 글 (여러 줄) | 「(주)이안카 · 대표 ○○○ · 사업자등록번호 000-00-00000」 |
| **공급사 코드** | **그 회사 차만** 팔 때만 | `RP031` |

**공급사 코드는 대개 «없음»이 맞습니다.** 영업채널은 «우리 재고 전체»를 제 이름으로 파니까요.
코드를 넣는 건 「그 공급사 차만 모아서 준다」는 뜻입니다.

색을 모르시면 **로고 파일만 주셔도** 됩니다 — 거기서 재서 씁니다(추정하지 않습니다).

---

## 만드는 데 걸리는 일

```bash
npm run channel:new -- --key=eancar --name=이안카 --tel=1899-9199 --color=#DE3536 \
  --biz="(주)이안카 · 대표 ○○○ · 사업자등록번호 000-00-00000" \
  --biz="주소 · 통신판매업신고 0000-○○-0000"
```

`--dry` 를 붙이면 **넣지 않고 줄만 보여** 줍니다. 도메인이 이미 있으면 `--host=...` 를 더합니다.

이 도구가 **사고 나는 칸 넷을 먼저 막습니다** — 이름 중복 · 주소 중복 · 색 꼴 · 공급사 코드 꼴.
(공급사 코드가 틀리면 **목록이 통째로 0건**이 됩니다. 그 사고를 여기서 잡습니다.)

---

## ★만들면 «저절로» 되는 것

새 채널은 코드가 하나라 **손볼 게 없습니다.**

- 목록·상세·검색·정렬·조건칸·빠른조건 — 전부 같은 화면
- 조건칸이 안 쭈그러들고, 0은 0으로 서고, 웹·폰이 같게 돎
- 카드 그림자·햅틱·설정 눈금·연동 시각(날짜+시각)
- 주소 **`freepasserp.com/<이름>`** 이 바로 살아납니다

```
  주소      https://www.freepasserp.com/eancar
  미리보기  https://www.freepasserp.com/shop?wl=eancar
```

## 나중에 채워도 되는 것 (막지 않습니다)

| | 언제 | 왜 미뤄도 되나 |
|---|---|---|
| **간판 그림(CI)** | 파일 받으면 | 없으면 회사 «이름 글자»로 섭니다. ★그림은 **재서** 넣습니다 — 여백 붙은 원본을 그대로 쓰면 로고가 작아지거나 잘립니다(`DESIGN_CONFIRMED_SHOP.md` §CI) |
| **통신판매업신고 번호** | 나오면 | 없으면 그 자리만 비웁니다. ⚠ `[미확인]` 같은 말을 손님 화면에 내보내지 않습니다 |
| **도메인** | 사면 | 그전까지 `freepasserp.com/<이름>` 이 정식 주소입니다. 도메인은 **사서 붙인 뒤에** 켭니다 — 안 산 주소를 손님에게 보내면 그 손님은 그걸로 끝입니다 |
| **빠른조건** | 언제든 | **코드를 안 고칩니다.** 그 채널 화면에서 설정 눈금(⚙)을 눌러 고칩니다 — 재고를 보고 정하는 값이라 만들 때는 알 수 없습니다 |

## 내가 하는 순서

1. `npm run channel:new` 로 줄을 넣는다
2. `npm run check:design` · `npm run build` 로 확인
3. PR → 머지 → 배포 → **운영이 그 커밋을 서빙하는지** 확인(`npm run check:deployed`)
4. 새 주소를 열어 **화면을 눈으로** 본다 — 간판·색·전화·대수

★2 ~ 4 는 제가 합니다(상시 위임 — `docs/` 「손님 화면은 배포까지 끝낸다」).
★1 도 값만 주시면 제가 칩니다. **이름·전화·색·사업자 줄** 넷만 말씀하시면 됩니다.
