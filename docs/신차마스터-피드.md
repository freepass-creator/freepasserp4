# 신차마스터 — 이 원자를 갖다 쓰는 길 (SSOT)

> 사장님 2026-09-05 「이 원자들이 잘 뻗어 나갈 수 있게 그 길만 잘 열어줘. 이 원자를 갖다 쓸 거거든.」

제조사 「내 차 만들기」에서 크롤한 **신차 트림·가격·옵션**을 담은 원자 묶음이다. 견적기(welrix)가 이걸 땡겨
**차량 가격을 확정**하고, 앞으로 다른 화면·도구도 이 길로 갖다 쓴다. **손대기 전 이 문서를 읽는다.**

## 원자가 어디 있나
- **정본 = Firestore 컬렉션 `new_car_trim`** (423트림, 현대·기아·제네시스·르노). 매일 갱신.
- **소비 경로 = `GET /api/newcar`** — 인증 없이, CORS 열림(외부 견적기가 크로스오리진으로 fetch). 이게 «길»이다.
- 차종마스터(`public/data/vehicle-master.json`)에 어느 세대가 신차인지 표시(`market_class`·`newcar_priced`).

## 피드 API — `GET /api/newcar`
| 쿼리 | 뜻 |
|---|---|
| `?maker=현대` | 그 제조사만 (현대·기아·제네시스·르노) |
| `?model=그랜저` | sub_model 부분일치 (현대 「디 올 뉴 아반떼」·기아 「sorento」 슬러그) |
| `?group=model` | 모델별로 묶어서 — 견적기 「모델 고르고 → 트림·옵션」 흐름용 |

**응답(기본):**
```json
{ "count": 423, "makers": ["현대","기아","제네시스","르노"], "updatedAt": "2026-09-05",
  "trims": [ { "maker":"현대", "sub_model":"디 올 뉴 아반떼", "carType":"디 올 뉴 아반떼",
    "fuel":"가솔린", "trim":"모던", "priceBefore":23980000, "priceAfter":23980000,
    "options":[{"name":"컴포트 I","price":900000},…], "rules":[…] } ] }
```
`?group=model` 이면 `{ modelCount, models:[{maker, sub_model, fuels[], trimCount, trims[]}] }`.

## 필드 뜻 (확정 규격)
- **priceBefore / priceAfter** — 세제혜택 «전 / 후». 가솔린 등 감면 없으면 전=후. 전기·하이브리드는 다르다(개소세·교육세·취득세 감면). ★후>전 역전은 버그(택시·영업용 taxIncentive 음수 처리 완료).
- **options** — `[{name, price}]`. `price:0` = 기본 포함, 없으면(−) 해당 트림에 제외. 기아는 좌표추출이라 이름 일부 조각(`옵션N`) 가능, **가격은 정확**. 현대는 선형 파싱이라 이름 깨끗.
- **basePrices** (제네시스만) — 기본모델 엔진×구동 «변형 가격» 배열. 제네시스는 트림계층이 아니라 «기본모델+필수/선택 옵션»이라 priceBefore=최저 변형, basePrices=전 변형.
- **rules** — 조합규칙(배타·종속) 문자열. 기아 PDF에서 뽑음.
- **carType** — 제조사 원문 모델명(현대=한글·기아=영문슬러그). sub_model 과 매칭 다리로 씀.

## 견적기용만 고르기 (신차/중고 구분)
`new_car_trim` 은 **전부 크롤 실가**라 그대로 견적에 쓸 수 있다. 차종마스터 쪽에서 «현행/실가»를 나눈다:
- `market_class` = `신차`(year_end=「현재」·현행생산) / `중고`(생산종료).
- `newcar_priced` = new_car_trim 에 실가 있는지. **`market_class=신차 && newcar_priced=true` = 견적기가 바로 쓰는 51개**(나머지 신차는 수입·미크롤).

```

      extract-genesis.py+apply-genesis.mjs (제네시스) · write-renault-filante.mts (르노)
현대 옵션: extract-hyundai-options.py + attach-hyundai-options.mjs (가격표 PDF 선형)
분류: apply-market-class.mts (신차/중고) · apply-newcar-priced.mts (실가 4단)
검수: monitor-newcar.mts (매일 — 제조사 가격·트림 변동 감지, 문서id 키) · audit-newcar.mjs (정합성 인증)
```
- **PDF URL**: 기아 `kia.com/content/dam/kwp/kr/ko/vehicles/pdf/price/price_{model}.pdf` · 현대 `hyundai.com/contents/repn-car/catalog/{slug}-price.pdf` · 제네시스 다운로드센터 POST(docId).
- **추출**: `python + pymupdf(fitz)` (한글 CID폰트라 pdftotext 깨짐). 기아=좌표 그리드, 현대·제네시스=선형 `[가격]`.
- **바꾸기 전**: 가격·트림이 어긋나면 크롤러가 아니라 **정본(제조사 PDF/API)을 먼저 의심**. audit-newcar 로 이상 0 확인 후 배포.
