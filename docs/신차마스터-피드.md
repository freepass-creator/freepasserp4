## ★★신차·중고 견적기 «양쪽» 제공 규격 (사장님 2026-09-06 「주는 쪽에서 잘 준비」)
주는 쪽(우리)이 두 견적기에 «문제없이 뻗어나가게» 내주는 세 피드:

| 받는 쪽 | 무엇을 땡기나 | 피드 | 데이터원 |
|---|---|---|---|
| **신차 견적기** | 조합지도·min~max (국산 전 브랜드) | `GET /api/newcar/config` (공개·CORS). `?maker=제네시스\|현대\|기아\|르노\|KGM\|쉐보레` `?model=gv80\|그랜저` | **로컬파일(무조건 안정)**: `genesis-config-fs.json`(제네시스 8·공식PDF·코덱스확정) + `hk-config.json`(현대·기아 38·트림사다리+옵션카탈로그) + `domestic-minor.json`(르노·KGM·쉐보레 16 간이) |
| **신차 견적기** | 트림·가격·옵션(raw) | `GET /api/newcar` | ⚠ **Firestore new_car_trim 의존** — 배포 Firestore 키 풀리면 503(폴백 없음). 조합지도(config)는 이거 없이도 로컬파일로 나가므로 견적기 핵심은 안전 |
| **신·중고 견적기** | 차량 «식별키»(세대·연식·트림)·신차 실가군 | `GET /api/carmaster?market=신차\|중고&priced=1` | **로컬파일(안정)**: `public/data/vehicle-master.json` |

- **차종마스터 = 두 견적기 공통 «차량 식별» 소스.** `market_class`(신차/중고)로 갈래를 나누고, `newcar_priced`로 신차 중 실가있는 51개를 가린다. 우리는 «식별을 정확히」 준다 — 중고 «시세」 산출은 중고 견적기 몫(우리는 maker·sub_model·gen_code·연식·trims를 정확히 제공).
- **조합지도(배타·종속·패키지·min~max)** = 신차 견적기가 「어떤 옵션·어디까지 조합·얼마」를 확정하는 데 씀. 값은 «유효 완성구성»에서만(단순 합산 금지).
  - **제네시스 8모델** = «기본모델+필수/선택 옵션» 구조 → 배타그룹(엔진·구동·인승·외장·휠·내장)+옵션+풀옵션 maxPrecise. 정본 = **공식 PDF(gen_*.pdf) 해독**(`scripts/parse-genesis-pdf.py`) → `genesis-config-fs.json`. **모델마다 코덱스 PDF 독립검증 확정**(VERDICT-codex-{gv80,g80,genesis-batch,genesis-ev}). 옛 mtops(genesis-config.json)는 구가·폐기.
  - **현대·기아 38모델** = «트림계층»이 변형축 → 트림 사다리(연료×트림, 각 완성가) + optionCatalog(현대 공식PDF 옵션·`parse-hyundai-pdf.py`). `build-hk-v2.mjs`. **min·트림사다리 코덱스 확정**. ★«모델 단일 max»는 산정 안 함 — 옵션초집합 단순합은 특장·상호배제·기본포함까지 더해 과대(코덱스). 최고가는 **견적기가 «선택 트림 + 그 트림 옵션»으로 계산**.
  - **르노·KGM·쉐보레 16모델** = carnoon 현재가 «간이»(min~max 범위·주요트림). `domestic-minor.json`. 트림상세·옵션은 후속(제조사 PDF 미확보). 매물비중 낮음.
  - ⚠ **정밀도 등급을 견적기가 구분해서 쓴다**: 제네시스=정밀(옵션까지) · 현대기아=트림확정+옵션카탈로그 · 소수3사=범위. 각 엔트리 `status`/`level` 로 표시.
  - ★★**모든 가격 = 개별소비세 5% 기준**(제네시스 공식 PDF·현대·기아 동일). 다나와·카눈 «시작가»는 개소세 3.5%(실효)라 ~1.3~1.7% 낮게 보이는데 **오류 아님**(basis 차이). 견적기가 3.5% 실효가로 내려면 개소세 1.5%p 감면을 받는 쪽에서 적용(전기·하이브리드는 별도 세제혜택 반영, EV base는 세제후). 교차검증: `docs/crosscheck/신차가격-교차검증-2026-09-06.md`(아반떼·그랜저·GV80·G90 등 카눈·다나와·제조사공식 대조 — 우리 숫자 정확 확인).
- 피드는 전부 공개·CORS·장애는 no-store. `/api/carmaster` `/api/newcar` 둘 다 `?maker` `?model` 지원.

## 원자가 어디 있나
- **정본 = Firestore 컬렉션 `new_car_trim`** (423트림, 현대·기아·제네시스·르노). 매일 갱신.

- 차종마스터(`public/data/vehicle-master.json`)에 어느 세대가 신차인지 표시(`market_class`·`newcar_priced`).

## 피드 API — `GET /api/newcar`
| 쿼리 | 뜻 |
|---|---|
| `?maker=현대` | 그 제조사만 (현대·기아·제네시스·르노) |
| `?model=그랜저` | sub_model 부분일치 (현대 「디 올 뉴 아반떼」·기아 「sorento」 슬러그) |
| `?group=model` | 모델별로 묶어서 — 견적기 「모델 고르고 → 트림·옵션」 흐름용 |

**응답(기본):**
```json
{ "count": 423, "makers": ["현대","기아","제네시스","르노"], "updatedAt": "2026-09-05",
  "trims": [ { "maker":"현대", "sub_model":"디 올 뉴 아반떼", "carType":"디 올 뉴 아반떼",
    "fuel":"가솔린", "trim":"모던", "priceBefore":23980000, "priceAfter":23980000,
    "options":[{"name":"컴포트 I","price":900000},…], "rules":[…] } ] }
```
`?group=model` 이면 `{ modelCount, models:[{maker, sub_model, fuels[], trimCount, trims[]}] }`.

## 필드 뜻 (확정 규격)
- **priceBefore / priceAfter** — 세제혜택 «전 / 후». 가솔린 등 감면 없으면 전=후. 전기·하이브리드는 다르다(개소세·교육세·취득세 감면). ★후>전 역전은 버그(택시·영업용 taxIncentive 음수 처리 완료).
- **options** — `[{name, price}]`. `price:0` = 기본 포함, 없으면(−) 해당 트림에 제외. 기아는 좌표추출이라 이름 일부 조각(`옵션N`) 가능, **가격은 정확**. 현대는 선형 파싱이라 이름 깨끗.
- **basePrices** (제네시스만) — 기본모델 엔진×구동 «변형 가격» 배열. 제네시스는 트림계층이 아니라 «기본모델+필수/선택 옵션»이라 priceBefore=최저 변형, basePrices=전 변형.
- **rules** — 조합규칙(배타·종속) 문자열. 기아 PDF에서 뽑음.
- **carType** — 제조사 원문 모델명(현대=한글·기아=영문슬러그). sub_model 과 매칭 다리로 씀.

## 견적기용만 고르기 (신차/중고 구분)
`new_car_trim` 은 **전부 크롤 실가**라 그대로 견적에 쓸 수 있다. 차종마스터 쪽에서 «현행/실가»를 나눈다:
- `market_class` = `신차`(year_end=「현재」·현행생산) / `중고`(생산종료).
- `newcar_priced` = new_car_trim 에 실가 있는지. **`market_class=신차 && newcar_priced=true` = 견적기가 바로 쓰는 51개**(나머지 신차는 수입·미크롤).

## 알려진 한계 (코덱스 검토 2026-09-05 반영 — 견적 확정 전 알고 쓴다)
- **옵션은 «연료-정확한 것만»** — PDF 연료 감지가 약해, 다연료 모델에서 연료가 안 잡히면 «틀린 연료 옵션을 붙이느니 안 붙인다»(현대 51트림·232셀만). 파서 연료 감지를 넓히면 커버리지 오른다. `newcar_priced`·옵션 유무는 «있으면 정확, 없으면 미수집»이지 «없으면 옵션 없음»이 아니다.
- **현대 재크롤은 옵션을 지우지 않는다(merge)** — 하지만 트림이 바뀌면 옵션도 갱신돼야 하니, **매 크롤 뒤 `attach-hyundai-options.mjs` 재실행이 정석**. 파이프라인 순서 = 크롤 → attach → audit.
- **기아·제네시스는 재적재 시 먼저 지운다** — 가격 바뀌면 옛 문서가 남던 것 방지(delete-first). 제네시스는 8모델 전부 추출 검증 뒤에만 삭제.
- **세제혜택 후(현대)** = API `taxIncentive` 로 계산(양수 감면만). **공식 견적서와 원단위 대조는 아직 안 함** — 택시·영업용 음수 의미 포함해 표본 대조 필요.
- **market_class/newcar_priced 는 휴리스틱** — `year_end`=「현재」→신차, new_car_trim 모델명 부분일치→실가있음. 「현행이며 실가 확인」의 «확정»이 아니라 «후보 표시»로 쓴다.
- **매일 모니터 감시 범위** = 현대 트림 추가·삭제·차량가만. 옵션·색상 변동, 기아·제네시스·르노는 아직 미감시.
- **audit-newcar 는 배포 게이트** — 이상 있으면 exit 1. 근사중복(스타리아 9/11인승 등 실구성)은 경고만.
