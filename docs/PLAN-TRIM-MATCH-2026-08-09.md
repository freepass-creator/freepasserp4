## 2. 커서가 할 것

### ★A. 공급사가 준 모델명을 «더 구체적인 마스터 모델»로 올리기 — 최우선

**증상**

```
원문  model=「아이오닉」  trim_name=「아이오닉 6 Long Range 2WD 익스클루시브 플러스」
결과  모델「아이오닉」 세대「더 뉴 아이오닉 일렉트릭」 트림「」
```

2016년 준중형 해치백이다. **다른 차를 팔고 있다.** 트림이 빈 것보다 이게 훨씬 위험하다.
아이오닉5도 같은 증상이다.

**마스터 결손이 아니다.** 마스터엔 다 있다:

```
아이오닉5   더 뉴 아이오닉5 NE · 아이오닉5 NE
아이오닉6   더 뉴 아이오닉6 · 아이오닉6
아이오닉9   아이오닉9
```

**원인** — `lib/domain/vehicle-master-normalize.ts:350-372`

```ts
if (!modelRaw || deps.looksCompoundVehicleText(modelRaw) || peeled) {
  out.model = hitModel;
}
```

`findHit()`은 이미 `hitModel = 「아이오닉6」`을 **정확히 찾아낸다**(후보 풀이 긴 이름 우선 정렬이라).
그런데 공급사가 준 `model = 「아이오닉」`이 빈칸도 아니고 문장도 아니라서, 손에 쥔 답을 못 쓰고 버린다.

**처방**

`hitModel`이 `modelRaw`보다 **더 구체적이면** 갈아끼운다. 조건은 좁게:

```
norm(hitModel) !== norm(modelRaw)
&& norm(hitModel).startsWith(norm(modelRaw))      // 같은 계열의 더 자세한 이름일 때만
&& 마스터에 hitModel 이 실재
```

`startsWith`로 묶는 이유: 「아이오닉」→「아이오닉6」은 올리고,
「아반떼」→「파사트」 같은 도약은 구조적으로 불가능하게 막는다.
(옵션칸이 모델 후보에 섞여 아반떼가 파사트로 붙은 사고가 2026-08-09에 실제로 있었다.)

**받아들일 조건**

- `scripts/_probe-ioniq.mts` 4케이스 전부 `아이오닉5 NE` / `아이오닉6` 계열로 붙을 것
- `sim-bform-model` · `sim-snap-failure` · `sim-trim-extract` · `sim-sheet-merge` 계속 통과
- `audit-trim-by-plate.mts` 재실행 시 **「사라짐」이 늘지 않을 것** ← 이게 제일 중요하다

### B. 영문 세대 표기 별칭 (중간 우선)

```
원문 「쏘나타DN8 The Edge … 익스클루시브」
결과 세대「쏘나타 DN8」        기대「쏘나타 디 엣지 DN8」
```

둘 다 `gen_code = DN8`이라 세대코드로 못 가른다. 「The Edge」와 「디 엣지」를 잇는 표기 사전이 필요하다.
`The Edge → 디 엣지`, `The New → 더 뉴` 정도. **실데이터에서 확인된 것만** 넣을 것.

세대가 갈리면 트림 후보가 바뀌어 「익스클루시브」가 그때 잡힌다(9대).

## 3. 하지 말 것

> **못 잡는 것보다 틀리게 잡는 게 나쁘다.**

없는 등급을 붙이면 손님에게 없는 차를 파는 것이다. 실제로 났던 사고들:

- 유사도 문턱 0.75 → 「아이오닉」이 「아이코닉」에, 「레인지」가 「롱 레인지」에 붙음
- 초성 매칭 → 벤츠 `E200 아방가르드`가 `E300 아방가르드`로 **등급이 올라감**
- 옵션칸을 모델 근거로 사용 → 아반떼가 파사트로, K5가 Q5로 (21대)

그래서 `vehicle-trim-resolve.ts`의 문턱(0.82~0.93)과
`vehicle-match-sources.ts`의 `NON_IDENTIFYING_FIELDS`(옵션·비고 제외)는 **낮추거나 늘리지 말 것.**
가르는 기준은 하나다 — **「그 칸이 차를 특정하는가.」**

## 5. 반영 원칙 — 빈 칸만 채운다

전수 검수 결과 재매칭이 **기존 값을 지우거나 깎는 차가 12대** 나왔다. 예:

```
109호1924  원문 「K5 LPi 2.0 스탠다드 3 22MY」   → 기존 「스탠다드」가 지워짐
109호3581  원문 「더 뉴 K3 1.6 가솔린 프레스티지」 → 기존 「프레스티지」가 지워짐
```

원문에 트림이 또렷한데 마스터 목록에 없어서 지워지는 것이다. **기존 값이 더 정확하다.**

그래서 실제 반영은 **빈 칸만 채우고 있는 값은 건드리지 않는다.**
그러면 97대를 얻고 하나도 잃지 않는다.

사장님 확인이 필요한 것 1건:

```
161허1360  원문 「… 4WD 시그니처 그래비티 DCT」   시그니처·그래비티가 둘 다 적혀 있음 — 실제는 어느 쪽?
```
