# 공급사 상품시트 규격 (2026-08-07 실측 기준)

이 문서는 «있어야 할 규격»을 상상해서 쓴 게 아니라, **지금 연동 중인 16곳의 시트를 그대로 읽어**
공통 구조를 뽑은 것이다. 대부분이 이미 이 양식을 쓰고 있으므로, 새 공급사에게는 이대로 요청하고
어긋난 곳만 맞춰 달라고 하면 된다.

## 실측 — 양식은 «두 가지»다

### A형 · 렌트사 표준 (11곳)

에스에이 · 아이언 · 리더스 · KH · 손오공 · 웰릭스 · 경진카 · 센트로 · 스타 · 우리캐피탈 · 빌린카

```
0 배차상태 │ 1 차량번호 │ 2 차종 │ 3 모델명(트림) │ 4 옵션 │ 5 외장색 │ 6 내장색
7 유종 │ 8 최초등록일 │ 9 주행거리 │ 10 구분
11~ 보증금·기간요금(단기보증·1·6·12개월 / 장기보증·24·36·48·60개월)
그 뒤 소비자가격 · 연주행 · 분납 · 21세 · 23세 · 1만+ · 대인 · 대물 · 자차 · 자손 · 무보험 · 전용계좌 · 비고
```

**차번이 1열로 고정**이고 그 좌우 배치가 11곳에서 동일하다. 열 개수만 33~36으로 조금씩 다르다.

### B형 · 종합시트 (2곳)

아이카 · 이안카

```
[차량상태] │ 배차상태 │ 입고일자 │ 구분 │ 차량번호 │ 차종분류 │ 세부모델 │ 연료
외장 │ 내장 │ Km │ 보증금·기간요금… │ 트림 │ 옵션 │ 최초등록 │ 소비자가격
제조사 │ 배기량 │ 차고지 │ 운전자범위 │ …
```

A형과 다른 점이 셋이다. **이게 아이카 7대·이안카 17대가 검수로 남는 이유다.**

| | A형 | B형 | 문제 |
|---|---|---|---|
| 차명 | `차종`(2열) | **없음** — `세부모델`이 그 역할 | 모델을 잠글 열이 애매하다 |
| 트림 | `모델명(트림)` 한 칸에 통합 | `트림` 별도 열 | B형이 오히려 구조가 낫다 |
| 차번 위치 | 1열 고정 | 4열·3열 | 앵커 위치가 다르다 |

## 규격 — 새 공급사에 요청할 것

### 필수 (없으면 매물이 안 올라간다)

| 열 이름 | 값 규칙 | 비고 |
|---|---|---|
| `차량번호` | `00가0000` 또는 `000가0000` | 번호 미발급 신차는 `신차` 또는 공란 |
| `배차상태` | 아래 상태 어휘표 | 빈칸이면 «출고협의»로 본다 |
| `차종` | 차명만 (`아반떼`·`그랜저`) | |
| `모델명(트림)` | 풀표기 (`더뉴아반떼 25MY 가솔린 1.6 N라인 인스퍼레이션`) | **차종 확정의 핵심** |
| 기간요금 | 헤더가 `12개월`·`36개월`처럼 «숫자+개월» | 값은 숫자만(콤마 허용) |

대여료가 하나도 없으면 그 행은 올리지 않는다. 차번과 대여료, 이 둘이 최소 요건이다.

### 권장 (있으면 차종이 정확해진다)

`유종` · `최초등록일`(`25-03`) · `주행거리`(숫자) · `외장색` · `내장색` · `옵션` · `구분`
· `배기량` · `제조사` · `트림`(따로 있으면 더 좋다)

### 상태 어휘 — 지금 실제로 쓰이는 말

| 시트 원문 | 우리 판정 | 올리나 |
|---|---|---|
| 출고가능 · 판매중 · 할인판매 | 출고가능 | ○ |
| 즉시출고 | 즉시출고 | ○ |
| 재고확인 · 출고 · `8월3일이후출고가능` · 빈칸 | 출고협의 | ○ |
| 출고불가 · 매각 · 출고완료 · 폐차 · 말소 | 출고불가 | **×** |
| 계약중 · 계약홀딩 · 보류 | 출고불가 | **×** |

「출고불가가 아니면 올린다」가 규칙이다. 애매한 말은 **출고협의**로 접혀서 올라간다.

## 시트를 만들 때 하지 말아야 할 것

실제로 사고가 났던 것만 적는다.

- **표 중간에 헤더를 다시 넣지 않는다.** 구간을 나누려면 탭을 나눠라
  (이안카 시트의 반복 헤더 1행이 «무효 차번»으로 잡혀 16곳 전체 반영이 막혔다).
- **차번 칸에 차종·스펙을 적지 않는다.** 번호가 없으면 `신차`라고만 쓴다.
- **열을 중간에서 지우거나 밀지 않는다.** 같은 탭 안에서 열이 밀리면 값이 통째로 어긋난다.
- **안내 문구를 표 위에 여러 줄 넣어도 된다** — 헤더는 `차량번호`가 있는 행을 찾아 쓴다.
- **행을 숨겨서 «판매 안 함»을 표현하지 않는다.** 상태 칸에 `출고불가`라고 적어라
  (숨김은 필터·정렬 등 다른 목적으로도 쓰여서 판매 여부로 못 읽는다).

## 우리가 시트를 읽는 방식 (참고)

1. `차량번호`가 있는 행을 찾아 헤더로 삼는다 — 행 번호를 고정하지 않는다.
2. 열은 **헤더 이름**으로 매핑한다. 저장된 매핑이 있으면 그게 우선하고, 없는 필드는 자동매핑이 채운다.
3. 지정된 차번 칸이 번호판 형식이 아니면 **그 행에서 번호판을 찾는다**(열이 밀려도 차를 놓치지 않는다).
4. 차종은 `차종`+`모델명(트림)`+나머지 신호를 합쳐 차종마스터에 붙인다.
   못 붙어도 매물은 올라가고 «차종 검수» 표시만 붙는다.
5. 사진은 열이 아니라 **차번 셀의 링크**(드라이브 폴더·상세페이지)에서 가져온다.

## 남은 숙제

- B형(아이카·이안카)에 `차종`(차명) 열을 추가해 달라고 요청 → 모델 잠금이 안정된다.
- A형 11곳은 이미 규격에 맞다. 신규 공급사는 A형으로 받는다.
- 트림은 등록원부 API 로도 안 온다(`VEHICLE_LOOKUP_API.md`). 시트의 `모델명(트림)` 칸이 정본이다.
