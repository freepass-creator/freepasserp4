# 원자 엔진 불변식 — «절대 실수할 수 없는 엔진»

> 사장님 2026-09-05 「엔진부터 확실히 만들자. 절대 실수할 수 없는. AI 넷이 머리 맞대 이것만 백 년 연구한 것처럼.」

이 문서 = 그 엔진의 «연구본». 네 AI(클로드·코덱스·커서·제미나이)가 원자 데이터를 만들 때 **반드시 지킬 불변식**을 한 곳에 박는다. 코드 SSOT = [`lib/domain/atom-invariants.ts`](../lib/domain/atom-invariants.ts). 줄자 = `npm run check:invariants`.

## 왜 «게이트»인가 (감사가 아니라)

2026-09-05, 가솔린 G80 이 세부모델 「일렉트리파이드」(전기)로 붙어 «배기량 3500cc 전기차»가 «확정»된 채 존재했다. 규칙이 여러 곳(evClean·canonFuel·audit)에 흩어져, 한 곳이 그걸 못 걸렀다.

⇒ **규칙을 «사후 청소」가 아니라 «확정 조건」으로 둔다.** 원자가 불변식을 어기면 **확정(확정=true)이 «될 수 없다»** — 검수대기로 떨어진다. 그래서 모순이 «확정된 채로» 존재하는 것이 **구조적으로 불가능**하다. 이게 «절대 실수할 수 없는」의 실체다.

**한 곳에서만 판정한다.** 원자화(ingest)·전수감사(audit)·게이트(check)가 «같은 함수»(`atomViolations`)를 쓴다. 흩어지면 언젠가 한 곳이 달라진다.

## 불변식 — block(확정 불가) vs warn(확정되나 표시)

| 코드 | 심각도 | 규칙 | 왜 |
|---|---|---|---|
| `IDENT` | **block** | 세부모델이 있으면 **차종마스터 실재값**이어야 한다 | 정체를 지어내면 안 된다 |
| `EV_CC` | **block** | 연료 전기·수소면 **배기량이 없어야** 한다 | 전기차엔 엔진이 없다 |
| `EVSUB_CC` | **block** | 세부모델이 EV(일렉트리파이드…)인데 **배기량이 있으면** = 내연차(모순) | ★배기량 있으면 전기차 아니다(사장님) |
| `EVSUB_FUEL` | **block** | 세부모델이 EV인데 연료가 전기·수소가 «아니면» 모순 | 이름과 연료가 어긋남 |
| `FUEL_RAW` | warn | 원문에 연료말이 있으면 원자 연료와 같아야 | 원문이 정본 |
| `CC_RAW` | warn | 원문 리터(2.5·3.5)와 배기량이 맞아야(전기 제외) | 2.5T=2497cc |
| `TRIM` | warn | 세부트림은 그 세부모델 마스터 트림이거나 비어야 | 트림 지어내지 않음 |
| `SEATS_RAW` | warn | 원문에 인승이 있으면 그 값 | 인승은 원문에 있는 것만 |
| `SEATS_2` | warn | 2인은 원문에 밴/2인승 있을 때만 | 토레스 2인 오류 방지 |
| `PROV` | warn | 원천(source)이 있어야 한다 | 정밀타격 — 어디서 왔나 |

**block 하나라도 있으면 확정 불가.** warn 은 확정은 되나 `_violations` 에 남아 눈에 띈다.

## 판정 흐름

```
원천 → 원자화(atomize)
   → 원자 조립(정체·스펙·상태·요금·인승·원천)
   → atomViolations(원자, 마스터인덱스)        ← 불변식 SSOT
   → block 있으면?  예 → 확정=false, 검수(코드)     ← 게이트: 모순은 확정될 수 없다
                    아니오 → confirmed && 통과 → 확정=true
```

- 원자화는 **원천 연료만** 믿는다(세부모델 이름으로 전기 판단 안 함 — 이름은 오매핑될 수 있다).
- 인승은 **원문에 있는 것만**(마스터엔 인승이 없다 · 없으면 필수 아님).
- 세대는 **섀시코드·최초등록**만(원문의 「N세대」 숫자는 시장 관례가 달라 안 씀 — 6세대=W214).

## 재검·수리 도구

- **게이트**: `npm run check:invariants` — 전 원자에 불변식. «확정인데 block» = exit 1(있으면 안 되는 것).
- **전수 감사·수리**: `scripts/audit-raw-vs-atom.mts` — 원문 ↔ 원자를 대조해 A(세부모델)·B(연료)·C(배기량)·D(인승)를 «원문·마스터 근거로만» 고친다. 근거 없으면 안 고치고 검수로 남긴다.
- **전기 배기량 힐**: `scripts/heal-ev-specs.mts` — 원천 연료 전기·수소인데 배기량 있으면 비움.

## 네 AI 규칙 (이 엔진을 건드릴 때)

1. **불변식은 `atom-invariants.ts` 한 곳.** 규칙을 딴 데 또 만들지 마라 — 그게 흩어짐의 시작이다.
2. **원자화는 반드시 이 게이트를 통과해야 확정.** 게이트를 우회해 확정을 세우지 마라.
3. **근거 없이 값을 만들지 마라.** 원문·마스터가 근거다. 없으면 검수대기(비움), 지어내지 않는다.
4. **바꾸려면 이 문서를 먼저 고치고 → SSOT를 고치고 → 게이트를 고친다.** 게이트를 먼저 통과시키려 규칙을 지우면 엔진이 거짓말을 한다.
