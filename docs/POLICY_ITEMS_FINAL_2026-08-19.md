## 0. 원칙 — 이 표 하나로 끝내기 위해

1. **항목 = 계약서·약관이 값을 참조하는 자리.** 조문이 참조하지 않는 값은 계약서 항목이 아니다(영업·내부 항목으로 따로 둔다).
2. **한 항목 = 한 값.** «가능 여부»와 «금액»은 다른 항목(추가운전자 → 가능여부 / 인원·요금 분리 원칙 유지).
3. **정액·정률은 값의 표기로 구분한다** — 항목을 둘로 쪼개지 않는다. `「10만원」=정액 · 「10%」=정률 · 「월 대여료 2개월분」=개월분`. **정률의 기준(무엇의 %)은 항목이 정한다**(아래 §2). 업체별로 정액·정률이 섞여도 한 칸에 담긴다.
4. **빈칸 ≠ 없음.** 보장이 없으면 「없음」·「미가입」·「불가」를 적는다. 빈칸은 «아직 안 적음»이라 발행이 막힌다.
5. **프리패스 표준값이 있는 항목은 「기본 따름」이 허용값.** 공급사는 다를 때만 적는다. 표준값은 `policy-defaults`(JPK 실계약서 숫자)를 그대로 쓴다.
6. **손님에게 나가면 안 되는 값은 계약서 항목에 두지 않는다**(심사기준·신용등급·수수료 환수).

## 1. 값이 흘러가는 곳 (왜 채우나)

```
공급사 정책 시트(정책 탭 1행 = 정책 1개)
   → ERP 정책 레코드(policy_code)
        ├─ 영업자 시트/상품 화면        exposure sales·quote     «상담에서 말하는 값»
        ├─ 고객 서명화면 묶음(consent)   esign-consent-doc        «손님이 체크하는 조건»
        ├─ 계약서 A4 143칸(data-field)   esign-template-fields    «계약서에 박히는 값»
        └─ 약관 조문 참조(제N조)         esign-standard-terms     «빈칸이면 조문이 공중에 뜸»
공급사(파트너) 레코드 → 계약서 임대인 칸(상호·사업자번호·대표자·주소·자동차대여사업 등록번호·계좌)
```

## 3. 항목표 — 계약서 순서로

표기: **필수** = 발행 게이트(빈칸이면 링크 못 만듦) · ○ = 계약서/약관/고객화면에 실림 · △ = 영업 전용 · ✕ = 내부 전용
「현 시트명」이 비어 있으면 **시트에 없는 항목**(추가 필요). 「표준값」은 프리패스 기본(policy-defaults) — `—`는 표준 없음(공급사가 반드시 적음).

## 4. 갈린 것 — 시트 ↔ 계약서

- **시트에 있는데 ERP 키가 없는 것**: 추가주행 방식(A2 — 값 표기로 흡수 가능), 전용계좌·특이사항(정책 레코드 자유칸으로만 존재).
- **계약서·약관이 참조하는데 시트에 없는 것(14)**: 결제방식·납부조건·월 납부일·결제주기·보증금 반환기한·청구서 종류·청구 주기·무보험 면책금·청구 기준·지연손해금율·시동제어 기준일·회수 기준일·보증금 미납 시동제어 회차·물품 보관료·보관기간·연장/인수 통지기한. 이 중 **공급사별로 다를 법한 것**은 월 납부일·납부조건·결제방식·보증금 반환기한·시동제어/회수 기준일 정도. 나머지(지연손해금·보관료·통지기한·청구서)는 **프리패스 표준으로 고정**하고 시트엔 안 두는 쪽 권장.
- **시트 블록 「④ 아직 안 쓰임」은 낡았다**: 위약금 1년 미만/이상(E1·E2)·초과주행 국산/수입(A4·A5)·법인운전자범위(B7)는 지금 계약서/고객화면에 실린다 → 블록 ③으로 옮기고 필수 표시.
- **같은 뜻 다른 말(한 말로 통일)**: 없음↔미가입(무보험) · 불포함↔미제공(정비) · 불가↔미제공(대차) · 차량가액↔차량가 기준(자차) · 연 5회↔연간 5회(긴급출동) · 자손보상 시트 드롭다운(1억원)↔표준 문구(사망 3천만/부상 1,500만).

## 6. 사장님 결정 필요 (이것만 정하면 표가 닫힌다)

1. **표준 고정 vs 공급사별 입력** — §4의 «시트에 없는 14개» 중 어디까지 시트에 열지. 권장: 월 납부일·납부조건·결제방식·보증금 반환기한·시동제어/회수 기준일 6개만 열고, 나머지는 프리패스 표준 고정(「기본 따름」).
2. **자차 면책금 연령 3단** — 현재 한 값. (a) 시트 3칸(만 21·23·26세) (b) 「연령별 표」 자유칸 (c) 기본연령 값만 계약서에 싣고 나머지는 특약. 실제 JPK 표는 3단.
3. **위약금 정액형** — E1·E2 겸용 허용할지(업체별 정액 존재). 허용하면 ERP 저장 구조·계약서 문구 분기 작업.
4. **입금계좌 정본** — 파트너 레코드(H) vs 정책별 전용계좌(G2). 빌린카(정책 3개=계좌 3개) 때문에 «정책별이 있으면 그것, 없으면 파트너» 우선순위로 갈 것인지.
5. **자손 보상한도 표기** — 시트 드롭다운(1억원·5천만원)으로 갈지, 표준 문구(사망·후유장애/부상 분리)로 갈지.
6. **항목명 개명 시점** — 위 «정제 항목명»으로 시트 머리행을 바꾸면 20곳 시트 재발행 + `POLICY_FIELD_RENAMES` 등록이 필요. 한 번에 갈 것인지.
7. **보험 별도(고객 직접 가입)형** — C2~C14를 아예 「해당 없음」으로 잠글지, 손님 보험 요건(대인 무한 등)만 받을지.
8. **대물 보상한도 표준값** — A4 서식(JPK 실계약서) 기본은 **1억원**인데 `policy-defaults`는 2억원. 영업용(렌터카 공제) 실제 가입증권 기준으로 하나로 확정(사장님 08-19 「영업용보험 잘 확인」). 별도형 최소 조건 「1억원 이상」과도 맞물림.
