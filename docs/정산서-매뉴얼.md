## 언제 하나

정본은 [`lib/domain/settlement-cycle.ts`](../lib/domain/settlement-cycle.ts) 하나입니다.
**여기 말고 다른 데 날짜를 적지 마세요** — 종이와 알림이 같은 숫자를 봐야 합니다.

| | | |
|---|---|---|
| 말일 | 마감 | 그 달 인도분을 닫습니다. **아직 안 끝난 달은 「누락」이 아닙니다** |
| **3일** | 청구 | 다음 달 3일에 청구서가 나갑니다 |
| **10일** | 결제 | 다음 달 10일까지 받습니다 ← 종이에 「입금 요청일」로 찍히는 날 |

8월분이면 → 9월 3일 발송 → 9월 10일 입금.

## 어떤 순서로 하나

### ① 시트와 ERP 가 갈렸는지 본다

```bash
npm run settlement:drift
```

**갈렸으면 여기서 멈춥니다.** 청구서를 만들면 안 됩니다.
사람이 시트에 한 줄 더 적은 것일 수도 있고, 우리가 뭘 놓친 것일 수도 있습니다.
어느 쪽인지 «보고» 맞춘 다음에 갑니다.

### ② 정산서를 뽑는다

```bash
npm run settlement:invoices 2026-08
```

한 번에 셋이 나옵니다 — `tmp/정산서-2026-08/`

| | 누가 보나 | |
|---|---|---|
| **PDF** | 회원사 | ★나가는 종이. 고객 이름이 가려져 있습니다(`문*준`) |
| HTML | 우리 | PDF 의 원본. 브라우저로 열어 봅니다 |
| XLSX | **우리만** | ⛔ **고객 실명이 그대로 있습니다.** 밖으로 보내지 마세요 |

맨 아래 «장부» 한 줄이 이 달의 뜻입니다.

```
받을 돈  공급사 청구     44,239,305
줄 돈   영업채널 지급    35,427,942
남는 것                8,811,363   19.9%
```

### ③ 쪽에 들어가는지 본다

```bash
npm run settlement:fit tmp/정산서-2026-08
```

간격·글자를 건드린 적 없으면 넘어가도 됩니다.
**종이 서식을 손댄 달에는 반드시 돌립니다** — 화면에선 멀쩡한데 인쇄하면 꼬리를 덮습니다.

### ④ 「확인대기」를 푼다

공급사 청구서는 **영업자가 자기 실적을 확인해야** 나갑니다.
확인 없이 청구하면 「확인받은 3건」에 몰래 2건이 붙어 5건이 청구됩니다.

**길은 이미 있습니다.** 영업자가 `/settlement/ledger` 에 로그인하면
「이 N건이 맞습니다」 단추가 있습니다. 관리자는 **대신 못 누릅니다** — 서버가 막습니다.
대신 누를 수 있으면 그 문은 문이 아닙니다.

2026-08 실측 — 청구 대상 36건 · 영업자 9명

| | |
|---|---|
| 로그인 있는 영업자 | 8명 (이태헌 12 · 김종현 6 · 최원영 6 · 이하민 3 · 이승호 3 · 최사랑 2 · 양정욱 2 · 정동근 1) |
| 로그인 없는 영업자 | **1명 — 정동영 (오토원트 1건)** 누를 사람이 없습니다 |
| 지금까지 누른 사람 | **0명** |

★막힌 게 아니라 **아직 아무도 안 누른 것**입니다.
  8명에게 「로그인해서 8월 실적 확인 눌러 주세요」 하면 그 순간 열립니다.
  정동영만 계정을 만들어야 합니다.

```bash
npx tsx scripts/check-confirm-reach.mts        # 달마다 «누가 누를 수 있나»를 셉니다
```

### ⑤ 빈칸을 채운다

뽑을 때 마지막에 「발송 전 채워야 할 것」이 나옵니다.
붉은 「미입력」이 찍힌 채로 나가면 안 됩니다.

### ⑥ 드라이브에 올리고 링크를 받는다

```bash
node scripts/upload-invoices-to-drive.mjs 2026-08 --folder=<폴더 id> --share
```

- **폴더는 AI 가 안 만듭니다.** 회사 문서고 체계에 맞는 자리를 정해 주세요.
  폴더를 드라이브에서 열면 주소 끝이 그 id 입니다.
- 같은 이름이 있으면 **덮어씁니다** — 달마다 쌓이면 어느 게 최신인지 모릅니다.
- 링크는 `tmp/정산서-2026-08/_링크.md` 에 떨어집니다 — **표 + 회원사별 메일 문안**.
  메일 권한이 없어 보내는 건 사람이 하므로, 그대로 붙여넣게 문장까지 지어 둡니다.

> ★**첨부가 아니라 링크로 보냅니다** (2026-08-27 「그냥 구글드라이브를 보내라」 · 「링크로 하면 복잡하니까」).
> ERP 안에 링크 체계를 새로 만들지 않습니다 — 드라이브 권한은 이미 열려 있습니다.
> 첨부는 고치면 «옛 첨부»가 상대 손에 남지만, 링크는 여기서 덮어쓰면 상대가 보는 것도 같이 바뀝니다.

> ⛔ `--share` 는 **「링크 아는 사람은 누구나」** 로 엽니다.
> 주소는 길어서 못 맞히지만, 주소가 새면 그 종이는 새는 겁니다.
> 그래서 고객 이름을 종이에서 가려 뒀습니다. 그래도 차량번호·금액·회원사명은 보입니다.
> **다 받고 나면 `--unshare` 로 거두세요.**

## 손대면 안 되는 것

- **시트를 지우지 않습니다.** 되돌릴 길입니다. 정본은 파이어베이스로 옮겼지만
  `SETTLEMENT_STORE=sheet` 한 줄로 되돌아갑니다.
- **금액·요율은 화면에서 못 고칩니다.** 고칠 수 있는 칸은 whitelist 로 정해져 있습니다.
- **계좌·사업자번호를 지어내지 않습니다.** 틀린 계좌 한 줄이면 돈이 남에게 갑니다.
  모르면 「미입력」으로 두고 사람에게 묻습니다.
- **엑셀을 회원사에 보내지 않습니다.** 고객 실명이 들어 있습니다.
